# MAX — пиксельная карта 3072×1536

**Production-итерация реализована 23.10.2026.** Параметры находятся в runtime JSON; текущие решения и операторские действия — [STAND_SETTINGS.md](STAND_SETTINGS.md). Подробные результаты — [проверки](verification-stand-production-20261023/README.md). Физическая установка и проверка на стенде ещё не выполнены.

23.10.2026. Режим `view=pixel-map` подготовлен по пользовательскому PDF «Маска» и уточнению: середина — плоская интерактивная часть, боковые части — скругления без тача. Полное изображение остаётся общим игровым полотном: фон и маршрутные иконки проходят через скругления. Главная композиция рассчитывается по центру с отступами7% от каждого края.

| Область | Координаты в полном полотне |
|---|---|
| Полотно | 3072×1536 |
| Левое скругление | x=0…560 |
| Плоская игровая зона | x=560…2320,1760×1536 |
| Правое скругление | x=2320…3072,752×1536 |
| Безопасная область | x=683.2…2196.8,y=107.52…1428.48 |
| Безопасный размер | 1513.6×1320.96 |

Отступы составляют123.2px слева/справа центра и107.52px сверху/снизу. Исходный PDF сохранён в `apps/max-game/source/hardware/max-pixel-map.pdf`, SHA256 `91187175a357185fca4d8bb8ce6897b7c9aabf4e729251c377f5a8a616f5f282`.

Запуск в готовой папке:

- `production/startup-one-pc/Start-Pixel-Map.bat` — MAX в режиме карты и обычная Стелла.
- `production/startup-max/Start-Pixel-Map.bat` — игровой ПК в сетевой паре со Стеллой.
- В тех же каталогах `Calibrate-Pixel-Map.bat` — контрольные границы: зелёная — полотно, синяя — плоская интерактивная часть, жёлтая — безопасная область.
- `Start.bat` сохраняет обычный режим. Перед сменой режима закрыть прежнее окно MAX. F11/Escape управляют полноэкранным режимом.

Launcher выбирает подключённый дисплей3072×1536, если он доступен, включает fullscreen и масштаб Windows для процесса1×. На другом дисплее полотно показывается целиком с сохранением пропорций и полями, без растяжения. Калибровочную рамку необходимо совместить с физической маской средствами LED-процессора/Windows. Этот выпуск не меняет аппаратную прошивку, калибровку LiDAR или TouchDesigner.

Один масштаб вычисляется по самому широкому устройству каталога и справке760logicalpx с прежним отступом. Меню, все миссии, телефон/ПК и переходы используют эту проекцию; накопленная история слева не уменьшает масштаб и не сдвигает композицию ради её вмещения. Полный renderer остаётся шире игровой зоны, поэтому иконки продолжают движение на скругления и за левый край. Снимки/устройства/справка остаются в safe. Меню в этом режиме имеет логотип, видео и нижний ряд миссий внутри центра; исходный браузерный/старый wall-профиль сохраняется.

Клавиатура, «Назад», «Пропустить», посты/товары ограничены центральной безопасной зоной. Для pixel-map пропуск размещается внизу слева safe, чтобы не уходить вместе с иконкой задания. Карточки могут входить/уходить через край своего поля, но не используют боковые скругления как сенсорную поверхность. Capture-фильтр отменяет pointer/click вне плоской зоны, включая события в overlay-элементах; уход контакта на скругление отменяет его без действия. Существующие guards, действия, часы/анимации, профиль/сохранения и связка gameId/фото Стеллы сохранены.

Реализация — `kdw-pixel-map.mjs`, локальный stand-host и `adapt-stand-main.mjs`. `circle-model.mjs`, старое WALL4096×1280 и frozen stand-base не менялись. Перед сборкой регенерировать main; новые production-поставки получают оба дополнительных батника автоматически через сборщик. Обновление готовых папок не затрагивает data, ключи пары и игровые профили.

[Проверки и кадры](verification-pixel-map-20261023/README.md). Нативный Electron3072×1536, preview1536×768, четыре миссии, широкий кабинет, клавиатура/посты/витрина, отказ касаний на скруглениях. Физический LED-экран не проверялся.
