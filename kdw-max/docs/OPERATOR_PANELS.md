# Панели оператора MAX и Стеллы

## Запуск

На каждом стендовом ПК установлены обе программы. `Start-Admin.bat` в папке приложения запускает локальный сервер при необходимости и открывает отдельную вкладку браузера. Сервер также запускается автоматически с основным приложением; закрытие вкладки его не останавливает.

| Программа | Адрес на этом ПК | Ярлык на рабочем столе RC4.1 |
|---|---|---|
| MAX | http://127.0.0.1:18752/admin/ | KDW MAX RC4-1 - Admin |
| Стелла | http://127.0.0.1:18751/stella/admin/ | KDW STELLA RC4-1 - Admin |
| Голос/VST Стеллы | http://127.0.0.1:18751/stella/admin/audio/ | Ссылка из панели Стеллы |

Открытие панели Стеллы не выводит основную сцену на дисплей. Обычный Start после запуска только панели переводит приложение в штатный режим. Финальная сцена Стеллы — пиксельная. Выбранный дисплей применяется при следующем запуске окна.

## MAX

- Состояние двух Spout-потоков, счётчики кадров, состояние UDP-приёмника и количество пакетов
- ARM/DISARM: допуск ввода после визуальной проверки в TouchDesigner; новый запуск требует нового ARM
- Видимость курсора лидара, сохраняемая отдельно от его калибровки
- Режим входа, тайминги игры и Стеллы, бизнес и начальные значения полей
- IP отправителя/приёмника, UDP-порт, таймаут контакта и измеренные точки
- Пошаговая калибровка: четыре угла и независимая проверка центра

Калибровка доступна без активного посетителя. Она отключает ARM и показывает мишени в `KDW_MAX_CONTENT`; реальные игровые нажатия блокируются. Удерживайте руку на мишени и нажимайте «Зафиксировать точку» в панели. После четырёх углов измеряется центр: допустимая ошибка — 60 px. Сохранение доступно только после успешной проверки. Выход без сохранения возвращает прежние настройки; через 10 минут калибровка отменяется автоматически. ARM после выхода остаётся выключенным.

Настройки игры применяются к следующим играм. Сохранение настроек и калибровки проверяет ревизию; устаревшая вкладка получает конфликт и должна перечитать данные. Неверные диапазоны, неподходящие IP и вырожденная геометрия отклоняются. Изменение порта при ошибке запуска пытается восстановить прежний приёмник, оставляя ARM выключенным.

## Стелла: музыка и эффекты

Использованы 13 оригинальных WAV из MAX-банка прежней двухбрендовой Стеллы. Источник: `VK_DigitalProducts/artifacts/workspace/tasks/stella-autonomous-20261006/code/integrations/master/stella-candidate/public/audio/vk-production-v1`. Каждый файл проверен по SHA256 исходного manifest.json; новая копия и контрольные суммы находятся в `public/soundtrack/manifest.json`. Голосовые Screen*.wav не включены.

| Событие | Звук |
|---|---|
| Основные сцены после входа | AmbienceMain, один зацикленный источник |
| Кнопки | Click, с ограничением частоты |
| Смена сцены | ChangeScreen и варианты 2–5 |
| Вылет слов выбранного направления | Tags; при уменьшенном движении вылет пропускается |
| Начало отсчёта фото | ScanStart1 |
| Съёмка/отсчёт | Scan, временный цикл |
| Принятие снимка | ScanEnd1 |
| Дополнительные варианты в прослушивании | ScanStart2, ScanEnd2 |

Музыка, эффекты и остаточная громкость под речь регулируются отдельно. По умолчанию: 18%, 45%, 12%. Входная заставка молчит. При скрытии сцены, прослушивании посетителя, подключении и обработке запроса звук плавно выключается. Во время речи действует понижение громкости. Одновременно допускается до трёх коротких эффектов; устаревшие асинхронные загрузки не запускают звук после смены сцены.

Во время разговора музыка и эффекты подмешиваются в существующий выход и AEC reference, без второго параллельного воспроизведения через динамики. Голосовые пресеты и цепочки VST не заменяются. Проверку акустики, уровней колонок и распознавания при реальном шуме нужно проводить на площадке.

Прослушивание банка запускается только кнопкой, играет на ПК браузера и блокируется во время разговора/VST-сеанса. Оно останавливается при скрытии вкладки. Существующая панель микрофона, голоса и VST доступна отдельной ссылкой.

## Хранение и обновление

Локальные файлы: MAX `settings/stand.json`, `data/lidar.local.json`, `data/operator.local.json`; Стелла `data/soundtrack.local.json`, `data/display.local.json`. При записи создаётся предыдущая `.backup`. Голосовые секреты, профили, плагины, сертификаты и данные посетителей остаются вне публичных архивов. Обновление сохраняет существующие `data`, `settings`, `plugins` и профиль app.json. Панели доступны только на loopback; изменения требуют POST JSON с правильным Origin.

Физическая калибровка не создаётся автоматически. Проверка наличия пакетов не заменяет проверку геометрии рукой и проверку обоих Spout-потоков в TouchDesigner.

RC4.1: изменение revision внутри фотоэкрана не отменяет ScanStart/ScanEnd. Смена музыкального оформления привязана к смене сцены; внутренние capture/review сохраняют свои эффекты. Проверка фиксирует запуск AudioBufferSource, а не только скачивание WAV.
