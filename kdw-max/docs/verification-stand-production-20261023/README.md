# Проверка production Stella + MAX — 23.10.2026

Эта итерация реализует STAND_USER_JOURNEY и STAND_SETTINGS. Финальные машинные результаты находятся рядом; `passed: true` означает завершённый прогон, `running: true` — ещё выполняющийся. Старые отчёты linked-builds и production описывают предыдущую сборку.

- `browser-checks.json`: изолированный Electron 3072×1536, все четыре миссии, удержание ладони реальными mouse input events, автозачёт задач, QR, возврат, неявка, смена JSON, ручной выбор и независимое бездействие. Для полного прогона длительности ускорены; точные 30/60/120/15 секунд проверяются виртуальными часами ядра.
- `linked/browser-checks.json`: Stella с синтетической камерой → подтверждение фото → передача → MAX ждёт ладонь → переходы Digital ID. Проверяются одинаковый gameId/sessionId, пиксели полученного JPEG, 17 декодируемых динамических SVG, восстановление после reload, отсутствие фото предыдущего посетителя и возврат Stella после доставки.
- `manual/browser-checks.json`: отдельный короткий прогон неявки, смены режима в JSON без пересборки и ручной миссии.
- `network/checks.json`: проверка актуальных delivery-manifest, двух отдельных процессов встроенного runtime, передачи JPEG через TLS, чтения той же версии JSON на Stella, отказов при неверном сертификате/ключе/Origin, запрета доступа к администрированию/статике с LAN, outbox и перезапуска MAX.
- `delivery-update.json`: обновление всех четырёх каталогов; резервная копия заменённых файлов, число сохранённых приватных файлов, отсутствие перезаписи data/операторского JSON.
- `automated-checks.json`: ядро, шлюз фото/голоса, очередь/JSON и TypeScript.

Инструменты: `ops/stand-production-20261023/verify-browser.cjs`, `verify-manual.cjs`, `verify-linked.cjs`, `settings-hub.test.cjs`, `ops/production-build/verify.cjs`. Данные прогонов изолированы от реальных посетителей. Результаты камеры синтетические; генерация Qwen не вызывалась. Существующие голосовые/VST файлы сохранены, но аппаратный тракт заново не измерялся.

Исправленные находки: логотип standby ожидал GPU-ready старого заменённого IMG; подписи иконок сохраняли отступ от прежнего размера; финальный QR останавливал presentation tick, поэтому таймер теперь работает независимо и начинается после GPU-ready QR; смена JSON требовала отдельного namespace standby и стабильного снимка политики без диагностических полей.

Осталась физическая приёмка на стенде: расположение двух дисплеев, реальные touch-координаты и удержание, попадание в safe-зону, камера/микрофон/акустика и VST, два ПК через фактическую сеть. Калибровку выполняют отдельно от visitor production. На рабочем ПК firewall и хранилище сертификатов не менялись; GitHub/VPS этой итерацией не обновлялись.
