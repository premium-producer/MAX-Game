# Статистика пользовательского канала — 22.10.2026

Задание по-прежнему состоит из двух экранов: `blogger.statistics.menu` → `blogger.statistics.statistics`. Использованы `Профиль.svg` и первый по содержимому график `Статистика_скролл_Подписчики.svg` из предоставленной папки. Остальные позиции прокрутки не добавлены в игровой маршрут.

Профиль получает `name`, `avatar`, `description`, `visibility`, `slug` из общего `personalProfile(state)`, как предыдущие задания создания канала и комментариев. Публичная ссылка отображается только при публичном канале с заданным slug. Пользовательский текст экранируется; длинное название сокращается многоточием, описание прокручивается в своей области строго из двух строк (40px, line-height20px). Отдельный нижний ряд сохраняет исходные три SVG-контура многоточия слева и «Ещё» справа; нажатие «Ещё» прокручивает описание, не смещая этот ряд. Исходные шаблонные название, изображение и рекламное описание удалены из подготовленного SVG, включая GPU-подложку; оригиналы UI не изменены. Неизменяемые подписи, иконки, графики и поверхности взяты из SVG. Учебное число 219 144 из шапки исходного профиля используется также в строке подписчиков, вместо противоречащего ему 13 423. Графики не вычисляются из реальной аналитики MAX.

Действия и их идентификаторы сохранены. Строка «Статистика канала» и внешняя кнопка открывают график; кнопка под графиком завершает прежнее задание. Новые игровые экраны, ввод и сетевые сервисы не добавлены. Готовность ресурсов, displaySnapshot, alpha и блокировка уходящего экрана используют существующий механизм личного канала.
