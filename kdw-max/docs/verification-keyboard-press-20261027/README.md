# Отклик экранной клавиатуры

Исправлено локально. На стенды не отправлено.

Причины: OSC-касание активирует native DOM через программный click, который не гарантирует CSS :active; updateKeyboardPanel пересоздавал все кнопки при смене регистра/языка, обрывая их визуальный отклик.

В существующем kdw-keyboard-ui добавлен явный отклик 240 мс с подсветкой и небольшим нажатием, без задержки ввода. Общий native-touch вызывает его перед обработчиком клавиши для обоих data-pc-key/data-kdw-key. Обновление раскладки сохраняет существующие кнопки с тем же ключом/классом, включая Shift, язык, символы, пробел и нижние управляющие клавиши. Закрытие/открытие сохраняет прежнюю оболочку и её плавность. Reduced-motion оставляет подсветку без дополнительного движения. Повторный отклик отменяет прежний, по окончании таймер явно очищает анимацию и маркер, в том числе при скрытой клавиатуре. Дублирующий touch click по отпусканию по-прежнему подавляется.

Проверка: 174 существующих теста MAX прошли; build:max и check:generated. Браузер реальной сборки с memory-preview канала: CDP-touch на первую заглавную букву → ввод «Й» ровно один раз, сохранён тот же DOM-узел и работающая анимация; затем буквы/пробел/удаление/регистр/язык/цифры/символы/Готово, очистка отклика и reduced-motion. Ошибок JavaScript нет. Сценарий ops/production-build/keyboard-press-browser.mjs, результат рядом.

Новых production-компонентов и изменений в правилах игры нет. Frozen stand-base не изменён. Поставка на стенды требует отдельного запроса.
