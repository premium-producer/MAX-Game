# Незаметная подготовка сцены и фотошаблоны — 27.10.2026

Статус: исправлено локально по уточнению пользователя. На стенды не отправлено.

## Итоговое поведение

- Новых экранов загрузки или ошибок MAX нет. Скрытый #loading используется только как диагностический маркер. Полноэкранная заставка MAX, логотип и анимированные точки из предыдущего локального варианта удалены.
- Standby → миссия: элементы standby плавно уходят штатным motion-контроллером, ресурсы подготавливаются без видимого загрузчика, затем появляется штатная сцена миссии. Сохраняются документ, фоновый canvas и GPU renderer; location.reload при обычном production-переходе не вызывается.
- Назначения со Стеллы и ручной выбор используют один переход. Новая сессия получает владельца ввода; предыдущая закрывается после ухода элементов. Повторный запрос объединяется с уже выполняющимся переходом. При ошибке ручного запроса меню плавно возвращается.
- Для отсутствующей фотографии используется существующий нейтральный силуэт в текущем контейнере. Не рисуются новые MAX-экраны, сетки логотипа или заменяющие игровые кнопки. Реальные действия и серверные ограничения остаются штатными.
- Изображение подменяется после 1500 мс задержки, оригинал догружается в фоне. При появлении оригинала используется переход 360 мс. Устаревшая загрузка не заменяет новую фотографию, поздняя заглушка не перекрывает восстановившийся оригинал.
- Стелла сохраняет исходный entry-экран; технические сообщения подготовки/ошибок скрыты. При недоступности камеры — нейтральная фотография, повтор камеры и «Без фото». Повтор не расходует переход экрана; заготовка остаётся одним DOM-узлом между попытками и плавно исчезает при готовности камеры.
- Подробности сбоев остаются в логах. Валидация ввода, reduced-motion, освобождение ресурсов и калибровка сохранены. Frozen stand-base не изменён.

- Стелла: typecheck/сборка и 49 тестов прошли.

Результаты находятся рядом с документом. Это проверки локальных сервисов с искусственными сбоями, не аппаратная приёмка Spout/лидара на стенде.
