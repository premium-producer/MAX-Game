# Замер передачи фото Стелла → MAX

Фактический прогон: 2026-10-27T21:08:14Z–21:08:15Z (UTC). Работающие production API двух физических ПК, штатный local voice controller, result authorization, outbox-v2, закреплённый TLS-сертификат и парный ключ. Секреты прочитаны только на Стелле, в отчёт не выводились.

Два синтетических JPEG 1080×1920, 732405 и 732028 байт. Камера и реальные фото посетителей не использовались. Созданы отдельные голосовые сессии и назначения. Миссия и JPEG переданы через штатные localhost submit/photo endpoints; очередь и HTTPS-передача выполнялись установленным сервером Стеллы.

Измерено одним монотонным таймером на Стелле, без сравнения часов разных ПК и без времени SSH. Опрос результата каждые 100 мс: цифры включают ожидание обнаружения подтверждения. Это два наблюдения, не статистика задержек и не верхний предел. Не включены камера/JPEG-кодирование, рендерер MAX, декодирование/подстановка изображений или TouchDesigner/LED.

В каждом случае gameId и SHA256 на MAX совпали с отправленными; UUID сессий и SHA изображений различны между пробами. Чужой voiceSessionId → 409 PHOTO_CONTEXT_CONFLICT, точный повтор → 200 с той же SHA. Оба назначения отменены штатным API с 200, голосовые сессии завершены. Пользовательские сессии и конфиги не менялись, приложения не перезапускались.

Ограничение: assignment=unavailable в обоих прогонах. Перед тестом окно Стеллы выключено (server-only), на MAX фоновый Spout lastGoodFrameAgeMs=11190 и fresh=false; contentReady=true не доказывает исправный вывод. Поэтому факт отображения фото в реальном игровом кадре НЕ подтверждён. Для полного сквозного замера требуется рабочий вывод и прохождение с подтверждением фото и ладонью. Пользователю отправлен запрос на такой проход, ответа в этом прогоне нет.

Первый диагностический клиент ws отвергал сервер без echo subprotocol, в отличие от браузера. Исправлено только в тесте: заголовок Sec-WebSocket-Protocol передаётся без требования echo. Две неудачные попытки STATE_TIMEOUT не считаются измерениями. Поведение production API не менялось. Фоновый PowerShell-наблюдатель не создал файл наблюдений; его старт не считается успешным сбором данных.
