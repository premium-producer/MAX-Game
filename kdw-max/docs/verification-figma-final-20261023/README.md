## Оснастка и ограничения

`final-prepare.mjs` создаёт состояния через настоящее игровое ядро; `final-capture.cjs` снимает настоящий renderer после decode/GPU/fade. Короткие результаты проходят штатный вход из предыдущего экрана. CSS, шрифты, тексты и геометрия не подменяются. Анимация фиксируется в один момент. Фото — нейтральный шаблон.

Скриншоты предназначены для точного визуального представления, текст внутри PNG не редактируется. JSON-экспорт исходного каталога сохраняет readOnly=true/changes=[]. Реальный импорт в Figma Desktop в этой проверке не выполнен; проверены API-модель плагина и настоящий iframe загрузки. Физический стенд не проверялся.

Ранние `failure*` и временные профили в этой папке — следы предварительных прогонов; итоговые результаты перечислены выше. Основной отчёт `capture-checks.json` относится к последней полной пересъёмке.

По последнему запросу плагин обновляется только в постоянной папке. Архив23октября и archive-checks.json относятся к предыдущему состоянию до исправления однострочного поля; новые ZIP не создаются.

## Центрирование широких устройств

Размеры и масштаб не менялись; центр устройства x1440 на дисплее3072×1536. Само устройство остаётся внутри safe683.2..2196.8, справка может выйти правее, оставаясь на дисплее. Обычные browser/wall ветки сохранены. Правки внесены в main и адаптер; оснастка check-device-centering.cjs запускает адаптер без записи, проверяет обе точки изменения и измерения широких и вертикальных экранов из production-кадров. Результат — device-centering.json. Снимки Figma пересняты в прежнюю папку, без ZIP.
Итог центрирования:102 статичных состояния, включая33 широких. Максимальное отклонение от оси1440 —0.0317px. Ширина изменилась только в пределах float0.00013px; положение прежних телефонов —0.0212px. Проверка адаптера,114 CPU,6 проверок плагина,134 ресурса в opaque iframe,28 файлов локальных комплектов — PASS.

## Типографическая обработка

kdw-typography.mjs обрабатывает текстовые узлы при отображении, не меняя каталоги/ввод/действия. Предлоги и союзы связаны со следующим словом, частицы/тире с предыдущим, число с единицей. Сохранены явные переводы строк, URL/email и HTML escaping. Отдельные адаптеры kdw-ui-copy/kdw-shared-ui сохраняют исходные stand-модули и сравнение retention. Тесты проверяют цепочки коротких слов, регистр/границы, идемпотентность, escaping, неизменность состояния и удержание плашки. check-typography.cjs при захвате измеряет Range каждого символа в реальном Chromium и проверяет окончания строк всех справочных h2/p и overflow. Измерения записаны в diagnostics.typography каждого кадра, сводка — typography-checks.json.
Итог типографики:220 справочных блоков /353 строки проверены через Chromium Range; висящих коротких слов0, overflow0.118 CPU,6 проверок плагина,134 PNG и32 целевых файла production-комплектов — PASS. В примере канала первая строка заканчивается тире, вторая начинается неразрывной группой «и поделимся».
