# Единый материал emoji-кругов — 21.10.2026

Причина подтверждена исходным CSS и проверкой изображения: полупрозрачный градиент с backdrop blur смешивался с меняющейся подложкой. Поэтому поверх яркой карточки и вне неё круг имел разный цвет/плотность. Родительские анимации opacity также меняют условия композиции; отдельный дефект браузера этим тестом не доказан.

Исправление только в hybrid-cards.css: непрозрачная фиолетовая база и локальные градиенты, прежние кромка/блик/тень. Backdrop sampling убран. Все четыре круга имеют общий материал. Самостоятельное плавание, emoji, карточки, hover, общий fade входа/выхода и вылет слов не изменялись.

Проверено:

- Build PASS. Изолированный Firefox: исходная сборка 8 проверок PASS; новая 10 PASS на pixels/gradient, четыре одинаковых материала, реальное движение, вылет → photo → result → выбор, отсутствие provider turns и ошибок JS/визуализации.
- Контролируемая чёрная/белая подложка под фактическим compiled CSS: средняя абсолютная разница RGB внутренней области до исправления 160,18 из255; после —0, максимальная0 на обоих фонах. Изменение opacity родителя1→.999 в этой пробе не дало разницы ни до, ни после; это не воспроизведение всей анимации ухода.
- Снимок after-pixels.png просмотрен: четыре насыщенных фиолетовых круга со светлой кромкой, исходные emoji и геометрия сохранены. При намеренном fade всей карточки круг исчезает вместе с ней.

integration.cjs — изолированный сервер с mock-provider/виртуальной камерой, до/после www; before.json/after.json — результаты. pixel-comparison.json — сравнение PNG области x45..119/y45..119 внутри контрольного круга. before.css и before-manifest.json — исходное состояние. postflight.json — установленная версия и HTTP SHA. package-diff.json — изменения переносимого комплекта.

Физический GPU/дисплей, акустика и другой ПК здесь не проверялись. Нового движка, генерации речи или изменения голосового тракта нет. Конфиги/пресеты, игра, донор и UI-оригиналы не изменялись.
