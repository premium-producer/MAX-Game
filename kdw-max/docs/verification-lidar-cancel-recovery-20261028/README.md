# Восстановление касания лидара после отмены — 28.10.2026

Обновление статуса: 28.10.2026 в 09:05 МСК фикс установлен на основной MAX по явному запросу пользователя. Патч `TOUCHSTART-MAX-20261028-1`, complete; готовность Spout и успешные касания подтверждены, ошибок input=0. Подробности: `../stand-patches/TOUCHSTART-MAX-20261028-1/README.md`.

Первоначально исправление было локальным: пользователь перезапустил игру, управление восстановилось и попросил искать причины. До отдельного запроса на установку работающий стенд не перезапускали.

## Подтверждение

До перезапуска output PID19540: input active=true, OSC bound=true, 2227 пакетов / 2038 принятых обновлений, ноль ошибок декодирования и транспорта. Браузер зарегистрировал только pointerdown и pointercancel. В output.jsonl повторялось `lidar-input-error: Must send a TouchStart first to start a new touch.` примерно на каждом обновлении координат.

В lidar.mjs любая ошибка CDP выставляла needsCancel=true. Следующее касание сначала вызывало touchCancel. Если Chromium уже не держал контакт, отмена отклонялась той же ошибкой, needsCancel снова выставлялся, новый touchStart никогда не отправлялся. Курсор продолжал получать координаты через onPoint до CDP. Это подтверждённый самоподдерживающийся цикл. Точный первый повод рассинхронизации из старого журнала не установлен: раньше тип неудачной команды не записывался.

## Изменение

Только touchCancel/touchEnd и только точная ошибка отсутствующего начатого касания считаются уже выполненным освобождением. Новое touchStart доходит до Chromium. Иные ошибки не подавляются. В состоянии lidar.input и журнале добавлены тип команды, счётчик ошибок/восстановлений, последний успешный dispatch и recoveryPending. UDP-порт, калибровка, включённость ввода и управление миссией не менялись.

## Проверка

Регрессии моделируют реальный контракт Chromium: reset до отправки queued start; самопроизвольная потеря контакта; повторное завершение уже отпущенного контакта. На прежнем собранном lidar.cjs все три новых сценария воспроизводят неисправность (5 passed / 3 failed). На исправлении все38тестов ввода/OSC/калибровки прошли, включая настоящий UDP bind/reconnect. Сборка только apps/max-game/launcher/lidar.cjs. Не требуется пересобирать или передавать графические материалы.

Диагностика через PowerShell дважды задержалась; дальнейшие чтения сделаны через закреплённый selectel SSH и bundled Electron в режиме Node, ограниченным извлечением журнала. Полный профиль и фото посетителей не копировались.
