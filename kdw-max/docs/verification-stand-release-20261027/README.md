# Реальный стендовый RC: MAX + Стелла

27.10.2026. Выпуск `KDW-Stand-20261027-RC2`, Windows x64, Electron 44.4.5. Локальный комплект: `production/KDW-Stand-20261027-RC2`. Публичные обновления приложений отделены от локальных голосовых настроек, VST и runtime.

## Реализовано

- Один настоящий игровой renderer MAX в offscreen Electron: весь контент, DOM, устройства, ладонь, линки и интерфейсы — `KDW_MAX_CONTENT`, premultiplied alpha
- Отдельный пассивный renderer штатного LumiCells-фона — `KDW_MAX_BACKGROUND`; без второй игровой сессии, звука, очереди или хранилища
- Оба потока 3072×1536, DPR=1. Проверенный native D3D11 bridge сохраняет текстуру Electron до GPU completion, максимум три незавершённых кадра на поток
- Разрешение вывода через ARM с bootId, готовностью реального контента и шейдера. Перезапуск требует нового ARM; штатная смена страницы сохраняет разрешение после новой готовности. Потеря renderer/ошибка GPU останавливает вывод
- OSC HokuyoTracker2: компактные и прежние сообщения, верхняя точка по откалиброванному Y, один стабильный ID жеста, quarantine после timeout/смены контекста. Native touch, без прямых команд игровому ядру
- Стелла — обычное полноэкранное окно, опционально закреплённый displayId. Общий runtime, сохранённые сервисы и голосовой тракт

## Проверено

`npm run test:audit:all` завершился с кодом 0: 140 MAX + 7 shared-link + 9 Stella тестов, TypeScript, generated adapter, сохранение профиля при сборке, retention, браузерный аудит. `node ops/production-build/test-lidar.mjs`: 25 тестов протокола, выбора контакта и калибровки.

`native-osc-game.json`: реальный Electron, цикл OSC UDP → native touch → выбор «Общение» → удержание ладони → первое задание. Проверены disarmed/armed/disarmed и прозрачный CSS фона контента. `shutdown.json`: завершение без незакрытых GPU кадров. Тестовый sender — loopback, калибровка — явно синтетическая только в изолированной fixture.

`alpha-analysis.json` и PNG: независимый D3D11 Spout receiver получил настоящий игровой фон, прозрачный слой и композицию. У content 3 915 265 полностью прозрачных, 176 977 полупрозрачных и 626 350 непрозрачных пикселей; фон полностью непрозрачен. Это функциональная проверка слоёв на RTX 5070 Ti. У короткого захвата нет пригодной прогретой серии FPS: нулевые значения в поле receiver не являются измерением частоты игры.

`max-packaged-startup.json`, `stela-packaged-startup.json`: оба уже упакованных приложения запущены через Windows PowerShell 5 и общий runtime; оба verify exit 0. MAX при проверке остался disarmed. У Стеллы errors/missing пустые. После проверки созданные профили и журналы вынесены в локальный архив; приватные исходные настройки сохранены.

`archive-verification.json`: SHA каждого файла совпал с архивом и готовой папкой, общий sharedRevision совпал, data/runtime/plugins отсутствуют в ZIP приложений, значение локального API-ключа не найдено в текстовых файлах архивов. Проверка runtime-manifest штатным Install-Runtime.ps1 прошла.

## Ещё не аппаратная приёмка

Именно эти реальные сборки пока не проверены на CHUWI с TouchDesigner и физическим лидаром. Предыдущие 180 секунд двух синтетических потоков на CHUWI — отдельное доказательство GPU-транспорта, не приёмка игры. На стенде ещё проверить калибровку/неподвижную руку, карту вывода, дисплей Стеллы, микрофон/камеру/VST, все миссии и бизнесы, очередь и длительную нагрузку. Автоматического receiver ACK нет: оператор подтверждает показ через ARM. Автоматического обновления/отката работающего стенда этот выпуск не включает.

Архивы: MAX 376 948 075 байт, Стелла 30 071 245 байт. SHA256 перечислены в `production/KDW-Stand-20261027-RC2/archives/SHA256SUMS.txt`.
