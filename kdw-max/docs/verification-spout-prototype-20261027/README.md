# Аппаратная проверка двух Spout-потоков — 27.10.2026

## Объём

Изолированный Electron-прототип, нативный D3D11/Spout2-мост и отдельный GPU-приёмник. Тестовая сцена включает непрозрачный анимированный фон, прозрачные частицы/линии, DOM-текст, плашку и кнопку. Рабочие MAX, Стелла, их данные и профили запуска не заменялись. Полные игровые экраны, ввод посетителя и одновременная нагрузка Стеллы/камеры/VST требуют следующего этапа.

## Среда

CHUWI: Windows 10 Pro, Ryzen 7 5800H, около 16 ГБ RAM, AMD Radeon Graphics. Прототип запускается одноразовой Scheduled Task в интерактивной сессии 2. Runtime кешируется отдельно в `C:/KDW-Stand/prototypes/spout-v1/runtime/electron-44.4.5`, версии пакетов — в `releases/<releaseId>`. У задач нет триггера автозапуска.

Диагностический прогон `chuwi1920-v2` также завершён: 30 секунд отправителя и 35 секунд приёмника, оба ExitCode=0. Приёмник 1920×960: 59,933 FPS фон / 60,001 FPS контент, p95 19,5 / 18,3 мс. Альфа-калибровка совпадает. [Измерения](chuwi1920/analysis.json), [приёмник](chuwi1920/receiver-summary.json), [коды выхода](chuwi1920/exit.json). Повторный запуск использовал уже скачанные пакет и Electron; повторной загрузки runtime не было. Тестовые процессы завершены автоматически.

- Локально RTX 5070 Ti: независимый приёмник около 60 FPS в 3072×1536 и 1920×960; альфа-калибровка корректна
- Начальный размер BrowserWindow ограничивался физическим монитором; после создания применяется `setContentSize`, каждый полученный размер GPU-текстуры проверяется
- Frame counter Spout включён только в скомпилированном SDK прототипа, без изменения глобального реестра
- Снимок через CPU readback выполняется однократно после трёх секунд; статистика FPS считается после пяти секунд. Обычная передача и композиция — GPU
- PowerShell 5 терял ExitCode у завершившегося Process; wrapper сохраняет Handle заранее и вызывает WaitForExit. Отдельная локальная проверка именно в PowerShell 5: оба ExitCode=0
- Первый CHUWI-прогон: отправитель работал 180 секунд без ошибки и освободил все текстуры; приёмник завершился примерно через 72 секунды, причина закрытия окна не подтверждена. Этот прогон не считается полной приёмкой
- Во второй версии приёмник по умолчанию скрыт, пишет elapsedMs/completed и возвращает ошибку при досрочном закрытии. Для визуального окна доступен `-Preview`

## Повторение на рабочем ПК

```powershell
./ops/spout-prototype/build.ps1
python -B ops/spout-prototype/stand.py deploy --release spout-probe-20261027-093235 --sha256 6ba11a992d6a3e27270f9a44b21fce495118e773b148c61dcbc1a6bcf7c42fe9 --run my-new-run --seconds 180 --width 3072
python -B ops/spout-prototype/stand.py status
python -B ops/spout-prototype/stand.py collect --run my-new-run --output .cache/spout-prototype/results.zip
```

RunId — латинские буквы, цифры, `_` и `-`; имя должно быть новым. Контроллер использует существующий проверенный SSH-доступ Producer Kit и не копирует ключи на стенд. Пакет скачивается самим стендом с GitHub. Диагностический ZIP возвращается по SSH и не содержит браузерного профиля.

Для другой версии указать её releaseId и SHA256. На этом этапе это повторяемая поставка прототипа, а не готовый атомарный обновлятор всего MAX/Стеллы с автоматическим откатом.
