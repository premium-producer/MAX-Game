# Локальный фильтр текста — 21.10.2026

Реализовано в локальной игре MAX: название/описание канала, публичная ссылка, комментарий и прежний редактор. Новый текст очищается до сохранения. При уверенном совпадении удаляются исходные символы слова; остальной текст и исходные пробелы сохраняются, позиция курсора/выделение пересчитываются. Уведомление на2,2с видно в телефоне и на открытой клавиатуре. Поля/фон/рамки приложения не пересоздаются.

## Источник и правила

Готовые152русские и415английских словарных записей взяты без изменения из `glin-profanity@3.3.0`, проверенного npm-архива. У upstream есть неоднозначные обычные слова, тестовая запись и медицинские термины; поверх исходных данных задан явный список исключений. Дополнительные русские формы и целиком привязанные сильные основы покрывают типовые окончания. Движок glin/React/ML/WASM/API не включены: поиск по локальным Set и ограниченным правилам возвращает диапазоны оригинального UTF-16 текста. Нормализация используется только для сравнения. Проверены регистр/ё, Unicode-аналоги, цифры, повторы, zero-width и ограниченные разделители между короткими частями. Это словарная фильтрация, а не гарантия определения любого оскорбительного смысла или любого обхода.

Версия — `kdw-text-v1`. Неоднозначный префикс можно дописать («хер…»→«Херсон», «бля…»→«бляха»). Он проверяется окончательно при вставке/разделителе/blur/отправке; незавершённый префикс не уходит в autosave. IME не прерывается: проверка после compositionend, финальная — на подтверждении. Смена экрана/повтор миссии очищает composition и таймер уведомления.

## Авторитетное сохранение

SAVE_INTERACTION и подтверждения проверяются ядром; неочищенное новое значение даёт TEXT_NOT_ALLOWED даже без клиентского textPolicy. Нативные текстовые команды содержат версию политики. При восстановлении старые команды без версии сохраняют принятую семантику и данные; история не переписывается. Изменение правил/словаря требует новой версии и сохранения предыдущих правил для уже принятых версионированных команд.
