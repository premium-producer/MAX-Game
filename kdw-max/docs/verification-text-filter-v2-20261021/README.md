# Строгий фильтр текста v2 — 21.10.2026

По прямому уточнению пользователя обычные слова с подозрительным корнем тоже удаляются: исключений для «страхуй»/«спорно» нет. Поиск идёт внутри токена, удаляется токен целиком, включая добавленные буквы. Добавлены сексуальная лексика, корни и проверенные написания: «пенис», «порно», «рхуй», «щлюха» и формы. Нет внешних запросов или ML; словарь/правила не обещают распознавать любую новую маскировку.

## Поведение

- Общая политика `kdw-text-v2`: название, описание, ссылка, комментарий; прежний редактор использует тот же модуль.
- Корень удаляется сразу при распознавании, без ожидания возможности дописать обычное слово. Введённые после удаления буквы — новый ввод. IME проверяется после завершения композиции.
- Исходные диапазоны UTF-16, курсор/выделение, остальные слова и уведомления сохранены. Одиночные буквы не становятся запрещёнными из-за свёртки словарного `xxx` в `x`.
- Цепочки отдельных букв через пробел и короткие фрагменты через точки/разделители проверяются; обычная фраза «the pen is blue» не склеивается в одно слово.
- Ядро проверяет новые команды текущей политикой даже со старым клиентским маркером или без него. Только восстановление принятой квитанции выбирает прежнюю политику.
- `kdw-text-policy-v1.mjs` побайтно совпадает с предыдущим модулем (SHA256 `35cf7f72bd37bde12d336546a370d2233f5444b34d1616ee09d8e83e1946148b`). Исходные glin-словари/лицензии не изменены. V1-квитанции с прежде разрешёнными словами корректно восстанавливаются, новые такие значения отклоняются.
