# MAX · управление игрой из админки

Откройте существующую админку MAX, раздел «Текущая игра». Здесь показаны миссия, задание, текущий экран, его номер и таймер. Состояние обновляется автоматически.

1. Выберите миссию и нажмите «Запустить выбранную миссию». Текущая сессия завершится, появится ладонь выбранной миссии. Способ входа в настройках для этого менять не нужно.
2. «Вперёд» и «Назад» переключают отдельные экраны выбранной миссии, включая переходы между заданиями. На границах и во время анимации кнопки отключены. Просмотр оператором не считается самостоятельным прохождением посетителя.
3. «Завершить сессию · Главное меню» закрывает только текущее назначение и возвращает экран в standby. Оставшиеся посетители сохраняются в очереди; следующий может быть приглашён автоматически.

Если данные устарели или вывод не запущен, управление экранами недоступно. При сообщении об изменившемся экране дождитесь обновления и повторите нужное действие. Служебные команды работают только со штатным desktop-выводом MAX; обычный preview браузера не получает эти права. Настройки таймингов, звука и калибровка остаются в прежних разделах.
