# Вход в магазин и перелёт товара — 20.10.2026

Локальная итерация `KDW-MAX-STORE-ENTRY-20261020`.
Bundle SHA256: `2fcfc28e03386b6a171d88b614c83c7d12d7984a2b7feda870f5922bd9ae3b73`.

Причины:

- Вход в магазин монтировал HTML только после phase=task; рамка уже была видна на phone-enter. В baseline получены восемь замеров с прозрачностью телефона выше 0,5 и отсутствующим каталогом.
- Blur безусловно отзывал владельца даже у видимого preview. В baseline после blur координаты карточек переставали меняться.
- CSS скрывал детей старого button в ячейке. Новая ячейка использует div.kdw-slot-content, поэтому принятый товар был виден до окончания перелёта.
- Проверка нового входа обнаружила START_STORE_ALREADY_STARTED (код ядра STORE_ALREADY_STARTED): следующий кадр ещё видел старый снимок. Проверка наличия активности перенесена на актуальную session.snapshot.

Исправления: каталог готовится на trace/phone-enter, ввод включается только в task; локальный владелец зависит от видимости вкладки, а не фокуса окна; слот резервируется до асинхронного подтверждения, содержимое скрывается до посадки.
