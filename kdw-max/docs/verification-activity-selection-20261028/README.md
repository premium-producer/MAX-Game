# Плавный выбор WebGL-карточек — 28.10.2026

Исправлено локально по замечаниям о резкой остановке, перестановке слоёв и сером провале в витрине. Стенд этим изменением не обновлялся.

## Причины и изменения

- Раньше при нажатии сохранялась неподвижная поза и карточка сразу получала opacity 0,75. Теперь берётся скорость последнего показанного кадра и за 320 мс плавно снижается до нуля по интегралу `v(t)=v0*(1-t)^2`. Геометрия начала перелёта берётся после торможения, без возврата к точке нажатия. ACK сервера не обрывает торможение.
- Раньше выбранные карточки рисовались после всех падающих, меняя взаимный порядок. Теперь каждой карточке при появлении присваивается постоянный layerOrder. Падающие, ожидающие, перелетающие и уходящие карточки собираются в общий упорядоченный список. Порядок hit-test соответствует отрисовке; выбранные объекты закрывают касания лежащих под ними карточек, не отправляя повторный выбор.
- Исходная поверхность карточки плавно исчезает за 260 мс; фото перелетает за 850 мс. Появление карточки внутри телефона занимает 420 мс. При ручной прокрутке канала, когда перелёт не нужен, выбранная карточка также тормозит и плавно уходит.
- Раньше белая ячейка удалялась при начале перелёта, показывая серую подложку. Теперь белая ячейка остаётся во время полёта и плавно уходит одновременно с появлением заполненной карточки.
- Reduced motion, правила выбора/оценки, сохранение, серверные команды и транспорт лидара сохранены.
