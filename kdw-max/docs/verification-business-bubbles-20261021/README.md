# Размер сообщений бизнес-бота

В `business.bot.result` текст уже менялся по отрасли, а старые SVG-баблы оставались фиксированными81/98px. Теперь переменные сообщения имеют нативную раскладку по строкам. Форма/градиент фона, время/галочки, статичные сообщения и кнопки сохранены из исходного `UI/new_screens/busines_no_sort/экран.svg`.

`kdw-business-messages.mjs` задаёт общий поток. Высота — текст и исходные отступы; короткая однострочная реплика сужается в пределах исходного максимума. Метаданные находятся снизу справа: если последней строке недостаточно места, резервируется13px. Шрифт17px/20px не уменьшается для подгонки под старую высоту. Соседние элементы следуют за новым размером; при переполнении тело диалога прокручивается, шапка и композер неподвижны. Кнопки используют прежнюю команду ядра и ведут к витрине.

`prepare-business-components.cjs` дополнительно извлекает13фрагментов. Поверхности выбираются непосредственно из исходных фигур (индексы120/144 закреплённого SVG), исходные маски/градиенты сохранены. Девять участков `border-image` сохраняют углы при изменении высоты/ширины. Время/галочки выделены на прозрачном фоне, независимо от старого бабла. Исходники UI не менялись.

Слой загружается прежним ограниченным кешем/Blob URL, ready по-прежнему не зависит от видимости. Измерение DOM выполняется после снятия hidden, до следующего кадра; дробный масштаб учитывается при резервировании места под время.
