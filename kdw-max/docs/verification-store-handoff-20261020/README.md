Причина визуального разрыва в коде: поток удалял принятый товар, а отдельный клон изображения создавался после ожидания команды с opacity 0 и затем проявлялся в RAF. Подпись и корпус исходной карточки исчезали сразу.

После подтверждения ядром уже существующее изображение летит в зарезервированную ячейку. При задержке команды оно остаётся видимым; при отказе/ошибке резерв и клоны снимаются, исходная карточка восстанавливается, если ещё существует в потоке. Уход из задания очищает анимации. Reduced motion сохраняет непосредственное заполнение после подтверждения. Рейтинг/сохранение и подтверждение выбора остаются в ядре.
