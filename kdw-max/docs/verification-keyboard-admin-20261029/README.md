# Настройка клавиатуры в админке — 2026-10-29

Локальное обновление, без установки на стенд. Включает ранее подготовленное расширение маленьких hotspot-зон.

В существующем редакторе композиции добавлен раздел «Клавиатура»: X −1536…1536 и Y −768…768 в координатах дисплея 3072×1536; ширина 50…150%; высота клавиш 50…200%. 100% сохраняет нынешнюю суженную/поднятую клавиатуру. Положительный Y направлен вниз. Настройки общие для экранов внутри выбранного профиля, с независимыми шириной и высотой клавиш.

Поля работают через существующий preview/SSE, предпросмотр iframe, сохранение, отмену и переключение профилей. Старые профили без поля keyboard сохраняют исходное поведение и не мигрируются при чтении. Параметры клавиатуры применяются к DOM-геометрии, которую использует выбор касания; клавиши и hit-area перемещаются вместе.

Каждое открытие клавиатуры сбрасывает язык, символы и регистр: русский с заглавной первой буквой для обычного текста; английский со строчной для slug/ссылки. Переключение языка сохраняется до закрытия или смены поля. Личный канал и прежний редактор канала используют это правило.

Проверки: 19 unit-тестов (профили, строгие границы, старые настройки, preview/CAS, переключение и сохранение, геометрия касаний); build:max, build:shared, check:generated. Браузерный сценарий `node ops/production-build/keyboard-admin-browser.mjs`: реальные контролы админки меняют открытую игровую клавиатуру, отмена возвращает размеры, сохранение фиксирует профиль; повторное открытие обычного поля возвращает русский, ссылки — английский. Подробности успешного запуска в browser.json. Физический стенд не проверялся.
