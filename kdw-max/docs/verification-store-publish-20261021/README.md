# Завершение витрины одним нажатием — 21.10.2026

Рейтинг 4,9 автоматически меняет состояние текущего нативного экрана: товары/след затухают за 280 мс, штатная справка возвращается, кнопка становится «Опубликовать витрину». Телефон и каталог не пересоздаются и не скрываются. Последний выбранный товар завершает полёт до доступности публикации.

В нативный каталог добавлены действия `business.store.{start,publish,result}.publish-now` с `complete-task`. Они проходят прежние проверки рейтинга/состояния/ревизии и сохранение ядра. Новое прохождение использует только первое действие. Два других позволяют завершить старое сохранение с любого прежнего промежуточного экрана. Старые действия и исходный каталог не изменены — receipts продолжают восстанавливаться. Дополнительного UI-флага завершения нет.

Возврат справки потребовал точечной адаптации `visit` в `journey-webgl-ui.mjs`: у справки нативного магазина динамическая CSS-прозрачность больше не запекается в базовую прозрачность материалов. Она уже учитывается при каждом GPU-кадре. Иначе панель оставалась невидимой при корректном DOM opacity1. Исходник замороженного донора сохранён; набор затронутых базовых файлов по-прежнему входит в шесть разрешённых адаптаций сборки.
