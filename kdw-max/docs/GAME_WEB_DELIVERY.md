## Подтверждённый основной сценарий

Вход должен выглядеть как на стенде. Обычный запуск portable и веб-игры показывает настоящий standby из `journey-v5-idle-menu.mjs`: логотип MAX, исходный TV-ролик в устройстве и четыре иконки первых заданий миссий. Используются исходные векторные glyphs заданий, а не большие mission-card/mission-choice. Дев-меню, «Обнулить миссии» и подписи покрытия не входят в основной сценарий; debug=1 остаётся явным техническим просмотром.

Прежний автоматический телефонный интерфейс с плашками отключён. На desktop, landscape и portrait используется одна полная сцена. Старые `display=touch`/`display=scene` не переключают её на отдельное приложение. Исходники прежнего touch UI сохранены как история, его JS/CSS в выпуск не включаются.

Нативные `journey-v5-idle-menu.mjs` и `journey-v5-idle-layout.mjs` совпадают с закреплённой установленной базой 7 октября. [SHA/границы адаптаций](verification-standby-20261019/lineage.json). Единственные изменения хоста — подключить этот компонент при локальном menu, отправить SELECT_MISSION через существующий SessionPort и вернуть standby при «Назад». Не реализован новый UI, копирующий его внешность.

Геометрия standby — 4096×1280. Общий план браузера заранее учитывает её и все миссии: при одинаковом окне переход из standby в задание не меняет масштаб. На узком экране вся сцена уменьшается целиком; для просмотра на телефоне полезна горизонтальная ориентация. После reload показывается standby без dev recovery-диалога; выбранное сохранённое задание продолжается сразу через иконку. Прогресс не сбрасывается.

## Ассеты и бюджет загрузки

- Сначала загружается ограниченная оболочка: модули, шрифты, логотипы и glyphs. Изображения задач до выбора не запрашиваются.
- Standby добавляет **один** 30-секундный ролик. Portable сохраняет оригинал 1920×1080, 19 816 649 байт. Веб-производная того же видео: 1280×720, H.264/AAC, faststart, **3 509 367 байт**, SHA `9625418092337e279fb5470af706451238ba681b297ed22db73464644b6ee96a`.
- Видео декодирует media element и показывает существующий VideoTexture; HTTP Range отдаёт поток. Оно не загружается через arrayBuffer/SHA-preload всей библиотеки. Размер и SHA проверены при экспорте и публикации.
- Текущие/ближайшие игровые изображения используют существующую ограниченную подготовку и освобождение GPU-текстур. Нет загрузки всего каталога или всей миссии на старте.
- PNG → lossless WebP и встроенные PNG в гибридных SVG сжимаются без правки оригиналов. Канонические пути/контракты каталога сохранены; `aliases` переводит URL на web-производные.
- `asset-manifest.json` содержит размеры/SHA, source path/SHA производных, shell, группы задач/миссий и standby metadata. `WebAssets` объединяет запросы, проверяет размер и SHA при доступном Web Crypto, делает до трёх попыток с тайм-аутом 15 секунд. Используйте HTTPS.

Локальная проверка первого готового standby: сумма объявленных размеров HTTP-ответов **6 030 786 байт без сжатия**, включая запрос полного web-ролика; ноль изображений миссий. После четырёх входов/возвратов foreground texture residency — 71 407 832 байта RGBA. Это учёт текстур переднего плана, не полная память процесса/GPU и не аппаратная приёмка.

Публичный CDP-журнал включает отдельный Range media request. `encodedDataLength` появляется после завершения запроса; сумма уже завершённых ресурсов в момент готовности первого кадра **не равна полному трафику ролика**. Не выдавать эту частичную сумму за размер всей загрузки. Прежние оценки 0,22/0,77 МБ для телефонного меню относятся к исключённой версии 18 октября.

Сначала загружать новый immutable release, затем index; старые выпуски не удалять, пока ими пользуются вкладки.
