# Относительная композиция MAX

Редактор: админка MAX → «Масштаб и расположение» → «Игровые экраны».

## Настройки

- Размер устройства — процент исходного размера в выбранном профиле. Пропорции экрана сохраняются, содержимое и области касания следуют за ним.
- Центр X/Y — смещение в процентах базовой ширины/высоты композиции при текущем общем масштабе. «По центру игровой области» возвращает устройство в центр области игры и обнуляет относительные смещения.
- Ширина иконки и справки — процент единого базового размера композиции. 100% соответствует логической ширине390 при базовой высоте800, масштабируется вместе со всей сценой, но не вместе с отдельным устройством.
- Три горизонтальных промежутка: между соседними иконками, от правой иконки до левого края устройства, от правого края устройства до справки. Все заданы в процентах того же базового размера.
- Промежуток справка → кнопка использует тот же базовый размер. Кнопка центрируется под справкой, а общий блок справки и кнопки — по высоте относительно устройства. Боковая граница зоны касаний больше не сдвигает кнопку в сторону от справки.
- Пустые поля размера иконок/справки сохраняют исходный размер. Поэтому устройство можно увеличить отдельно. При заданной ширине в процентах элементы следуют общему масштабу. Смена телефона на широкий компьютер, увеличение отдельного устройства и увеличенный игровой телефон не меняют размер иконок/справки или выбранный центр. Пустые отступы используют пропорции прежнего макета.

«Прежний масштаб всего блока» сохранён отдельно в сворачиваемом блоке. Старые абсолютные смещения из ранее сохранённых профилей продолжают читаться, но новые игровые смещения задаются относительно устройства. Standby и калибратор не изменены.

## Профили и live

Сохраняются прежние профили и уровни наследования: вся игра → тип устройства → отдельный экран. Отдельные relative-поля наследуются по одному, например исключение для промежутка не отменяет общий размер устройства. Live использует существующий SSE/черновик: сохранение фиксирует профиль, отмена и переключение возвращают сохранённые значения. Никакие параметры игры или очередь посетителей редактор не меняет.

Формат остаётся schemaVersion:1. Необязательный game/devices/screens.relative содержит deviceScale (множитель), centered (bool), centerX/Y, iconWidth, referenceWidth, iconGap, iconsDeviceGap, deviceReferenceGap, buttonGap (проценты). Старые JSON без relative валидны и не переписываются при чтении.

Геометрия рассчитывается в kdw-composition-layout.mjs и используется для DOM, GPU, областей нажатия и линков. Кнопка внутри DOM устройства получает компенсацию масштаба родителя, чтобы соответствовать справке. Обычные кнопки внутри телефона остаются частью устройства. Новые компоненты, экраны и API не добавлены.

Установлено на основной production-MAX 28.10.2026, патч RELATIVE-LAYOUT-MAX-20261028-1. Сохранённые профили не заменялись.

Уточнение28.10: геометрия берётся из исходной позы, а штатная анимация применяется поверх неё. Порядок иконок — порядок маршрута, ладонь/продолжение не упаковываются в ряд заданий. Профиль отдельного экрана выбирается по реально показанному кадру, а не по следующему состоянию сервера. Резкие изменения корректирующей геометрии при переходе сглаживаются тем же кадровым циклом. Новое исправление после RELATIVE-LAYOUT-MAX-20261028-1 пока локальное.


## Отдельные проценты устройств

В «Игровые экраны» добавлены «Компьютер, % обычного устройства» и «Игры с падающими карточками, %», оба10–200%. Они умножают размер обычного устройства в этом профиле; иконки/справка не увеличиваются. Значения по умолчанию: компьютер100%, карточки120%. Карточки применяются к постам канала и витрине, заменяя прежнее жёсткое увеличение1,2 в KdwTaskJourney. Поля профиля: relative.pcScale / cardsScale, множители0,1–2.

Изменения размера сглаживаются в существующем кадровом проходе V5MotionValue, включая изменения из админки и большие переходы10→200%. Центр сохраняется, оба размера изменяются равномерно без искажения пропорций. reduced-motion по-прежнему отключает анимацию. Новых компонентов/таймеров/сетевых сервисов нет.

Проверка новых процентов: docs/verification-device-percent-20261028. Пока только локально.
