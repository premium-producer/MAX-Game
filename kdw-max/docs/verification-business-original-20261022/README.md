# Итерация «Кофейня — исходные экраны»

Отдельный вход: `/webgl-v5/cafe-original.html?backend=local&view=game`.
Основной `/webgl-v5/client.html` сохраняет версию с кастомными SVG для сравнения.

## Состав

- После ладони сразу открывается регистрация, без выбора типа бизнеса. Единственный бизнес — кофейня.
-16статичных экранов регистрации, создания канала и чат-бота восстановлены из архивных PNG `assets/figma-20261003`, с SHA256 из `client/vendor/backend-figma-v2/manifest.json`. В этой итерации отсутствует слой `kdw-business-native`, подстановки профилей и новые SVG-поверхности. Восстановлен исходный маршрут регистрации, включая прежний финальный экран.
- Семантические действия и последовательность взяты из исходного reviewed-каталога. Координаты активных областей нормализованы к разрешению PNG: в частности, исходное подтверждение1759×1100 отличается от reviewed SVG880×550.
- Игровые посты и витрина остаются живыми: прежнее падение, выбор, полёт, прокрутка, оценки и завершение. Остальные миссии не меняются.
- Сохранения имеют отдельную contentRevision `.cafe-original-v1`, которая входит в ключ IndexedDB. Данные версии с кастомными экранами не мигрируют и не сбрасываются.

## Проверка

Модельные тесты:96/96. Проверены точные SHA всех16PNG, нормализованные области нажатия, отсутствие выбора бизнеса, исходный маршрут регистрации, восстановление квитанций и неизменность игровых активностей/основного каталога.

Браузерный маршрут и скриншоты — в [checks.json](checks.json). Проверка проходит через меню и ладонь, все16статичных экранов, живые посты кофейни и витрину. В браузерном аудите набор очков постов пропускается штатной кнопкой, чтобы отдельно проверить весь маршрут; механика активностей проверяется общей модельной серией.

Сборка локальная; физический стенд и публикация на внешнем сервере не проверялись. Исходные UI и замороженная stand-base не изменялись.
