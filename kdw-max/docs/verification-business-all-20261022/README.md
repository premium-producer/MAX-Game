Основная игра: `/webgl-v5/client.html?backend=local&view=game&v=business-all-v1`.
Выбор: кофейня (`cafe`), цветочный магазин (`flowers`), автомастерская (`auto`). Выбор сохраняется на весь маршрут. Исторический `sports` не переименован; прежние ID сохранены для воспроизведения истории. ## Ресурсы и поведение

- UI-оригиналы и ZIP не изменены. Подготовленные копии32SVG сохраняют контурные подписи, значки, поверхности, маски и градиенты. Все области нажатия заданы в координатах SVG viewBox.
- `prepare-business-all.mjs` выносит растры в файлы по SHA256: примерно83,6МБ исходных SVG превращаются в29,7МБ общих ресурсов. В JS входят метаданные, без base64 картинок.
- Загрузчик готовит текущий экран выбранного бизнеса, собирает его зависимости в Blob, ждёт decode независимо от видимости. Хранит до4декодированных экранов, отменяет запросы и освобождает Blob URL при закрытии. При ошибке показывает повтор загрузки.
- `prepare-business-logos.cjs` извлекает эмблемы из шапок17.1/17.2/17.3 для выбора и игровых аватаров. Фото посетителя в аккаунте на2/3 остаётся отдельным ресурсом стелы; эмблемы бизнеса им не подменяются.
- Автомастерская получает отдельный банк8постов (5полезных) и6товаров (4подходящих). Масло здесь полезный товар; в кофейне его прежняя роль не меняется. Цветы и кофейня сохраняют свои игровые банки. Механика падения, выбора, полёта в телефон и начисления рейтинга сохранена.
- При переходах18→19→20 проверка рейтинга применяется к игровой витрине, а не к предварительным настройкам. Старые сохранённые переходы прямо к игре продолжают строго воспроизводиться по квитанциям.
