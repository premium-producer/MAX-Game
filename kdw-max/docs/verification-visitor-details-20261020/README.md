## Способ реализации

Это локальная композиция, а не полная нативная перевёрстка. Пять экранов бизнеса имеют PNG-подложку с новым круглым фото; два — сохранённое векторное содержимое SVG с новым фото. Исходник выбора канала берётся с уже исправленными иконками меню. Первый чат общения — PNG-подложка с новыми временами. Оригинальные исходники не меняются. Геометрия и действия этих восьми экранов сохранены; новые ресурсы имеют те же размеры.

`prepare-visitor-details.mjs` сверяет SHA исходников и использует `visitor-placeholder.webp` из подготовки общения, а также общий `VISITOR_CAPTURE`. Все семь фотослотов совместимы с `composeVisitorScreen`. Состав и происхождение записаны в `kdw-visitor-details-assets.json`.
