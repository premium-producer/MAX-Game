# Появление главного меню

Общий alpha старого меню отсчитывался до завершения decode и загрузки текстур. Готовый позже ресурс получал уже alpha=1. Все иконки также входили одновременно.

`kdw-idle-menu.mjs` сохраняет исходный маршрут/видео/выбор, но выделяет отдельный V5MotionValue каждому из шести элементов. Прогресс идёт только после готовности ресурса, пока меню активно. Задержки: логотип0, видео100мс, иконки200/290/380/470мс. Исходный maath обеспечивает плавность и разворот при restore. Renderer добавляет подъём36единиц и масштаб0,96→1 к одной общей позе GPU и DOM. Reduced-motion снимает задержки и движение. Выход, watchdog и освобождение видео сохранены; stand-base не изменён.

## Проверка

`apps/max-game/source/verify-idle-reveal.cjs` запускается в скрытом Chromium/Electron1920×1080 с реальным WebGL. Запросы логотипа/MP4 намеренно задержаны1800мс. Проверены:

- Первый вход: все шесть элементов начинают с нулевой прозрачности, затем проходят промежуточные кадры и достигают готовности.
- Реальное нажатие бизнес-миссии, появление ладони, возврат кнопкой «Назад»: вступление повторяется.
- Первое ненулевое alpha около0,02, а не1; по24–26промежуточных кадров каждого элемента. Интервал первой/последней иконки около280мс.
- Через CDP включён prefers-reduced-motion: прозрачность только0/1, без анимации.
- Ошибок консоли нет.

Результат: `checks.json`, покадровые данные `frames.json`, конечный вид `menu.png`.
