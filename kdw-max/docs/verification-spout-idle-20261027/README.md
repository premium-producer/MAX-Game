# Spout: прозрачное меню до ARM

Причина в renderer: `outputHidden()` возвращал true при ARM=false, а `idleMenu.tick` использовал этот допуск для reveal. Все элементы меню оставались с нулевой прозрачностью, хотя фоновый поток продолжал рисоваться.

Исправлен только reveal стартового меню в `adapt-stand-main.mjs`: для desktop Spout меню анимируется до ARM. Обработчики ввода, owner, таймеры и допуск реального прохождения сохраняют прежние ограничения. Frozen stand-base не изменён.

Проверки: 140 тестов MAX, check:generated, Chromium с simulated desktop preload и ARM=false. Четыре иконки имеют полную видимость; нажатие не меняет статус menu; ошибок browser нет. `disarmed-content.png` проверен визуально: логотип, видео и четыре пункта действительно нарисованы. Тест не имитирует физический Spout transport.

Пакет `SPOUT-IDLE-20261027-1`: только app.js и два build manifest, 684 735 байт. Предыдущие настройки/ARM не меняются. Применяется готовым установщиком на обе production-копии MAX; CHUWI исключён.

При диагностике обнаружено: предыдущее восстановление через Start-Process из SSH выполнялось вне интерактивной сессии. Такой запуск непригоден для проверки GPU и мог объяснять повторный `Shared GPU texture unavailable`; первоначальный сбой shared-texture этим ещё не объяснён. Восстановление основного MAX выполняется через Scheduled Task с Interactive token DR7, как штатная установка. Автоматически ARM не включается.

## Подтверждение на стенде

Обе установки `SPOUT-IDLE-20261027-1` завершены complete; конфигурации сохранены. Основной MAX восстановлен в интерактивной console-сессии DR7, ARM=false, backgroundReady/contentReady=true; счётчики обоих потоков растут (`output.json`).

Независимый DirectX Spout receiver на DR7 за 10 секунд получил по 598 кадров каждого слоя (~59,8 кадров/с). Реальная текстура CONTENT 3072×1536 содержит 626442 непрозрачных и 176826 полупрозрачных пикселей, остальное прозрачно; BACKGROUND полностью непрозрачен. Это подтверждает, что контентный поток больше не пустой (`alpha-probe.json`). Фото/полное прохождение в этом тесте не проверялись.

Дополнительная попытка полной проверки Стелла → MAX завершилась `fetch failed`; этот отдельный сценарий не объявляется пройденным. Состояние контентного Spout подтверждено непосредственно независимым приёмником.
