# Восстановление касаний после перезапуска renderer

Патч 30.10.2026. Установлен на диск production MAX в 13:38 МСК без перезапуска. Применится при следующем полном запуске MAX. См. docs/stand-patches/LIDAR-RECOVERY-MAX-20261030-1/README.md.

В логах MAX 13:26:12 МСК renderer content завершился (clean-exit), картинка восстановилась в 13:26:14. После этого acceptedUpdates продолжал расти, lastSuccessAt отправки касаний остался на 13:26:12; следующая миссия завершилась no-show. Вероятная причина — незавершённый CDP promise блокирует последовательную очередь.

Изменение: source/stand-output/lidar.mjs. Каждая CDP-команда ограничена 1000 мс; тайм-аут отсоединяет debugger, следующий контакт переподключает его и отменяет старый жест перед touchStart. Штатный reset при навигации сбрасывает поколение очереди, прерывает ожидание команды и переподключает debugger. Старые callbacks не меняют состояние нового поколения. UDP-приёмник и калибровка сохраняются. Просроченные команды очереди пропускаются. Логи lidar-input-reset/error/recovered и счётчики timeouts/resets.

Проверка: node ops/production-build/test-lidar.mjs — 40/40. Добавлены незавершающаяся команда, восстановление после reset, поздний reject старой команды, тайм-аут без reset и ограниченное завершение close. Это mock CDP + существующие тесты реального UDP, не аппаратная приёмка Electron.

Для установки нужен только apps/max-game/launcher/lidar.cjs и перезапуск MAX. Сохранить предыдущий файл для отката; настройки не заменять. Полная пересборка UI не выполнялась.
