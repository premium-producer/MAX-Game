# Последовательное исчезновение карточек

21.10.2026, локальная игра. Общий эффект для постов и товаров: 90 мс между карточками, 240 мс на увеличение/вспышку/схлопывание. Ввод отключён с начала цепочки. Выбранные миниатюры и телефон не входят в эту анимацию.

- 77 Node-тестов прошли.
- Chromium: достижение обеих целей настоящими выборами; 3 оставшихся поста и 5 товаров исчезают последовательно. Попытки нажать исчезающие карточки не добавляют публикаций. Полёты в телефон продолжаются одновременно; итоговый экран доступен.
- Проверена отмена/повторный запуск эффекта, завершение 10 карточек за 1150 мс и немедленное удаление при reduced motion.
- Ошибок браузера нет. Кадры posts-popping.png и store-popping.png просмотрены. Данные — checks.json и *-frames.json.
- HTTP 18752 соответствует локальной сборке (http.json). Рассмотрены 6 изменённых и 2 новых файла, удалений нет (package-diff.json); game seal/check выполнен. Пользовательский data и стела не изменялись. Физический стенд не проверялся.

В первом прогоне проверка ошибочно сравнивала порядок DOM с визуальным порядком. Исправлено сравнение задержек по индексу сверху вниз; итоговый прогон успешен.
