# Синхронизация исправлений аудита — 26.10.2026

Выпуск: **KDW-MAX-AUDIT-FIXES-20261026**. Канонические исходники — корневые `apps/UI/docs/ops`, GitHub-компоненты — `premium-producer/MAX-Game` и `premium-producer/VK_Stella`, ветка `kdw-max`.

Состав: исправления игрового процесса из [отчёта](../verification-audit-fixes-20261026/README.md), регрессионные проверки, восстановленная документация и [ТЗ на звук](../SOUND_DESIGN_SPEC.md). Полная аппаратная приёмка остаётся отдельной задачей.

Синхронизация выполняется по явному списку `ops/sync/paths.json`. Перед записью проверены исходные SHA, чистота Git-копий ПК и совпадение удалённых веток с предыдущим выпуском. Все заменяемые файлы и манифесты сохраняются на ПК в `.sync/archive/release-20261026/before`; состояние операции и итоговые commit/sharedRevision находятся в `.sync/SYNC-STATUS.json` и `.sync/release-20261026`.

Обновляются рабочий корень, публикационные копии и четыре производных комплекта: dev, startup-one-pc, startup-max, startup-stela. Профили app.json, операторские настройки, ключи, runtime и пользовательские данные сохраняются. Работающие приложения автоматически не останавливаются: новая сборка используется после их следующего запуска.

Шесть устаревших документов dev-комплекта сверены по содержимому: инструкции/журнал отстают от корня; Figma описывает отменённый native2; статусы фотографий и веб-поставки относятся к предыдущему выпуску. Они обновляются из канонического источника с сохранением прежних байтов в архиве. Уникальных новых правок кода при сверке не обнаружено.

Контроль: Gitleaks перед публикацией; соответствие Git index и SOURCE_MANIFEST, включая LFS; SHA общего набора на Mac/ПК; восемь манифестов приложений и четыре манифеста поставок на ПК. Точные результаты сохраняются в локальной квитанции синхронизации; исходниковая проверка не считается аппаратной приёмкой.
