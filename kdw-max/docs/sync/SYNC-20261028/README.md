## Проверки и ограничения

Непосредственно перед синхронизацией прошли 289 локальных тестов, TypeScript, generated, build-profile и retention. Повторное тестирование неизменного кода не выполнялось. Полный браузерный аудит остаётся незелёным из-за 18 HTTP 409 в сценариях Стеллы; синхронизация не заявляет исправление этого дефекта или причин прежних GPU-сбоев. После перезапуска Стелла сообщает готовность, но это не длительная аппаратная приёмка.

`npm run check` проверяет заново сформированные локальные package-manifest. `npm run sync:check` проверяет публикационные копии и общий SOURCE_MANIFEST. Секреты, data, private, runtime и VST в синхронизацию Git не добавляются.

Операционные квитанции, хеши профилей и полный журнал доставки хранятся локально в `docs/stand-patches/SYNC-*-20261028-1`, итоговые проверки — рядом с этим документом. Установки выполнялись готовым дельта-установщиком с проверкой базы, SHA архива, резервной копией и сохранением режима вывода.
