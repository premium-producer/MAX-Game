# Плавное скругление прилетающих постов

Причина: радиус 18 px принадлежал родителю `.kdw-feed-post`, а сама `.kdw-feed-photo` сообщала движку полёта нулевые радиусы. Дубликат интерполировался в прямоугольник и оставался квадратным после переноса в ленту; затем появлялось родительское скругление.

Исправление: общий CSS-параметр радиуса карточки и явные верхние углы фото. Нижние углы фото нулевые на стыке с текстом. Движок анимации, длительности, очередь, свечение и маски не изменены.

Проверка: `apps/max-game/source/verify-post-corners.cjs`, реальный Chromium/Electron, окно 1450×900. Цветочный бизнес пройден через меню, ладонь, выбор бизнеса и экраны канала; кофейня через изолированный preview. Дробный масштаб телефона 0.387652491. Проверены кадры полёта и посадки: верхние углы никогда не нулевые, радиусы дубликата и фото при посадке совпадают; скачок <0.001 экранного пикселя. Ошибок консоли нет. Скриншот посадки цветочного поста просмотрен.

Результаты: `checks.json`, `flowers-frames.json`, `cafe-frames.json`, `*-landing.png`, `*-settled.png`. Проверка не охватывает физический стенд и все браузеры. Сборка обновила CSS в www; JS не менялся.
