# Два изображения Stella → MAX — локальная реализация

28.10.2026. Production не изменён. Контракт: `../STELA_PHOTO_VARIANTS.md`.

Общий `async-link.cjs` принимает full 1080×1920 и avatar 512×512, проверяет JPEG-размер, SHA, сессионный контекст и вариант. Сохраняются независимые файлы, ACK, ошибки и повторные попытки. Прежние поля full и запросы без заголовка варианта совместимы. Одно успешное изображение не подтверждает доставку второго. Медленное фото не удерживает очередь команд игры.

`game-link.cjs` хранит оба изображения в одном gameId. Круговые SVG-слоты получают avatar и явную круговую маску; полноформатные получают full. Пока аватарки нет, действует прежний full-only кроп. Общая photoRevision меняется при появлении любого варианта. MAX watcher декодирует обновлённые ресурсы, обновляет существующие и вновь созданные img без смены сессии или перезагрузки. Отмена, замещение, завершение, startup reset и retention очищают оба файла. Размеры настоящего JPEG также проверяются nativeImage в MAX portable-server.

- `ops/audit-fixes/max-photo-variants.mjs` PASS: настоящий JPEG, поздняя аватарка без reload, красный центр/прозрачные углы avatar, независимый синий full с непрозрачными углами. `browser.json`.
