# Название канала и шапка

Два отправленных названия (`business.channel.type/publish`) оставались внутри143px-бабла SVG. Текст уменьшался и пересекал область09:41/галочек. Шапка активности имела встроенный аватар кофейни под новым живым аватаром. Цветная окантовка букв была отдельной проблемой LCD-сглаживания Windows Chromium.

## Изменения

- `prepare-business-components.cjs`: для обоих экранов выделены исходные шапка/композер, неподвижные обои, верх/низ переписки без обоев, форма отправленного сообщения и прозрачные время/галочки. Оригинальные материалы UI не меняются.
- `kdw-business-source-ui.mjs`, `kdw-business-messages.mjs`, `kdw-business-native.css`: название16px, максимальная ширина300px, минимум143px; текущие кафе/спорт/цветы занимают145/234/224px и40px по высоте. Многострочное название увеличивает бабл и сдвигает нижнюю часть. Весь чат прокручивается внутри фиксированной шапки/композера; обои не сдвигаются. Поверхности/углы/метаданные — исходные SVG, прежние действия ядра сохранены.
- `prepare-posts-chrome.py`: статичная шапка больше не содержит исходный аватар. Статус, стрелка и меню сохранены побайтно из исходных узлов. Живой аватар один, на исходном месте52/65,2/42,95px. Название и verified — отдельные flex-элементы; размер18px сохранён, очень длинное имя не вытесняет значок.
- `kdw-post-identity` рисуется отдельной прозрачной поверхностью (`opacity:.999`). Это выключает цветные LCD-края текста в Windows; диагностический `font-probe.json` показывает, что одного `-webkit-font-smoothing` недостаточно. Альфа меняется менее чем на1/255, гарнитура и размер прежние.
