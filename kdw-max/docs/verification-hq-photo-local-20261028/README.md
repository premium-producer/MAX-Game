## Исправления

- Все 25 HQ-ресурсов включены в пакет. `r9-build.json.requiredAssets` фиксирует SHA256 всех 432 native-зависимостей. Подготовщик автоматически добавляет отсутствующие/изменённые ресурсы, проверяет хеши и не передаёт неизменённые повторно. Новый JS больше нельзя упаковать отдельно от необходимых ему HQ-файлов.
- Поздний снимок или аватарка обновляют текущие и позднее созданные изображения своей сессии. Декодирование выполняется для отображаемых изображений; ошибка неиспользуемого экрана не задерживает остальные фото. Контекст gameId/voiceSessionId, независимые full/avatar и очистка завершённых сессий сохранены.
- Цифровой ID получает центрированный face crop, сохраняя собственную прямоугольную маску с верхними скруглениями. Дополнительная круглая маска больше не оставляет по углам исходный портрет. Круговые видеосообщения и аватарки сохраняют круглую форму.
- Шаблонные экраны при отсутствии фотографии, выбор аватарки канала, названия, описания и прочие редактируемые поля сохранены.
- Разрешён уже установленный адаптированный `journey-v5-touch-area.mjs` в проверке сборки; frozen stand-base не изменён. Тестовая сборка профиля дополнена зависимостями генератора fallback-медиа.
