# Создание личного канала без обязательного ввода

Локальная правка 28.10.2026, без обновления стенда.

По уточнению пользователя: видимая кнопка должна выполнять действие; пустое название не должно блокировать «Создать канал». При подтверждении пустого поля сохраняется имя по текущей аватарке: visitor — «Мой канал», cinema — «Кино каждый день», cat — «Кошачьи истории», game — «Игровой мир», island — «Вокруг света». Это же имя видно как подсказка поля. Свой текст, включая название из одной буквы, сохраняется. Защита от повторной отправки во время сохранения остаётся.

Дополнительно воспроизведён ACTION_UNAVAILABLE после OPERATOR_GOTO: внешний экран уже name/filled, вложенная модель канала остаётся chats либо completed. При отказе вложенной модели после явного перехода оператора она восстанавливается через допустимые переходы графа, затем применяется исходное действие. Успешные исторические команды не меняются; проверено восстановление внешних и вложенных receipts.

Проверки: 235 тестов MAX; реальная форма и installNativeTouch в Chromium — все пять аватарок без названия, своё название, одна буква, переход через админку. Все восемь сценариев переходят в blogger.channel.privacy с сохранённым профилем (`browser.json`). Сборка и check:generated проходят. Физическое устройство/лидар не проверялись.

Повтор браузерной проверки: `node ops/production-build/personal-create-browser.mjs`.
