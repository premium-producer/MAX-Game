# Нажатие на таймер завершает миссию

Подготовлено локально 28.10.2026. Установлено в составе проверенной сборки [DEVICE-BRIGHTNESS-MAX-20261028-1](../stand-patches/DEVICE-BRIGHTNESS-MAX-20261028-1/README.md) по запросу обновления MAX.

Таймер активной миссии — кнопка «Завершить миссию», доступная общему обработчику мыши/лидара. Вместо прежнего dev-toggle отправляется FINISH_MISSION с текущей миссией и штатными revision/session guards. В ожидании ладони и на финале команда недоступна. Очередь рядом остаётся неинтерактивной.

Серверная модель переходит в существующий completed/incomplete → QR → menu. Невыполненные задания помечаются пропущенными, завершённые сохраняются. Штатный game-link освобождает текущую сессию и подхватывает следующую из очереди; при пустой очереди остаётся меню. Повторное касание не завершает новую миссию. Для таймера отключено расширение зоны до 500 единиц, чтобы касание соседних элементов не завершало игру случайно.

Проверено: 234 теста MAX; все четыре миссии, нажатие во время задания/результата, просроченный таймер, чужая миссия, повтор и восстановление состояния, штатное ожидание QR. Chromium проверил реальный сгенерированный activateButton и touchPick: точное попадание, отсутствие расширенной зоны, неактивную очередь, скрытый таймер, одну команду при повторе. Сборка и check:generated прошли. Физический лидар не проверялся.

При следующем обновлении учитывать app.js/build.json/r9-build.json и изменения канонических source/client/src/core/mission-core.mjs, contracts/mission-command.mjs, application/mission-session.mjs для серверных потребителей. Готовый установщик должен сформировать фактическую дельту от последнего установленного пакета.
