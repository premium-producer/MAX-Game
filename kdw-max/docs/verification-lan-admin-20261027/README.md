# Админки в локальной сети — 27.10.2026

HTTPS-вход для MAX: порт 18762, /admin/. Для Стеллы: порт 18761, /stella/admin/. На production-PC MAX адрес 10.0.0.13, на production-PC Стеллы 10.0.0.12. Обе админки имеются на обоих ПК.

Пользователь подключается к той же локальной сети и открывает HTTPS-адрес. При первом входе браузер попросит подтвердить локальный самоподписанный сертификат. HTTPS нужен для Web Crypto в редакторе композиции; HTTP на IP без secure context для него недостаточен. Адреса также показываются в основных локальных админках.

## Реализация

Общий apps/STARTUP/tools/lan-admin.cjs создаёт отдельный HTTPS listener на основном порту приложения +10, только при наличии data/lan-admin/config.json и server.pfx. Основные API, supervisor, Envoy и голосовые WebSocket не переводятся на общий сетевой интерфейс.

Вход разрешает только LAN-адреса источника и собственные адреса/имя ПК в Host. Изменения требуют точного Origin сетевой панели; после проверки запрос проксируется в штатный loopback API с его прежним Host/Origin, сохраняя CAS и действующие ограничения операций. Разрешены настройки оператора, звук/загрузка дорожек, диагностика/runtime, композиция и статические ресурсы её preview, VST-конфигурация/пресеты. Голосовые сессии, приём/чтение назначений игры, внутренний /__kdw/stop и произвольные файлы data не публикуются. Upgrade WebSocket закрыт.

При остановке API закрывается и его LAN listener; supervisor запускает их вместе при восстановлении. Ошибка сертификата/занятый LAN-порт отображается в /__kdw/lan-admin и не завершает игровой API. Сетевой вход не заменяет независимую loopback-панель supervisor при отказе основного API.

Настройка Windows — ops/production-build/configure-lan-admin.ps1. Он создаёт отдельные локальные сертификаты и PFX для двух приложений, файлы data/lan-admin/config.json и server.pfx остаются приватными. Повторный запуск сохраняет существующий сертификат. Правила Firewall: TCP 18761/18762, RemoteAddress=LocalSubnet. Патч-установщик проверяет сохранность обоих файлов. Сертификаты, PFX и пароли в Git/патч не включаются.
