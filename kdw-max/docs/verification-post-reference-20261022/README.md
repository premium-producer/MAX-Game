# Справочная информация на финале канала

Исправлено общее для client.html и cafe-original.html поведение: правая справочная плашка скрыта, пока её место занимают падающие посты, и возвращается после достижения цели. Текст берётся из reviewed-инструкции создания канала: «Канал создан, теперь можно поделиться новостями вашего бизнеса». Нижнее уведомление с дельтой подписчиков и объяснением оценки удалено из DOM. Счётчики внутри MAX и игровая механика сохранены.

Флаг завершения сбрасывается при уходе/новом запуске, прежнее плавное появление плашки сохранено. Изменения не затрагивают квитанции и сохранения.

Проверка Chromium: в обеих версиях выбраны реальные падающие полезные посты до достижения цели; во время игры плашка скрыта, на финале видна с правильным текстом, нижнего уведомления нет, кнопка следующего задания доступна.
