# RC3: обе сборки на каждом ПК, финальная пиксельная Стелла

27.10.2026. Указание пользователя: MAX и Стелла должны присутствовать на обоих стендовых компьютерах для смены ролей; финальная Стелла — именно пиксельная. Окна Стеллы пока не выводить.

## Установка и текущий запуск

На CHUWI, стендовом MAX и стендовой STELLA установлен **полный одинаковый набор приложений RC3** в `C:/KDW-Stand/releases/KDW-Stand-20261027-RC3`:

- `apps/max-game` — Electron, два Spout-потока 3072×1536;
- `apps/stela` — Electron без Spout, вход `/stella/pixels/`;
- общий Electron 44.4.5, текущие приватные голосовые настройки и VST;
- отдельные `Start-MAX.bat`, `Stop-MAX.bat`, `Start-STELLA.bat`, `Stop-STELLA.bat`, соответствующие ярлыки `KDW MAX/STELLA RC3` на рабочих столах.

На CHUWI и текущем ПК MAX работает только скрытый MAX, без ARM и LiDAR. На ПК STELLA приложения остановлены после проверки. Стелла не запущена ни на одном ПК. Автозагрузка не добавлялась. RC2 и его данные сохранены для отката; пользовательские профили, настройки, пресеты и ключи перенесены в RC3 после штатной остановки. Активных назначений перед обновлением не было.

Для смены ролей: остановить старые приложения штатными Stop-ярлыками, затем на новом игровом ПК запустить `KDW MAX RC3`, а на другом — `KDW STELLA RC3`. Сетевые настройки обеих Стелл заранее указывают на противоположный ПК, TLS-пара и узкие firewall-правила подготовлены в обе стороны. Проверены оба направления с закреплённым сертификатом и ключом. Изменение IP-адресов, выбор физического экрана и калибровка лидара требуют отдельной настройки; их автоматический перенос не заявляется.

## Пиксельная версия закреплена

- Канонический `apps/stela/app.json` открывает `/stella/pixels/`.
- Основной `/stella/` тоже выбирает пиксели. Градиент сохранён только как явный альтернативный просмотр `/stella/gradient/`.
- Проверка production требует готовый `lumi-cells` и `stellaRenderer=ring` — это историческое имя пиксельного рендера, а не градиент.
- Сборщики новых production-комплектов закрепляют пиксельный вход.
- Обновлены актуальные локальные launch-профили dev/startup-one-pc/startup-stela и их манифесты. Прежние значения сохранены в локальном служебном backup; данные не изменялись.
- `production/current-stand.json` указывает на RC3. Исторический опубликованный RC2 не переписывался.
- Решение записано в AGENTS.md, README.md и документации поставки.

Пиксельная Стелла сохраняет фотоэтап. Она не подменена вариантом `pixels-no-photo`.

## Проверки

Полный `npm run test:audit:all` прошёл: 140 тестов MAX, 7 связи, 9 Стеллы, TypeScript, сохранение профиля при сборке, retention и браузерная проверка передачи миссии. Начальная попытка в sandbox упёрлась в `spawn EPERM`; повтор вне sandbox завершился успешно.

Все архивы и файлы приложений проверены по SHA256. На существующих MAX повторно использованы идентичные проверенные файлы, с новым RC3-манифестом/версией; недостающий MAX скачан на ПК Стеллы. Общая версия протокола обоих компонентов сохранена.

Скрытый запуск обеих сборок на **каждом** ПК прошёл. Во всех трёх случаях у Стеллы `ready:true`, `renderer:ring`, `pixels:true`, `errors:[]`, `missing:[]`:

- [CHUWI](chuwi-verify.json)
- [ПК MAX](max_right-verify.json)
- [ПК STELLA](stella-verify.json)

Полноценная аппаратная приёмка всех игровых сценариев, физического вывода и лидара остаётся отдельным этапом. Транспортные FPS предыдущего RC2 не выдаются за новый замер пиксельной Стеллы.
