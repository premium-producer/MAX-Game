# Восстановление флюидов при касании ладони

23 октября 2026

## Причина

`foreground.startPalmScan` и исходный GPU-эффект `JourneyIntroBurst` оставались в коде, но вызов был только в autoplay. Обработчики указателя и клавиатуры подтверждали контакт без запуска струй.

## Изменение

В `journey-guided-main.js` добавлен общий `beginPalmContact`: после успешного `controller.down` обновляет сцену и запускает исходный эффект вокруг плитки ладони. Этот путь используют указатель, клавиатура и autoplay. Правка закреплена в `adapt-stand-main.mjs`, который воспроизводит основной файл из frozen stand-base. Frozen-исходники, шейдер, тайминги удержания и правила допуска в игру не менялись.
