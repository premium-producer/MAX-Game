# Витрина: только автоматический скролл; клавиатура без отправки

Локальная правка 28.10.2026, на стенд пока не установлена.

- WebGL-витрина передаёт `manualScroll: false` в обработчик касаний. Ни нажатие на пустую область телефона, ни колесо не включают ручной скролл и не отключают автоматический.
- При движении удерживаемой руки hit-test карточек продолжается, включая карточки внутри области телефона. Автопрокрутка к новым товарам и плавное приближение scroll к scrollTarget сохранены.
- Ручная прокрутка канала не изменена.
- В клавиатуре ответа личного канала удалена кнопка «Отправить». Отправка рядом с полем ответа, удаление символов, пробел, переключатели и сворачивание клавиатуры сохранены. В остальных полях «Готово» сохранено.

Проверки: регресс касания пустой области → движение → две карточки без отпускания; колесо не прокручивает витрину; прежние тесты контактов/блокировок/повторного выбора. Локальная production-сборка и check:generated успешно завершены. Физический лидар на стенде не проверялся.
