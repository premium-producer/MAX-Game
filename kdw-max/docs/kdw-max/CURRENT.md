# Текущая игра MAX — 21.10.2026

Ветка kdw-max содержит последнюю проверенную локальную сборку. Полный Electron/runtime и ресурсы хранятся в существующей Git LFS поставке. Стабильный тег от19октября, main и VPS сохраняются; этот push не означает новый stable/деплой.

После предыдущего обновления интегрированы точные SVG-компоненты бизнес-интерфейса: cafe/sports/flowers, исходные логотипы/подписи/поверхности/радиусы, живые данные бизнеса и подготовленный демонстрационный портрет. Баблы результата, названия канала и ответа адаптируются к тексту; время/галочки не перекрывают строки. История hotel/theater и старые сохранения поддерживаются. Фото — явно выбранный пользователем тестовый fixture стелы с provenance, не данные посетителя; передачи фото из работающей стелы нет.

Обычные иконки standby начинают выбранную миссию заново, с ладонью и штатным вступлением. Обычный SELECT_MISSION сохраняет восстановление; отдельные interaction-preview остаются изолированными. Исправлено повторное появление видео standby после временно недоступного кадра. Подсказки полей скрываются при фокусе и возвращаются в пустое поле после blur.

Сохраняются нативные посты/витрина, ядро/IndexedDB/совместимость, рейтинг4,9, очередь перелётов/реакций, исчезновение карточек после цели, общая сцена/масштаб/таймер. Бабл ответа поддерживает200символов для нового ввода и восстановление ранее принятых400. Поля очищаются до сохранения, IME и неоднозначные начала не обрываются, курсор/выделение сохраняются; уведомление видно2,2с. Ядро отвергает новые неочищенные записи, textPolicy сохраняет воспроизведение прежних квитанций. [Итоговый отчёт](../verification-text-filter-20261021/README.md). Актуальная политика находится в исходниках и тестах; данные RU/EN glin-profanity включены отдельно с исходной лицензией и provenance, без движка/ML/загрузки зависимостей при запуске.

Frozen stand-base192файла сохраняется. Семь явных адаптаций включают прежние шесть и journey-v5-video-source.mjs для готовности standby-видео. Проверяются SHA всех build inputs, bundle/CSS и пакет. Пользовательские data/профили/журналы/ключи исключены. Новых аппаратных/облачных/браузерных прогонов при публикации нет; ранее выполненные проверки отражены в рабочих отчётах. Физический стенд/второйПК/связь со стелой отдельно не приняты.
