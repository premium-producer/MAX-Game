# Синхронизированная поставка KDW-MAX — 25.10.2026

Исходная база — проверенный Production Local Export от 24.10.2026. На Mac и основном ПК сверены все 4202 файла по SHA256; экспорт прошёл 132/132 игровых теста на Windows. В основной рабочей папке Windows восстанавливаются доказанные конфликты из этого экспорта с отдельными резервными копиями. Изменения на VPS эта синхронизация не публикует.

В поставке production-логика и связь MAX/Stella, общие настраиваемые тайминги, pixel-map, актуальные переходы и типографика. MAX содержит текущий Figma-плагин и screens.maxscreens. Контрольные теги 19.10 и исторические каталоги сохранены.

Git-поставка содержит текущие исходники и сборки, общий STARTUP и документацию. Electron Windows x64, пользовательские data/private, настройки камер/микрофонов, частный голосовой профиль, секреты и операторские VST-плагины остаются локальными. Неиспользуемое исходное тестовое фото visitor-photo.png также остаётся только локально. Рабочая JPG-заглушка и производные продуктовые ресурсы сохранены.

Исходный package-manifest.json описывает полный переносимый Windows-комплект; он сохранён для происхождения и не является манифестом очищенной Git-поставки. Точный состав опубликованного среза проверяется отдельным SOURCE_MANIFEST.json. После установки runtime/операторских плагинов и проверки состава локальной поставки её package-manifest можно обновить штатным check-package --seal. Исходный экспорт при публикации не переопечатывался.

На macOS синхронизированы файлы для разработки; Windows Electron, BAT/PowerShell и audio host не становятся нативными macOS-программами. Проект голосового профиля не пересоздавался; платные запросы не запускались.

## Сверка Git-копии

После клонирования загрузить LFS-ресурсы текущего среза и выполнить команду проверки из README. verify-source.mjs сравнивает размер/SHA256 каждого файла с SOURCE_MANIFEST.json, не читает пользовательские data и не выводит приватное содержимое. LFS pointer вместо ресурса считается ошибкой.

Версионные команды запуска рассчитаны на Windows. На существующем ПК сохранять его runtime, плагины, устройства и data; не заменять их заводскими настройками из другой машины.
