# Единая версия KDW-MAX — 25.10.2026

Текущая база — рабочий корень apps/UI/docs/ops на Mac и основном ПК, версия KDW-MAX-UNIFIED-20261025. Первоначальный экспорт24.10 сохранён как история. После него отдельно одобрены и восстановлены конфигурации запуска и служебные файлы; общие инструменты согласованы между платформами. Дальнейшие изменения делать в рабочем корне. [Порядок работы и сборка общего корня](../sync/WORKSPACE.md).

MAX-Game/kdw-max и VK_Stella — два компонента одной версии. Их SOURCE_MANIFEST имеют одинаковый sharedRevision общего исходного набора, но собственные списки файлов. В MAX: apps/max-game, общий STARTUP, UI/docs/ops. В Стелле: apps/stela, тот же STARTUP и документация. Раздельные компоненты объединяются в общий рабочий корень по инструкции; команды umbrella требуют обоих приложений и публикационных копий под github.

Полные package-manifest в Git отражают проверенный состав локальной переносимой базы. Они включают файлы, которые не входят в очищенный Git-срез, и могут отличаться от манифестов установленных Windows-комплектов. Для Git использовать SOURCE_MANIFEST и verify-source.mjs. Манифесты не переутверждать без анализа изменений.

Стендовые production=true и dev-профили production=false задаются явно в соответствующих комплектах; это варианты запуска одного кода. Runtime/Electron, пользовательские data/private/secrets, pairing, устройства, частные голоса и операторские VST остаются локальными. Неиспользуемое исходное фото visitor-photo.png в Git не входит. Готовые игровые bundles при этом согласовании не пересобирались. Аппаратная приёмка, оплаченные голосовые запросы и VPS-деплой не выполнялись.

## Проверка Git-среза

В MAX-Game из корня репозитория:

```sh
node kdw-max/docs/kdw-max/verify-source.mjs
```

В VK_Stella:

```sh
node docs/kdw-max/verify-source.mjs
```

Перед проверкой загрузить LFS-ресурсы текущего компонента. Проверка считает LFS pointer ошибкой, сравнивает размер и SHA каждого файла. В объединённом рабочем корне npm run sync:check дополнительно сверяет оба публикационных набора с исходниками. Исторические каталоги и stable-теги сохраняются.
