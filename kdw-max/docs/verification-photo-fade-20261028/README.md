# Позднее фото со Стеллы — локальная версия

На уже открытом экране сохраняется прежний шаблон до декодирования фото и успешной загрузки его текстуры на GPU. Затем прежнее изображение плавно исчезает поверх нового за 520 мс, с ease-in-out. Экран, устройство и управление не заменяются отдельной загрузочной сценой.

Использован существующий media guard: DOM и WebGL/Spout читают одну анимацию прозрачности. Прозрачность не запекается при пересоздании материала. Повторная подмена до GPU-ready сохраняет первоначальный видимый шаблон; уход со страницы отменяет анимацию и освобождает временное изображение. Reduced motion сохраняется.

Проверено локально:

- 220 тестов MAX, включая задержку decode/upload, повторную подмену, отмену и DOM-вариант
- Chromium + настоящий WebGL: шаблон полностью виден до GPU-ready; последовательные пиксельные замеры переходят от старого изображения через смешение 50/50 к новому (`browser.json`)
- `npm run build:max` и `npm run check:generated`

Браузерная проверка изолирует media guard и GPU-смешение; полный сценарий на физическом Spout-приёмнике пока не запускался. На стенды это изменение не устанавливалось. Готовая локальная сборка также содержит новые HQ-экраны общения и создания Цифрового ID.
