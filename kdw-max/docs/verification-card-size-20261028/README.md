# Падающие карточки: масштаб и ширина поля

Подготовлено локально 28.10.2026. На стенд эти изменения ещё не установлены.

Падающие посты и товары по умолчанию увеличены ровно в 2,2 раза по ширине и
высоте относительно прежнего размера. Размер телефона, карточек внутри него,
содержимое каталога и правила выбора не менялись.

Админка MAX → «Масштаб и расположение» → «Игровые экраны»:

- «Размер падающих карточек, % прежнего»: 50–300%, исходно 220%
- «Расширить область появления вправо, px»: 0–1600 дополнительных px в
  координатах 3072×1536; фактическая область ограничивается краем дисплея
- «Телефон в играх с карточками, %» — прежняя отдельная настройка устройства,
  переименована для исключения путаницы

Расширение поля не увеличивает карточки и не меняет скорость их движения.
Новые параметры входят в обычную иерархию: вся игра → тип устройства → экран.
Существующие профили читаются без миграции и перезаписи. Работают прежние
save/preview/cancel, CAS, проверка Origin, экспорт и импорт.
За жёлтой областью лидара касания недоступны — предупреждение присутствует
рядом с полями. Калибровка и глобальные границы ввода не изменялись.

Текст падающих карточек готовится в Canvas с двойным разрешением (880 px по
ширине при логической ширине 440). Фото больше не уменьшаются до 640 px:
новый предел 1024 px без увеличения исходников меньшего размера.
Все текстуры готовятся перед показом и загружаются ограниченными порциями;
во время падения не перерисовываются. Бюджет текстур ограничен 160 МиБ на
активность. В замере кофейни: посты 90 127 302 байт, товары 83 626 545 байт.

профилей прошли; после фикса стабильной маски повторены 11 профильных тестов.
Сборка и check:generated прошли.

Chromium 3072×1536: оба режима, живое сохранение настроек, область +600 px,
исходные 220% в админке, увеличение одних и тех же карточек ровно 2,2× и
успешный выбор увеличенной карточки (published=1). См. hit-check.json.
6-секундные локальные замеры: max frame 16,8 мс, CPU update max <1 мс,
нет длинных задач, скачков по X и обратного движения. Это локальная проверка,
не подтверждение устранения подёргиваний на стене через TouchDesigner.

PNG posts/store default/wide проверены визуально. При крупном размере и узком
поле пересечения карточек заметнее; расширение регулируется отдельно.
