# Музыка и операторские панели — RC4.1

Итоговая сборка: `KDW-Stand-20261027-RC4-1`. Инструкция: [OPERATOR_PANELS.md](../OPERATOR_PANELS.md).

## Что изменено

- Стелла остаётся пиксельной; подключены 13 оригинальных музыкальных/шумовых WAV прежнего двухбрендового стенда. Старые голосовые Screen*.wav не перенесены
- Отдельные уровни музыки и эффектов, снижение громкости под речь, приглушение при прослушивании посетителя, включение/выключение и прослушивание банка
- Музыка включена в существующий WebRTC/AEC reference, VST-пресеты и голосовые параметры сохранены
- Стелла: общая браузерная панель, ссылка на прежнюю панель VST, выбор дисплея для следующего запуска, состояние связи с MAX
- MAX: тайминги и режим входа, начальные значения, состояние Spout, ARM/DISARM, видимость курсора, OSC-настройки и калибровка четырёх углов с проверкой центра
- Панель стартует вместе с сервером приложения. Start-Admin запускает сервер без основной сцены; обычный Start после этого переводит MAX в режим Spout

В RC4.1 исправлена выявленная на проверке отмена звука фото при обновлении revision: события capture/review остаются внутри одной сцены и не отменяют собственные ScanStart/ScanEnd. Проверка расширена с загрузки WAV до реального вызова AudioBufferSource.start.

## Проверки

- [Общий аудит](audit.txt): `npm run test:audit:all`, 140 тестов MAX, 7 связи, 9 Стеллы, TypeScript, сохранение launch-профиля, retention и реальная браузерная передача миссии
- 6 тестов операторского API: Origin, запрет GET-изменений, валидация, CAS/backup, ограничения активной игры, точки и центр калибровки, повторное открытие UDP-порта
- 25 существующих тестов OSC и калибровки
- [Браузер](browser.json): сохранение настроек обеих панелей, VST-ссылка, PCM музыки ненулевой; проигрывание кликов, переходов, Tags и всех трёх фотоэффектов; ошибок страницы нет
- [Electron + реальный UDP + native Spout](native.json): калибровочная мишень в canvas, отмена без изменения файла, пять синтетических измерений, сохранение при выключенном ARM, фактический пиксель курсора и очистка после отключения. Это изолированный тест, не запись вымышленных точек в стенд
- Архивы и все файлы установок проверены SHA256; приватные data/plugins/runtime исключены из публичных app ZIP

## Стенды

На каждом ПК находятся обе программы. Прежние releases оставлены для отката; существующие data/settings/plugins и параметры app.json сохранены. Версия app.json обновляется отдельно от операторских параметров. На рабочих столах — Start, Stop и Admin для MAX и STELLA с суффиксом RC4-1.

Стелла оставлена в server-only на всех ПК, без вывода сцены на дисплей. MAX работает с двумя Spout-потоками на MAX и CHUWI; на ПК Стеллы запущен только его сервер. ARM после проверок выключен. Физическая калибровка не создавалась и не заменялась синтетическими данными. Настройки пар и TLS работают в обоих направлениях на основных стендах. На всех трёх ПК добавлено узкое входящее правило UDP 9001 от 10.0.0.11 только для Electron текущей версии; общие профили Firewall не менялись. После смены IP/порта предусмотрена утилита Configure-LidarFirewall.ps1.

Транспортные проверки выполняются отдельным headless Spout-приёмником по 15 секунд в состоянии ожидания с отключённым ARM. [MAX](max_right/analysis.json): 59,996/60,005 FPS, без пропусков. [CHUWI](chuwi/analysis.json): 49,734/50,371 FPS, по четыре пропуска кадров каждого потока в измеренном отрезке. Это короткий замер транспорта, не приёмка всех игровых сценариев. CHUWI и ранее давал около 52 FPS на реальной игре, в отличие от облегчённого Spout-прототипа; стабильные 60 FPS на нём не заявляются. Физический TouchDesigner-вывод, геометрию лидара и акустику с микрофоном следует проверить на площадке.

## Доставка

Применяются небольшие GitHub overlays поверх проверенного базового манифеста, затем проверяется полный манифест новой версии. Для первой доставки RC4 на CHUWI GitHub CDN пять раз упёрся в таймаут; тот же архив передан по SSH и сверён по SHA256. В RC4.1 звук повторно не передаётся: MAX overlay — 47 058 байт, Стелла — 140 096 байт.

- [MAX RC4.1](https://github.com/premium-producer/MAX-Game/releases/tag/stand-production-20261027-rc4-1)
- [Стелла RC4.1](https://github.com/premium-producer/VK_Stella/releases/tag/stand-production-20261027-rc4-1), приватный репозиторий
- [Проверка опубликованных assets](publication.json)

Сборка — `build-stand.py`; публикация — `publish-rc4-1.py`; доставка, установка и проверки — `ops/production-build/deploy-rc4/`. Одноразовые Scheduled Tasks работают в интерактивной сессии владельца, без триггеров автозапуска. Файловые ACL не изменяются.
