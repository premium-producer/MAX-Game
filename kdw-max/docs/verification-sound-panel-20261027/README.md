# Локальная проверка звуковых панелей

Проверены две независимые библиотеки, сохранение и восстановление конфигурации, конфликт ревизий, резервная копия, загрузка файлов и выдача диапазонов, отклонение неправильных путей / Origin / содержимого / значений громкости и fade.

Chromium: загрузка и декодирование WAV с русским именем, назначение события, сохранение и повторное открытие, сохранность несохранённых значений при обновлении банка, фактический запуск AudioBufferSource при прослушивании. В настоящих движках проверены пользовательский файл, громкость события × master, завершение и очистка источников. Ошибок JavaScript нет. [Машинный отчёт](checks.json).

Дополнительно: проверки существующего operator API, TypeScript Стеллы, generated-адаптер MAX; локальные сборки обоих приложений.

Проверка не использует SSH, CHUWI или production-ПК, не меняет их версии. Физические колонки, акустика площадки и AEC с реальным микрофоном остаются аппаратной проверкой после отдельной команды на обновление стенда.

Превью: [MAX](max-sound-panel.png), [Стелла](stela-sound-panel.png). На снимках временные тестовые библиотеки и тестовые значения, не настройки рабочего комплекта.
