# Увеличенные зоны нажатия — 2026-10-29

Подготовлено локально; на стенд не установлено.

- Маленькие внутренние hotspot-кнопки личного канала (`pc-hotspot`), бизнеса (`bn-original-action`) и Цифрового ID (`media-hotspot` соответствующей миссии) получают виртуальную область ×3 по каждой оси. Критерий узкого элемента: меньшая сторона не больше 20% ширины поверхности. Область ограничена краями устройства, размеры учитывают текущий масштаб.
- Внешний вид, клавиатура, таймер, карточки и большие плитки не изменены. При пересечении зон точное попадание приоритетно, иначе выбирается ближайшая исходная кнопка. Disabled/inert и перекрытые элементы не активируются.
- Удержание не запускает новый экран автоматически; между соседними живыми кнопками можно перемещаться без поднятия руки.
- В локальной браузерной проверке обнаружен дополнительный отказ старого выбора у субпиксельного края кнопки: elementFromPoint возвращал родителя. Проверка видимости теперь отступает внутрь кнопки и для расширенной зоны проверяет также центр. Это воспроизведение локального дефекта, не доказательство точной причины прежнего инцидента на стенде.

Проверено: 12 unit-тестов касаний/геометрии, build:max, check:generated; браузерная проверка с профилем геометрии стенда (layout-fixture.json).
