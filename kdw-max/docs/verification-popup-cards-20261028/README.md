# Случайно появляющиеся карточки — 28.10.2026

Реализовано локально; на стенд не отправлялось. Новые задания используют posts v14 / store v9.

- Карточки появляются по одной в случайных точках существующего диапазона размещения. Позиция остаётся постоянной на протяжении показа; вертикального потока и шлейфа нет.
- 150 мс — полный срок доступности невыбранной карточки, а не длительность fade. По истечении этого срока удаляются изображение и hit area; authority отвергает просроченный выбор.
- Новое появление каждые 450 мс. Расписание и координаты воспроизводимы по seed/run/index; браузер и игровой reducer используют один timeline.
- Изображение целиком помещается в заданный диапазон с учётом текущего размера карточек. При слишком узком диапазоне размер ограничивается его границами.
- Выбранная вовремя карточка сохраняет перенос в устройство, плавную каёмку на выборе и её уход при начале полёта. Сохраняются только положительные карточки и общая очистка очереди при достижении цели.
- Исторические версии заданий продолжают использовать прежнее расписание для корректного восстановления сохранений.
