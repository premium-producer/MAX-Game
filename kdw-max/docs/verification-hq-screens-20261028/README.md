SHA исходников и выходных файлов — client/src/kdw-hq-screen-assets.json. Размер1440×3200, финальная история1440×3052. Остальные задания ЦИД, блогер и бизнес не переведены на этиPNG.

prepare-hq-screens.mjs сохраняет семь прежних масок общения и портрет ЦИД. НовыеPNG размещены под существующим слоем посетителя; без фото сохраняется шаблонный мужчина. Геометрия QR и перекрывающих элементов сохранена. Исправленные временные подписи первого экрана звонков сохранены поверх новой подложки. Сервис game-link автоматически подставляет фотографию в новыеSVG в прежних каталогах conversation/visitor-details; сетевые протоколы не менялись.

Каталог подключает новые файлы после прежних адаптеров. Координаты hotspot пересчитаны пропорционально; действия, исходы, маршруты, тексты и таймеры сохранены. Версия каталога получила суффикс.hq20261028. СтарыеURL резервных изображений сопоставлены новым экранам, без дублирования встроенных данных.

Рендерер узнаёт только новыеHQ-ресурсы и создаёт для них ограниченную текстуру до1440×3200, включая прозрачные поля. Для стандартного телефона реальный размер1440×3053, полезная картинка немного меньше из-за полей. Разрешение не зависит от текущего CSS-масштаба, поэтому увеличение устройства больше не растягивает первоначальную низкую текстуру. Ключ не меняется на каждом кадре масштабирования. Существующая очередь предварительной подготовки ограничена тремя ресурсами, остальные освобождаются; загрузка всех миссий вGPU не добавлена. Старые ресурсы сохраняют прежнюю политику качества.
