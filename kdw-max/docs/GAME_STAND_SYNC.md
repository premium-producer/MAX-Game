## Принятое поведение

- Будущие иконки скрыты даже во время начальной расстановки. Они не монтируются в DOM/GPU до visual handoff pack своего задания, затем проявляются через исходный maath clock. Пройденные сохраняются с галочкой. Это установленная правка MAX-UI-COPY от 6 октября, сохранённая позднейшими сборками.
- Справка определяется основным текстом: пустое body не показывает пустую карточку. Ширина 760 logical px и сдвиг композиции взяты из актуального источника. Цифровой ID не разрывается.
- Таймер — большая стендовая плашка над левыми иконками. Ядро выдаёт 60 секунд на задание; переходы между внутренними экранами не сбрасывают минуту. Тайм-аут истекает для всей миссии. Прежнее скрытие таймера в R8 отменено как следствие неверного источника.
- Автономный выбор миссии подтверждает старт существующим contact-контрактом, без требования удерживать ладонь. Очередь Стеллы, physical presented и LiDAR остаются внешними обязанностями стендового хоста.
- Клавиатура канала открывается снизу поверх игры; витрина и подтверждённое сохранение данных сохранены как дополнения KDW.

## Адаптация экрана

Браузер и Electron используют один renderer и общие переходы. Для view=game полотно общее для меню и всех четырёх миссий: заранее учитываются самый широкий экран всего каталога, полная справка шириной 760 logical px и два начальных слота иконок. При одинаковом окне масштаб одинаков во всех миссиях; данные берутся из каталога без ожидания декодирования изображений. Масштаб остаётся постоянным при появлении/скрытии справки, смене экранов/миссии, морфинге устройства и добавлении иконок. Только реальное изменение окна пересчитывает проекцию. Место под справку резервируется до её проявления. Браузерный gap увеличен с 64 до 128 logical px между иконками и между иконкой/устройством; его измеряет тот же Flexbox route measure. По уточнению пользователя иконки могут выходить за левый край: всю историю маршрута не пытаемся вместить уменьшением масштаба или сдвигом устройства. Устройство и справка остаются в окне.

view=wall сохраняет исходные 4096×1280, физические интервалы и координаты. Изменённая браузерная геометрия не выдаётся за аппаратную калибровку нового стенда. Фон в автономной оболочке — локальный MAX grid-слой; внешние MASTER/GPU/viewer для запуска не нужны.

Дополнение по resize: кэшированная растровая рамка устройства разделена на девять участков. Углы, радиус и поля свечения сохраняют размер в логических координатах, прямые края и середина растягиваются по текущим границам DOM. Рамка не перерисовывается в новую текстуру на каждом кадре; неиспользуемая геометрия освобождается. Это локальная правка общего renderer, включая переходы между пропорциями телефона и ПК. Прогресс и contentRevision R9 сохранены. [Проверка resize](verification-resize-20261018/results.json), [проверка геометрии](verification-resize-20261018/cpu-tests.txt).

## Разработка

Активная база — source/stand-base/manifest.json, а не старая папка F. Источник следующих обновлений определять по последней квитанции INSTALLED и её build inputs. Однократные import/upgrade-скрипты не перезапускать поверх локальных правок. Изменения границ хоста вести через source/adapt-stand-main.mjs и регенерировать main перед сборкой.

Сборка: node apps/max-game/source/build.mjs ПУТЬ_К_ИНСТРУМЕНТАМ_node_modules . Проверки: node --test --test-isolation=none apps/max-game/source/client/test/kdw-interactions.test.mjs apps/max-game/source/client/test/kdw-stand-adapter.test.mjs . Сверить изменения, затем check-package.mjs --app max-game --seal; другое приложение не переутверждать.
