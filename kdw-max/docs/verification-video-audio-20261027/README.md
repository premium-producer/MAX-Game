# Звук видео MAX — 27.10.2026

Установлено на обоих production-ПК патчем VIDEO-AUDIO-20261027-2. Основной MAX восстановил оба Spout-потока; резервный MAX на ПК Стеллы работает только сервером. См. ../stand-patches/VIDEO-AUDIO-20261027-2/README.md.

В панели `/__kdw/sound/panel` добавлен раздел «Звук видео» с независимыми включателями и громкостью 0–100% для «Видео Standby» и «Видео в заданиях». Общая громкость и включатель MAX действуют на оба канала. Итоговый уровень = общая громкость × громкость выбранного вида видео; явный mute отдельного игрового ресурса сохраняет приоритет. Настройки видео не заменяют встроенную аудиодорожку и не загружают новый видеофайл.

Настройки сохраняются в `data/sound-events.local.json`, поле `video.standby` / `video.tasks` (`enabled`, `volume`). Старые настройки читаются с включёнными каналами и уровнем 100%, без перезаписи файла и сброса аудиособытий. Старое окно панели, не передающее новые поля, сохраняет их текущие значения; CAS-конфликты и проверки Origin остаются.

Активные ролики получают изменения при штатном опросе звуковых настроек (обычно до 2 секунд), без перемотки или перезапуска. До первого ответа настроек новые локальные видео беззвучны, чтобы не прозвучать на полной громкости при сохранённом mute. Удалённый audioPort не затронут. После удаления видео регистрация громкости очищается. Fade in/out событий не распространяется на остановку видео: звук прекращается вместе с паузой/уходом со сцены; это прямо указано в панели.

Стелла использует прежнюю панель без секции видео и без новых полей в своём профиле.

Проверки:

- `npm run build:shared`, `npm run build:max` — успешно
- `npm run test:audit:all` — успешно
- `kdw-video-audio.test.mjs` — независимость каналов, master/mute, сохранение позиции, cleanup, чтение старого профиля, сохранение на диск, CAS и недопустимая громкость
- `node --test ops/production-build/sound-library.test.cjs` — прежняя библиотека/загрузка/Origin/назначения без регрессий
- `node ops/production-build/sound-panel-browser.mjs` — настоящая панель в Chromium, сохранение уровней видео, громкость HTMLVideoElement, прежний Howler MAX и Web Audio Стеллы; ошибок страницы нет

Звук через физические колонки стенда удалённо не проверялся. После установки проверены API настроек, наличие секции видео и доступность панели на обоих ПК.
