# Кнопка перехода и карточки: вторая итерация

Статус: локальные изменения. На production-ПК этот патч не устанавливался.

## Кнопка

У переходных кнопок CSS анимировал `transform`, который одновременно изменял GPU-рендерер. При нативном нажатии также включался `scale(.98)`, затем отключался из-за `disabled` во время команды и снова включался до отпускания. Размер кнопки участвовал в расчёте её расположения под справкой.

Теперь нажатие меняет оптическое состояние без изменения геометрии. Для нативного touch состояние контакта сохраняется во время выполнения команды; один контакт не активирует ту же переходную кнопку повторно после выхода и возврата руки. Обработка обычных полей, других кнопок и подавление завершающего системного click сохранены.

Проверка `node ops/production-build/navigation-press-browser.mjs`: настоящие CDP touchStart/touchEnd, вызов штатного click-пути, переключение disabled во время удержания и пересчёт размещения на каждом RAF. С прежним CSS ширина колебалась на 7,80 px, высота на 1,28 px; с исправлением обе величины постоянны. Один контакт — одно срабатывание. [Результат](navigation-press.json)

## Карточки

Нативные слои в основной игре больше не выравниваются и не обновляют поток дважды за кадр. Snapshot обрабатывается при его изменении, а движение — один раз после применения текущей геометрии GPU, включая кадры без движения иконок. Убраны повторные записи неизменившегося текста счётчиков/рейтинга и disabled падающих карточек. Коррекция визуальных часов постепенно меняет скорость, без мгновенного переключения между поправками ±10%. Авторитетные часы и игровые команды сохранены.

Изолированный Chromium-прогон настоящих модулей активностей, по 12 секунд: [до](before.json), [после](after.json).

| Показатель | Посты до → после | Товары до → после |
| --- | --- | --- |
| Изменения текстовых узлов / childList | 1514 → 359 | 776 → 49 |
| Изменения disabled | 399 → 364 | 1633 → 183 |
| CPU обновления, P95 | 1,5 → 1,4 ms | 1,5 → 1,4 ms |
| Скачки / преждевременные удаления / замены узлов | 0 → 0 | 0 → 0 |
| Успешные выборы | 2 → 2 | 2 → 2 |

157 тестов MAX и 13 тестов раскладки/калибровки прошли. `check:generated` пройден; собранный bundle проверен по SHA всех 331 исходных модулей. Браузерный прогон не измеряет конечную плавность Spout на production-оборудовании и не подтверждает отсутствие всех возможных задержек.

Дополнительно `node ops/production-build/card-native-scene-browser.mjs` проверил собранные полные GPU-сцены постов и витрины: нативный слой появляется и совпадает с геометрией телефона, ошибок JavaScript нет. [Результат](full-scene.json). Этот memory-preview проверяет интеграцию раскладки; движение проверяется отдельным activity-прогоном, поскольку preview не запускает production ticker.
