# Точность интерфейса бизнес-миссии

Пользователь отклонил предыдущую приблизительную перерисовку. Теперь неизменяемые элементы клиента составлены из оригинальных SVG: брендовая строка, значки, фиксированные надписи, поверхности, градиенты, маски и скругления. Нативный слой меняет только размеченные поля бизнеса/посетителя и обрабатывает действия. Выбор бизнеса, посты и витрина сохраняют свои реализации. UI-оригиналы не редактировались.

## Реализация

`apps/max-game/source/prepare-business-components.cjs` читает геометрию в Chromium и сохраняет компоненты с транзитивными зависимостями. Реестр `client/src/kdw-business-components.json` фиксирует SHA исходника, координаты каждой области и отдельные сменные поля. 16 исходных экранных позиций + нативный выбор бизнеса. Исходные viewport и контуры сохранены; CSS не добавляет вторые радиусы или рамки. Перекрытие соседних областей на1px и подложек полей на2px убирает стыки при дробном масштабе.

`kdw-business-source-ui.mjs` собирает оригинальные части и отдельные поля профиля. Исходные времена и галочки сообщений восстановлены отдельными неизменяемыми SVG-фрагментами поверх сменной реплики. Семантические кнопки совпадают с элементами макета; команды/outcomes прежние. На подтверждённом профиле переход расположен под устройством, чтобы не изобретать кнопку внутри клиента.

В новой выгрузке банковская плитка оказалась пустой. Точный значок найден в ранее предоставленном `www/assets/reviewed-20261004/business-platform-verification-98d2a4483c08.svg`, SHA `98d2a4483c086caba7159b8497349f5d1b8c58f8aeebf511b842a380f0673274`. Сохранён исходный векторный фрагмент; значок не перерисовывался.

109ресурсов/22 638 733байта включают SVG-компоненты и общие PNG в исходных байтах. Подгружаются ресурсы текущего экрана; одинаковые растры передаются один раз и внедряются в Blob SVG перед декодированием, поскольку SVG в `<img>` не загружает внешние зависимости. Кеш декодированных частей ограничен, Blob URL освобождаются. Сетевое чтение/декодирование ограничено8секундами, отказ освобождает ready; готовность не зависит от видимости. Глобальной загрузки всех экранов нет.
