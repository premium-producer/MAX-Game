## Что исправлено

Раньше AnswerFlight запускался только из обработчика нажатия. Голос сразу применял серверный photo/result и пропускал сцену. Теперь клиент хранит принятый snapshot отдельно, запускает ту же HybridSelection и применяет snapshot после callback завершения. Повторная команда серверу не отправляется. Ready результата является барьером озвучки. На audience обработка речи не прячет интерфейс, но VoiceVisualModel продолжает визуальные реакции. Переход к камере тихий.

Ручной ввод остаётся на тестовых WAV без Qwen-генерации; voice confirm/skip после фото озвучивает финал через прежний Qwen pipeline. Кнопочное confirm/skip сохраняет прежнюю тестовую запись. Никаких новых реплик не синтезировано. В итоговой речи по-прежнему нет предложения другой миссии.
