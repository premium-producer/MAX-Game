- Холст использует фактическую отображаемую ширину×DPR с пределом .25–2 authored-размера. ResizeObserver/window.resize пересчитывают и перерисовывают текущий кадр на паузе; cleanup освобождает ресурсы. Наблюдатель не добавляет покадровых DOM-измерений.
