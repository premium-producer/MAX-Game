# Плавные размеры устройств и исчезновение линков регистрации

23 октября 2026

## Изменение

В основном renderer восстановлена передача `fromHeight/toHeight` и принятие обеих координат в `resize(width,height)`. Ранее `KdwDeviceMorph` поддерживал две оси, но вызов из пересобранного main передавал только ширину: конечная высота сразу попадала в `presentedDevice`. Теперь обе оси используют один прогресс maath. Канал и мини-приложение проходят общий out → resize → ready → in; конечные размеры сохранены.

DOM-слои канала и витрины дополнительно выравниваются после шага renderer, чтобы не отставать от устройства. Все изменения внесены в `adapt-stand-main.mjs`, повторное выполнение воспроизводит main побайтно. Frozen stand-base не изменён.

`RegistrationLinks` при переходе на `business.platform.ready` удерживает прежнюю геометрию точки привязки и плавно уменьшает прозрачность до нуля. На плашку подтверждения линки больше не перенацеливаются. Новый запуск, reduced motion и выход на следующую задачу обрабатываются отдельно. Архивный cafe-original сохраняет прежнее поведение.
