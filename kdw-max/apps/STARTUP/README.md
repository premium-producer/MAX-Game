# Запуск переносимых приложений MAX

Положите `STARTUP` рядом с папкой `stela`, `max-game` или обеими папками. Общая родительская папка может находиться в любом месте.

- `Start.bat` — запустить все присутствующие приложения.
- `Start-Stela.bat` — запустить только стелу MAX.
- `Start-Game.bat` — запустить только игру MAX.
- `Check.bat` — проверить локальные HTTP-сервисы присутствующих приложений.
- `Stop.bat` — остановить присутствующие приложения этого комплекта.

Оба приложения включают Electron 44.4.5 для Windows x64, ресурсы и собственные стартовые файлы. Node.js, npm, Python, браузер и установку зависимостей на принимающем ПК не требуются. Нужен Windows-ПК с поддержкой WebGL2 в драйвере видеокарты.

Двойной щелчок по батнику запускает приложение в отдельном окне. F11 переключает полный экран, Escape выходит из него. Закрытие окна завершает это приложение. Повторный запуск использует его существующий процесс. Стела и игра независимы; обмен миссиями между ними пока не подключён.

Переносите **папку целиком**, включая `runtime`, `www`, `launcher`, настройки и исходные материалы. Можно перенести сразу весь `apps` или только одно приложение вместе с `STARTUP`. Исходный VK_DigitalProducts, корневые UI/PRESENTATION/docs и интернет для локального запуска не нужны.

Стела использует `127.0.0.1:18751`, игра — `127.0.0.1:18752`. Прогресс и профиль каждого приложения находятся в его `data/`; каталог создаётся при первом запуске. Для новой установки поставляется комплект без тестовых данных. При переносе действующего прогресса копируйте `data/` после закрытия приложения. Папка должна быть доступна для записи текущему пользователю.

Диспетчер возвращает управление после готовности локального HTTP-сервиса; Check проверяет этот сервис, а не завершение всех игровых заданий. Ошибки запуска записываются в `data/desktop.log`.

Для технической проверки без окна: `Start.bat all -NoWindow`, затем Check и Stop. В обычной эксплуатации флаг не нужен. `tools/` содержит исходники оболочки и инструменты сборки/проверки; глобальный Node.js нужен только разработчику для этих инструментов.

Проверены перенос в путь с кириллицей и пробелами, общий/раздельный запуск, повторный старт, остановка и реальная загрузка обоих интерфейсов в перенесённой копии. Проверка проведена на текущем ПК; физический второй ПК и оборудование нового стенда ещё не проверялись.
