# Запуск игры MAX

Положить max-game/ и STARTUP/ рядом. Start-Game.bat запускает игру, Stop.bat останавливает её, Check.bat проверяет состояние. Общий Start.bat запускает присутствующие приложения; стела в эту поставку не включена. Пути вычисляются относительно BAT, допускаются пробелы и произвольный текущий каталог.

После клонирования репозитория выполнить git lfs pull. В GitHub Source code ZIP файлы LFS могут быть указателями: использовать готовый автономный ZIP стабильного релиза либо полноценный clone с LFS.
