# Два Spout-потока: аппаратный прототип

Изолированная проверка Electron 44.4.5 → GPU shared texture → D3D11 → Spout2. Это тестовая анимированная сцена, а не интеграция всех экранов MAX. Рабочие launcher, app.json и данные игры не меняются.

- `KDW_MAX_BACKGROUND`: непрозрачный фон, 3072×1536
- `KDW_MAX_CONTENT`: DOM + canvas с premultiplied alpha, 3072×1536
- Отдельный `kdw_spout_receiver.exe` принимает оба потока через SDK, композитит на GPU и пишет собственные измерения новых кадров
- По умолчанию приёмник скрыт, но композиция и снимки рассчитываются на GPU. `run.ps1 -Preview` открывает окно; клавиши: 1 — фон, 2 — контент на шахматной подложке, 3 — композиция. Досрочное закрытие окна считается незавершённым тестом
- Диагностический режим: 1920×960; целевая частота обоих режимов — 60 FPS

## Сборка

Из корня объединённого проекта, Windows x64, PowerShell 7, Visual Studio 2022 Build Tools C++, CMake, Git:

```powershell
./ops/spout-prototype/build.ps1
# При необходимости включить runtime для локального переноса:
./ops/spout-prototype/build.ps1 -IncludeRuntime
```

SDK закреплён коммитом `6b68a5b4fdeca6130b851e5f9366467a844860e5`. Заголовки Electron и import library проверяются по SHA256. CMake включает счётчик кадров только внутри собранного SDK; глобальный реестр Spout не изменяется. Загрузка Node-API использует delay-load из electron.exe. Borrowed GPU-текстуры освобождаются после D3D query completion; одновременно допускается не более трёх кадров на канал.

Результат — отдельный каталог и ZIP в `.cache/spout-prototype/deliveries/`, `manifest.json` содержит хэши файлов и исходников. Пакет без Electron — около 0,5 МБ. SDK, компилятор и Node.js на стенде не нужны.

## Запуск

Из каталога распакованного пакета:

```powershell
./run.ps1 -Seconds 180 -Width 3072 -RunId smoke3072 -RuntimePath C:/KDW-Stand/prototypes/spout-v1/runtime/electron-44.4.5
```

Имя RunId должно быть новым. Запускать в интерактивной Windows-сессии. `run.ps1` ограничивает время жизни только своих процессов. Результаты: `results/<RunId>/sender`, `receiver`, `process-samples.json`, `exit.json`. Снимки readback делаются один раз после трёх секунд, вне измеряемого участка после пяти секунд; обычная передача кадров не использует CPU readback.

```powershell
python -B ops/spout-prototype/analyze.py ПУТЬ_К_КАТАЛОГУ_RUN_ID
```

Анализ выдаёт FPS и интервалы кадров отправителя/приёмника, конвертирует GPU-снимки в PNG и проверяет пиксели альфа-калибровки. У content чёрный прозрачный угол должен иметь RGBA 0/0/0/0, красный образец — 255/0/0/255, половинный белый — 128/128/128/128 до преобразования PNG.

## Поставка на CHUWI

Готовый пакет публикуется отдельным prerelease GitHub Releases. Стенд скачивает его по HTTPS, проверяет SHA архива и каждого файла, сохраняет в отдельном каталоге версии. Electron скачивается один раз из официального релиза и проверяется по официальному SHA. SSH используется только для коротких управляющих команд; Producer Desk — для визуальной проверки.

Этот прототип ещё не реализует обновление всей MAX/Стеллы, ввод посетителя и автоматический откат рабочего стенда. Успешный синтетический тест не заменяет измерения реальной игры вместе со Стеллой, камерой и VST.
