1. Figma Desktop → Plugins → Development → Import plugin from manifest… → manifest.json из этой папки. Если плагин уже импортирован отсюда, закройте и запустите его снова.
2. Выберите обновлённый **screens.maxscreens из этой же версии**. Старый пакет1920×1080 не подойдёт.
3. Выберите миссии и бизнесы, затем «Собрать фреймы со скриншотами».

Полный состав: **134кадра / 69актуальных этапов**, четыре миссии; кофейня, цветочный магазин и автомастерская. Включены главное меню, ладонь, пустые/заполненные поля, клавиатура, игровые посты/витрина, успех, короткие итоги заданий и финальный QR. Пять исторических альтернативных экранов не входят в активный маршрут, поэтому не возвращаются в выгрузку.

Источник — **production/startup-one-pc/max-game**, KDW-MAX-STAND-PRODUCTION-20261023, точный режим pixel-map3072×1536 и его штатный settings/stand.json. В кадрах нет debug-меню, «Назад», «Пропустить», верхнего логотипа оболочки и перезапуска под QR. Большой логотип в standby и логотипы внутри интерфейсов сохранены. После найденного регресса веер подтверждения регистрации привязан к видимой SVG-плашке; исправление перенесено в MAX production и адаптер пересборки. У потоков постов/товаров устранена обрезка по внутреннему safe-отступу: карточки входят и уходят через края дисплея. Все кадры пересняты после исправлений.

Скриншоты получены настоящим WebGL/DOM-рендерером после decode ресурсов, загрузки шрифта и завершения перехода. Оснастка вводит снимки состояния настоящего ядра; не заменяет CSS, тексты, шрифты, геометрию или прозрачность. Короткие результаты сначала проходят штатный вход из предыдущего экрана. Фото — нейтральный шаблон игры, личные данные посетителей не читались. Движение фона/линков/карточек и видео фиксируется одним кадром; оно не воспроизводится в Figma.

Окно плагина лёгкое, без встроенных PNG/base64. Пакет читается по одному изображению с SHA256, через Uint8Array. Повторная сборка создаёт набор рядом с прежним; отмена сохраняет завершённые фреймы. Можно собирать отдельные миссии и бизнесы. Имена/метаданные фреймов редактируемы; содержимое PNG целиком растровое.

«Исходные тексты · JSON» сохраняет прежнюю схему max-clean-screen-texts/v1 с текстами каталога, readOnly=true и changes=[]: правки текста внутри скриншота не предполагаются. Предыдущая native2-сборка сохранена отдельным архивом max-current-screens-20261022.zip и не является текущей.

Разработка: source/final-prepare.mjs → source/final-capture.cjs (при необходимости --shard=0/1/2 по отдельности, затем final-merge.mjs) → source/package.mjs. Проверки: source/final-plugin.test.mjs, source/final-verify-ui.cjs, source/final-production-proof.cjs. Старые native/raster-legacy исходники сохранены для истории.
