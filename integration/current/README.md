## Сборка и тесты

Из корня репозитория, после `git lfs pull`:

```sh
npm ci --prefix integration/current
node integration/current/build.mjs
node integration/current/startup.test.mjs
node integration/current/ui.test.mjs
node integration/current/test/handoff.test.mjs
```

Сборщик использует только файлы репозитория и закреплённые зависимости, проверяет точный SHA обоих bundle до записи. Проверено: client `fe9aef1cb5c77a726fad30352a8e2b4e04f0badd1cb90a24123f95a35a161104`, stand `1eb4fa93076257f2eae21871db1669c9dc1a826e27d88334470e18294e6c57f8`. 12 startup + 16 UI + 4 handoff теста PASS. При дальнейшем изменении source ожидаемый SHA меняют только после проверки и фиксации новой версии; сборщик специально отклоняет случайное расхождение.

`code/client` — закреплённый снимок для воспроизведения; тот же клиентский source находится в `artifacts/max-game/src`, runtime — `apps/max-game/webgl-v5/app.js`. `code/stand` — отдельный актуальный source управляемого стенда. Не заменять stand клиентским backend. Общие внешние зависимости находятся в `artifacts/ribbon` и `artifacts/service`.

## Интеграция и пульт

`host/MAX_RIGHT/app` содержит проверенные интеграционные изменения оболочки, bridge/diagnostics, управления показом, OSC LiDAR и калибровочного solver. `host/MASTER/app` — сопутствующий MAX-срез пульта и сценарных модулей, а не полный актуальный MASTER. Это patch к штатному stand base: неизменённые launch-diagnostics/audio/mobile/служебные зависимости предоставляет мастер-проект. Самостоятельный запуск host из этих файлов не предусмотрен. Каждый файл имеет проверенный SHA и дату в `host/provenance.json`. Общие MASTER файлы требуют сверки с текущим мастер-проектом; простое копирование поверх другого релиза запрещено.

Пульт предусматривает standard, автопрохождение Цифрового ID с циклом видео, независимое устройство и background-only. Независимое устройство имеет SVG/video цикл и отдельное управление иконками; видео со звуком идёт через принятый audio bridge. OSC `/create`, `/update`, `/delete`, формы 3/5 аргументов; выбирается верхняя точка по калиброванному Y. Ввод игры: пересечение зоны 500×500, мгновенное срабатывание без удержания, перемещение курсора без отпускания; drag отключён. Настройки и текущая калибровка на стенде являются внешними данными.
