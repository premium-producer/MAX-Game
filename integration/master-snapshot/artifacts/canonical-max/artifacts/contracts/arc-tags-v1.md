# VK-06: технические теги арки, первый срез

04.10.2026 — ранний план/result применён; технический [Discovery cycle v1](discovery-cycle-v1.md) добавляет отдельный executor v6. Прежние durable версии и семантика emission_complete сохраняются. [Проверка](../reports/sys06-discovery-integration-20261004.md).

03.10.2026. Отдельная проекция текущего квиза и техническое представление в локальном мастере. Она не запускает пакеты, Discovery, генерацию и не освобождает Стеллу.

## Данные

`GET /stella/vk/sessions/{sessionId}/arc` возвращает `arcTagsV1`: binding session/visit/generation, sourceRevision, phase/motion, полный набор кандидатов, targetOpacity, происхождение выбранных тегов, число видимых тегов, выбранный профиль и целевую скорость. Это read-only endpoint; backend вычисляет видимость из сохранённых ответов и сохранённого определения квиза. UI не выводит теги из весов, тем или текущего файла квиза.

Одинаковый текст представлен одним tagId; все принятые источники перечислены. Не выбранные теги остаются кандидатами с opacity0 и стабильным расположением. Повтор принятого ответа не добавляет новые теги. Back пересчитывает набор из оставшихся ответов, а не пытается отменять накопленные эффекты.

Новые admissions сохраняют `arcProfile` рядом с определением Стеллы. Настройки читаются из `configs/arc-tags-profile.json`, проверяются до допуска и не меняют текущую сессию при последующем редактировании JSON. Старый admission без профиля явно неподдержан этой проекцией; пользовательский квиз, ответы и пакет продолжают работать по старому контракту. Новый квиз получает новый профиль. Исторические тела durable workflow и схема БД не меняются.

## Наблюдаемое поведение

| Состояние | Арка |
|---|---|
| Допуск, onboarding | Движения нет; «Начать» ещё не принято |
| Begin/question | Все кандидаты вращаются; ещё не выбранные полностью прозрачны |
| Answer/answer-reveal | Принятые metadata проявляются на прежних траекториях; скорость плавно растёт с visibleCount |
| Photochoice | Выбранные теги продолжают вращаться до решения |
| Accept/photo-reveal/camera | Добавлены четыре фототега; это намерение сделать фото, не готовый снимок |
| Skip, scanning или particles/final | Теги уходят, показывается граница следующего этапа; Discovery в этом срезе не реализован |
| Pause, offline, hidden | Все принадлежащие арке анимации останавливаются |
| Cancel, expiry, closure, другая сессия | Старый визуал удаляется; ответы в истории сохраняются |

Прогресс вращения/opacity/speed выполняет закреплённый Anime.js4.5.0. Вращение и переходы независимы: ускорение кольца не ускоряет fade. Новый общий scheduler или сетевое время не вводятся.

## Восстановление и границы

Смысловой набор восстанавливается из мастера. Локальная поза сохраняется в sessionStorage с версией и привязкой к instance/session/profile; это только восстановление в той же вкладке, не сохранённая на сервере производственная фаза и не синхронизация разных ПК. При недоступном storage пользователь видит ограничение; квиз остаётся рабочим. Snapshot другой сессии/экземпляра/профиля не применяется. Устаревший HTTP-ответ не должен возвращать старые теги.

Технический эллипс и текстовые метки не являются художественным LumiCell/Discovery визуалом реального стенда. Точные фазы нескольких устройств, отдельный renderer, Discovery reveal/erase, ранний immutable package/result и поздние ассеты выполняются последующими небольшими шагами.
