# Локальная страница MAX для бизнеса

Адрес: **http://localhost:8770/max-game/business/index.html**. Отдельное превью полной публичной страницы [business.max.ru](https://business.max.ru/), рядом с [локальным брендбуком](BRANDBOOK_PREVIEW.md). Игра, прогресс, источники/назначения мастера не изменяются.

Сохранены исходная HTML-разметка, inline SVG, два оригинальных CSS, графика с PNG/WebP srcset (в том числе hero1×/2×/3× и варианты для планшета), шесть Max Sans WOFF2. Восемь разделов: hero, чат-боты, мини-приложения, каналы, Цифровой ID, партнёры, подключение бизнеса, поддержка. Оригинальные CSS-градиенты/вращение/масштабирование сохранены; параллакс, раскрытие при прокрутке, реакции градиента, мобильное меню и фиксированные мобильные CTA перенесены в локальный модуль. Reduced motion отменяет движение и оставляет содержимое видимым. Параллакс обновляется одним RAF только по scroll/resize, а не постоянным циклом.

Все ресурсы отрисовки локальные. AVIF `<source>` исключены, поскольку существующий локальный сервер не задаёт их MIME; исходные WebP/PNG тех же размеров сохранены. Менять сервер ради этого не требовалось. Кнопки входа/подключения ведут на официальную платформу, остальные внешние ссылки остаются официальными. Личный кабинет, формы регистрации и связанные сайты не клонируются. Next hydration/маркетинговая аналитика не включаются; original HTML/JS/CSS сохранены в архиве источников.

Исходники: `artifacts/max-game/public/business/`; runtime: `apps/max-game/business/`; оригиналы и URL/SHA: `docs/Research/max-business-site-20261001/sources/`.

```powershell
py -3 artifacts/max-game/scripts/prepare-business.py
py -3 artifacts/web/tools/check_project_duplicates.py
node artifacts/max-game/scripts/build-brandbook.mjs business
```

Общий изолированный сборщик поддерживает три разрешённых имени: `brandbook` (по умолчанию), `business` и `digital-id`. Обновляет только выбранный каталог и проверяет пользовательские runtime-правки по `build.json`. Основная сборка игры автоматически включает превью через обход `public/`. [Цифровой ID](DIGITAL_ID_PREVIEW.md) доступен рядом отдельной страницей.

[Техническая проверка](../../../artifacts/reports/max-business-site-20261001/README.md). Визуальная оценка остаётся за пользователем: проверить первый экран, градиенты и кнопки, появление изображений при прокрутке, мобильное меню. Агент визуальный обход не выполнял.
