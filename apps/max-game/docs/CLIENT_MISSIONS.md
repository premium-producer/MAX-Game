# MAX — три независимых стеклянных круга

Актуальный единый свод миссий и последних обновлений клиента от 28.09.2026 — [MISSIONS.md](MISSIONS.md). Этот файл сохраняет историю прежней версии; её геометрия и числовые цепи не являются текущей механикой.

Действующая механика заменена на [Journey 1.0](JOURNEY.md): 17 учебных заданий в смысловых объектах, размещение не считается успехом, финал доступен после четырёх миссий. Числовые цепи и топологический валидатор ниже — история предыдущей версии. Клиентские названия/состав сохранены.

27.09.2026 — действующая раскладка: two — две независимые зоны, single — одна большая; каждый режим даёт те же четыре клиентские миссии. Сессии режимов независимы и сохраняются в памяти при переключении; перезапуск источника очищает их. Все действия и маршруты находятся на прямом участке SCREEN_RIGHT, вне загиба. Название circle-model сохранено для совместимости исходников, границы ввода теперь прямоугольные.

Версия 0.4.0, 27.09.2026. По последнему уточнению пользователя прежнее 16:9 поле и прямоугольные боковые панели заменены тремя независимыми кругами на всей правой стене. Это не три обязательных шага одной миссии: каждый круг отдельно выбирает любой из четырёх сценариев, хранит узлы, выбор действия и результат. Повтор/смена миссии сбрасывает только выбранный круг. Сессии живут в памяти игрового источника; перезапуск источника сбрасывает их.

## Геометрия и взаимодействие

Логическая стена 4096×1280. Круги радиуса 520 с центрами (660,708), (2048,708), (3436,708), без пересечений. Равномерный scale сохраняет окружности при любом размере вывода. Заголовок/одно короткое описание сверху внутри круга, выбор пронумерованных действий снизу. Все маршруты строятся внутри своего круга. Тап по действию → тап по полю. Тап по узлу → тап по новой позиции; «Убрать узел» удаляет выбранный. Выход за рабочую внутреннюю область или перенос в соседний круг запрещён. Выбор действия хранится независимо в каждом круге; активный pointer маршрутизируется по зоне контакта.

Один createWebGLField рисует все три зоны. Сохраняются исходные шейдеры узлов, многослойные анимированные линки, частицы и bloom. Стеклянные края и лёгкая прозрачная подложка — декоративный CSS, текст остаётся резким. Нет трёх iframe/renderer или отдельных источников. Pointer API мастера остаётся прежним; аппаратный одновременный multitouch этим изменением не заявляется.

## Миссии

Источник — [клиентский документ](../../../artifacts/max-game/incoming/Пользователь_VK_MAX13.md), [разбор](../../../docs/Research/max-client-missions-20260927.md). В каждом круге:

- Блогер: канал → общение с подписчиками → статистика.
- Цифровой ID: создание → отель → льгота → возраст.
- Общение: видеозвонок → голосовое/видеокружок → групповой чат → стикер/реакция → история.
- Бизнес: сфера → бизнес-аккаунт → один инструмент: канал, бот или мини-приложение. Переключение сохраняет два общих узла только своей зоны и удаляет прежний инструмент.

Цифры 1…N временные. ID/общение — условный учебный порядок, реальные аккаунты/ID/звонки не создаются. Таймера поражения нет.

## Код и проверка маршрута

Активны src/circular-main.js, src/circle-model.mjs, src/circular.css и прежний src/webgl-field.js. client-missions.json — источник контента, client-webgl-catalog.mjs генерирует конфигурацию исходного mission-evaluation при сборке. Общий WebGL получает уникальные ID узлов и endpoint-префиксы каждой зоны; evaluator каждого круга видит только его узлы и A/Б. Policy screenProjected, камера фиксирована, плоскость z=0. Старые latitude/longitude — внутренний формат, не география. Координаты на стене преобразуются через ту же камеру 25°/z=9.

Пробуждение 350 мс, свежесть проекции до 120 мс, правильный маршрут удерживается 300 мс. Ревизия геометрии/удержание локальны для круга: игра в соседнем круге не сбрасывает победу. Жест в своей зоне, cancel, hidden и pause сбрасывают удержание. После победы остаются светящиеся связи и краткий результат.

Исходный тёмный фон мастера сохранён; локальные световые полосы с аналитическим ореолом в max-wall-atmosphere.js добавляются к нему. Сплошная яркая заливка предыдущего варианта отменена. Это процедурная проектная адаптация палитры, не оригинальный Angular-компонент из Figma.
