«Без заглушек» означает наличие иллюстративных материалов для каждого учебного этапа, а не реальную интеграцию с аккаунтами, Госуслугами или заказами. Скриншоты могут содержать другие имена и примеры, чем авторские кнопки задания. Все действия находятся внутри устройства; справка только информационная. В Guided значимые действия крупные под кадром, у создания ID используются исходные hotspots. Горизонтальные кадры Guided показываются в рамке ПК, портретные — в телефоне. Мелкий текст исходного кадра не становится самостоятельным обязательным target.

## Источники и соответствие

- `artifacts/max-game/src/journey-media.mjs`: явное соответствие семантическому шагу, этапу и выбранному формату; покрытие миссии включает **все** бизнес-ветки, а не только текущую.
- `journey-media-assets.mjs`: подготовленный индекс URL, названий и исходных размеров.
- `public/assets/client-media/sources.json`: происхождение, Figma node ID, SHA256 и размеры111 оригинальных PNG. Подготовка: `scripts/prepare-client-media.py`. Файлы копируются без обрезки, увеличения или перерисовки; исходные выгрузки сохраняются.
- Создание ID продолжает использовать прежние подготовленные векторные SVG из `assets/digital-id`, без возвращения PIN-экранов.
- Используется последняя дневная пара с Мишкой из `design/digital-id-mascot-urban-stills-20260930`. Ранее отвергнутые варианты не подключены.
- Пример бота из клиентского вложения показывает **статус/перенос доставки**. Он добавлен как контекст, но не выдаётся за отсутствующую сцену **принятия заказа**: на этом этапе сохраняется явная заглушка.

Исходных видео для этих сцен не обнаружено. Сюжетные анимации ID по указанию пользователя заменены двумя статичными кадрами: подход к учреждению → предъявление ID. В прежних редакциях дополнительные экспортированные состояния доступны через галерею; в текущей Guided Reveal показан один кадр на этап, кроме двух последовательных экранов открытия меню канала. Это не видеозапись. Малые фрагменты меню и дополнительные фотографии ID не превращаются в новые задания.

## Рендер и ввод

Один прежний WebGL renderer: изображения входят в retained foreground через CanvasTexture. Для новых изображений применяется contain по исходным пропорциям, включая горизонтальные бизнес-экраны; ничего не растягивается до портретного отношения сторон. Повторная шапка учебного телефона скрывается, чтобы увеличить полезную площадь исходного кадра.

В Guided Reveal справа находится только справка, действия — внутри устройства: одинарная кнопка под кадром, несколько кнопок для выбора либо hotspot настоящего элемента на скриншоте. Галерейного chrome нет. В прежних редакциях галерея сохраняет отдельное листание без зачёта задания. Первые кадры прогреваются до старта игры, дополнительные декодируются по требованию. Замена выполняется существующим `transitionContent` и общим clock. Повторный ввод во время декодирования не создаёт второй переход; ответ, закрытие или смена миссии отменяют устаревший commit.

В меню всех редакций показывается «Без заглушек» либо «Есть заглушки». В отсутствующей сцене прямо написано, какого материала нет. Результаты подтверждения заданий и ответы по-прежнему принадлежат существующим reducers/controllers, не картинкам.

[Проверка реализации](../../../artifacts/reports/max-client-media-20260930/README.md). Физическая читаемость оригинальных кадров и аппаратный ввод проверяются на стенде отдельно.
