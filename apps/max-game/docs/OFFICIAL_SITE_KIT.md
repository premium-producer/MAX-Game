# Новая изолированная визуальная основа MAX

01.10.2026 — по запросу пользователя подготовлен [ассет-пакет пяти официальных сайтов](../../../artifacts/DESIGN/BRANDS/MAX/site-kit-20261001/README.md). Он независим от текущего визуального стека игры и прежнего пилотного брендового пакета. Основной runtime сохранён; первый отдельный прототип собран в `/max-game/site-game/index.html`. [Текущее состояние](SITE_GAME.md).

Основа содержит 165 уникальных исходников, оригинальные цвета/шрифты, 29 CSS и 9 рецептов компонентов. Игровые ассеты старой сборки не импортированы. [Аудит](../../../artifacts/reports/max-site-kit-audit-20261001/README.md) показывает покрытие всех 6 миссий и недостающие экраны/состояния. [Исследовательское обоснование](../../../docs/Research/max-site-kit-20261001.md).

Следующая разработка: отдельный источник и runtime, собственные сохранения и новая система визуальных компонентов из выбранного поднабора сайта. Сохранить старую игру, её данные и назначение мастера. Прежние игровые требования используются для сравнения поведения, не для автоматического переноса стекла/шейдеров/иконок. Первая малая итерация — оболочка и одно задание блогера, затем скриншот и отзыв пользователя.
