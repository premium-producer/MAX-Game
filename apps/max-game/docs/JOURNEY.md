GPU-проход не добавляет новый renderer/RT, текстуры освобождаются при смене состава UI; reduced-motion и пауза учитываются. ## Прохождение

CTA «Открой возможности MAX» → выбор одной из четырёх миссий → касание свободного поля → локальный выбор смысловой иконки → объект с уведомлением → инструкция и учебный экран → два действия задания → отметка выполнения. Размещение объекта само по себе не завершает задание. После всех заданий миссии доступен возврат к выбору; после четырёх миссий — общий финал и повторная игра. Сброс требует подтверждения и касается только своей зоны.

| Миссия | Объекты |
| --- | --- |
| Стать блогером | Канал, общение с подписчиками, статистика |
| Цифровой ID | Создание ID, отель, льгота, возраст |
| Общение | Видеозвонок, голосовое/видеокружок, групповой чат, реакция, история |
| Продвижение бизнеса | Сфера, аккаунт и один инструмент: канал / бот / витрина |

Всего 17 видов заданий с двумя этапами. В бизнесе достаточно одной выбранной ветки; остальные можно попробовать отдельно. Сфера и аккаунт общие, прогресс каждого инструмента отдельный. Это учебные взаимодействия, не настоящий интерфейс MAX и не интеграция с его API: реальные аккаунты, ID, публикации, заказы, звонки не создаются; камера и микрофон не запрашиваются. Выбранные примеры тем/контактов иллюстрируют механику, не сохраняют реальные персональные данные.

Связи выбирают ближайшие пары по расстоянию на 2D-поле и образуют минимальную связную сеть без циклов (Kruskal MST). Центрального объекта по роли миссии нет. Каждая зона считается отдельно; во время drag связи перестраиваются, декоративное парение не меняет соседей. Проверяется выполнение заданий, а не топология линии. Иконки — единый авторский SVG-набор с цельными белыми силуэтами в пластике MAX; оригинальный логотип не перерисован. Объекты перетаскиваются; после отпускания позиция сохраняется. Удаление отдельного объекта не предусмотрено.

## Файлы и состояние

- `artifacts/max-game/src/journey-main.js` — активный вход, DOM и адаптер исходного WebGL.
- `journey-links.mjs` — ближайшая сеть, профиль волокон и восстановленная независимая траектория частиц из upstream.
- `journey-state.mjs` — чистый reducer, валидация восстановления, независимые сессии.
- `journey-tasks.mjs` — тексты, варианты действий, проверка 34 этапов.
- `journey-icons.mjs` / `journey.css` — единые векторные пиктограммы и интерфейс.
- `public/config/client-missions.json` — названия и состав клиентских миссий.
- `webgl-field.js` — исходные изогнутые волокна и частицы; прежние цифровые модели скрыты через hideNodes. Journey-профиль в journey-links.mjs:5 волокон/80 сегментов/32 частицы,3.25 волны,flowSpeed0.19. Тонкий core0.006 world units/intensity1.15 сохраняет яркостной запас для частиц; spread0.008/amplitude0.018 адаптированы к плоскому экрану.

localStorage `max-journey-v1:{wall|web}:{single|two}` содержит массив сессий. В каждой runs хранит позиции, этап и done объектов; completed восстанавливается из подтверждённых этапов, а не доверяется сохранённому массиву. После перезагрузки показывается CTA с сохранённым прогрессом. Нет серверного профиля, аналитики и передачи действий игрока. Приватный режим может ограничивать сохранение; в памяти игра продолжает работать.

## Мастер и геометрия

Сервис `max-wall-right`; полный фон 4096×1280, игровая часть только на длинном прямом участке. Режим single: одна зона; two: две независимые сессии. Выбор в presentation, вне игровой полосы. Полные UI-области находятся в Y615…1020, что соответствует 1.00–1.80 м текущей модели. Аппаратная LED/LiDAR-калибровка остаётся отдельной проверкой.

`data-game-ready`, `data-glass-revision` и сообщение родителя `max-service-state` сохранены. Режим/пауза принимаются только от same-origin parent. Отменённые и перемещённые жесты не превращаются в нажатия. Кнопки доступны с клавиатуры.

Мастер рисует общую подложку, затем десять световых градиентных волн отдельным проходом в экранном разрешении, затем реальное преломление MaxPanelGlass и foreground игры. Координаты волн берутся из renderRect тайла с halo; rect без halo даёт швы. Дополнительных RT для волн нет. Пиксели/сетка/Earth не возвращаются. Цвета — проектная палитра MAX; белое ядро и мягкие ореолы аналитические, а не новый full-scene bloom. Пауза/reduced-motion сохраняются.

Standalone использует wave shader и общий PANEL_GLASS_FRAGMENT через journey-background.mjs. Один linear HalfFloat RT хранит фон, следующий проход преломляет его под панелью и размывает под кнопками. DOM-текст/иконки композятся позже. Размер RT ограничен1600px и2.56Mpx; mip-цепочка добавляет около трети памяти текстуры. Параметры берутся из тех же раздельных пользовательских профилей, bounds/радиусы пересчитываются из реального DOM при revision/resize. Кнопки: Frost56.25 → проектная калибровка9logicalpx, фильтрованные mip-уровниLOD≤3 и9 взвешенных выборок. Большая панель:Frost0, Depth116.91, преломление и линза. Это адаптация референса, не точное численное воспроизведение Figma.
