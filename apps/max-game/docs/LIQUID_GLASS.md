# Стекло MAX

29.09.2026 — по запросу пользователя **матовые поверхности переведены на мягкий blur** (`overlapping-mip-blur-v2`). Общий BACKDROP_BLUR_GLSL фильтрует фон, волокна+bloom и UI за попапом четырьмя перекрывающимися bilinear-выборками mip-текстуры вместо девяти разнесённых копий. Преломление под матовыми контролами удалено; прозрачная внешняя панель сохраняет свой материал. LOD зависит от native-разрешения и масштаба карточки, максимум5; консервативный охват≤56native px помещается в halo64. Новых RT/проходов/RAF нет, текущий UI-target переиспользуется. Резкие текст/знак/кнопки рисуются после blur. Это заменяет описанную ниже WEB-калибровку9taps/LOD4; исходные числа Figma сохранены. [Проверка и ограничения](../../../artifacts/reports/max-smooth-blur-20260929/README.md).

29.09.2026 — выбранная летящая плитка имеет приоритет Frost над остальным пикером и полем. Маски с opacity≤0.001 исключаются до лимита20: скрытый круглый next-plus больше не оставляет круглую область внутри квадратной иконки.

28.09.2026 — контекст задания: выбранная плитка остаётся единственным видимым экземпляром и фиксирует текущую позу; скрывается только её подпись. Остальные узлы плавно приглушаются до45%, фон не затемняется. Карточка раскрывается вокруг исходной плитки, скрытый task-icon служит только layout-якорем. objectContextPresence общий для foreground и оптики. Карточка сильнее матовая:36logical px (WEB-калибровка поверх референса Frost56.25). JourneyContextGlass размывает реальный UI под ней/телефоном: один переиспользуемый RGBA8 mipmapped RT, прогретый вместе с шейдером при загрузке в существующем renderer; без открытого задания дополнительного прохода нет. Sharp popup рисуется после фильтра, выбранная плитка — последним слоем. Профили — glass-profiles.json/contextCard.

28.09.2026 — оптическая маска учитывает общую видимость зоны, CSS-opacity родителей и ui-fade перелёта. #circles opacity0 относится только к DOM-input и не гасит WebGL. При открытом picker стекло оставшихся объектов сохраняется с opacity0.08; task/reset исключают перекрытые контролы после общего ухода поля.

Профили пользователя записаны в [glass-profiles.json](../../../artifacts/DESIGN/BRANDS/MAX/glass-profiles.json), правила работы — [max-liquid-glass](../../../artifacts/skills/max-liquid-glass/SKILL.md). Панель: Light −68°/70%, Refraction100, Depth116.91, Frost0. Кнопки: Light −45°/80%, Refraction100, Depth33.47, Frost56.25. Dispersion/Splay0 у обоих.

WEB-калибровка не является переводом единиц Figma. Контролы: радиус матирования18 local design px,9 весовых taps, mip LOD≤4, transmission0.72, violetTint0.24. В standalone design ширина1600/900, в сервисе4096. Значения и исходные профили экспортирует `artifacts/service/public/max-panel-optics.js`; тест сверяет их с JSON. Цвета MAX, границы/интенсивность контуров — художественная адаптация.

Фон и clear-панель рисуются существующим MaxPanelGlass (standalone использует тот же shader). Его frosted-контролы фильтруют фактический фон. Волокна и их bloom собираются в существующий линейный HDR target поля. JourneyFiberGlass фильтрует этот слой по тем же control bounds, затем рисуются резкие UI-знаки, подписи и badge. Резкой копии волокон поверх Frost нет.

Эта декомпозиция нужна для мастера, где фон и iframe игры имеют разные WebGL-контексты. Передачи текстуры через CPU нет. Связи располагаются над большой панелью, под кнопками; Frost панели остаётся0. Не считать две независимые текстуры одним физическим объёмом стекла.

Стоимость: переиспользованный HDR/MSAA target с mipmaps, один fullscreen compositor вместо прежнего OutputPass,9 texture samples только в footprint контролов. Дополнительного RT, контекста или RAF нет. Без связей Journey пропускает пустую цепочку HDR/bloom/compositor. Геометрия/материал compositor создаются один раз, размеры следуют resize существующего поля, освобождение через foreground.dispose. Background target standalone и RT мастера существовали до этой итерации.

HDR очищается в transparent black; RGBA фильтруется premultiplied, output переводится в sRGB однократно. Bounds читаются по glassRevision; standalone радиусы приводятся из local design px к4096, как координаты. Tile offsets фона остаются ограничены56 native px при halo64. Меню/задания исключают закрытые ими контролы.

Известные пределы: широкие фоновые градиенты сами по себе плохо демонстрируют blur, поэтому проверка включает тонкие яркие волокна. Числа профиля не гарантируют пиксельное совпадение с внутренним Figma renderer. Аппаратная производительность стенда и художественная приёмка отдельно. [Проверка реализации](../../../artifacts/reports/max-frost-layering-20260928/README.md).
