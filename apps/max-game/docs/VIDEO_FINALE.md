# Видео вместо QR в автомиссиях MAX

В local WebGL V5 меню есть флажок **«Видео вместо QR в автомиссиях»**. По умолчанию выключен; выбор сохраняется отдельно от прогресса, недоступность localStorage не мешает текущему сеансу.

URL `webgl-v5/client.html?backend=local&autoplay=communication&finale=videos` включает вариант по прямой ссылке. `finale=qr` явно отключает его для текущей загрузки. URL параметр имеет приоритет над сохранённым выбором при загрузке; checkbox меняет текущую сессию/предпочтение.

После финального задания любой автоматической миссии открывается один полноэкранный плеер. 11 роликов последовательно; после №11 — №1. Следующая миссия никогда не запускается из окончания видео. «К миссиям» завершает просмотр, освобождает player и возвращает обычное меню в том же экземпляре игры.

Пауза, звук, перемотка, выбор ролика и «Следующий ролик» доступны в player. При запрете автозапуска нажать «Воспроизвести». Ошибка ролика останавливает автоматическую смену, доступны повтор/следующий/выход. При скрытии вкладки воспроизведение останавливается; видимость возобновляет только ранее играющее или ожидавшее первичного запуска видео.

Во время подборки игра не принимает ввод, WebGL/ambient приостановлены, игровые звуки остановлены. Видеозвук наследует mute игры при входе; controls видео независимы и не перезаписывают пользовательский mute игры. Обычные миссии, QR выключенного режима, разметка и backend остаются прежними.

## Источники и сборка

- `artifacts/max-game/src/journey-v5-finale.mjs`: опция, граница завершения, import/cancel.
- `journey-v5-finale-player.mjs`: Video.js/playlist lifecycle.
- `public/webgl-v5/finale-videos/manifest.json`: исходные имена, порядок, длительности, SHA обоих вариантов.
- `scripts/build-video-finale.mjs`: отдельный ленивый bundle + CSS/licenses; общий сервер включает range-parser и не требует node_modules в runtime.
- `node artifacts/max-game/scripts/build-webgl-v5-runtime.mjs`: scoped rebuild; полный builder также включает video bundle/server.

Пакет содержит H.264/AAC MP4 1920×1080/25fps faststart, 140.68 MiB суммарно. Видео не участвует в стартовом asset warmup. Хостинг должен обслуживать `.mp4` как `video/mp4` и HTTP byte ranges. Встроенный сервер поддерживает HEAD/200/206/416; multipart Range игнорируется с 200. SHA-query меняется вместе с файлом; cache max-age=3600. Source/runtime MP4 используют существующее правило Git LFS.

Для master-интегратора: изменение только независимого MAX-Game, в service режиме видеоконтроллер не монтируется. Defaults off; миграций прогресса/БД нет. Новые зависимости закреплены в package-lock, лицензии в webgl-v5/licenses. Перенос в F, публикация и долгий/физический iPhone прогон не выполнены.
