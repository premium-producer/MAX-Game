# Звук WebGL v5

Howler 2.2.4 загружает фиксированный набор из 16 пользовательских SFX один раз на документ. Локальные manual/auto переключения сохраняют тот же аудиоконтроллер. Звук включается первым реальным касанием/клавишей либо кнопкой «Включить звук» справа внизу. Кнопка также выключает звук. Прямая ссылка на автопрохождение без жеста остаётся беззвучной.

| Событие | Имя исходного WAV без game_ |
|---|---|
| UI click | button_click_1/2/3, случайный вариант |
| Захват иконки | icon_grab_1/2 |
| Захват устройства | phone_grab_1 |
| Удержание ладони/иконки/устройства | icon_hold_loop |
| Подтверждение удержания / появление shell | transition_handscreen |
| Расстановка ряда / repack | transition_icons |
| Первое проявление каждой иконки в run | icon_pop |
| Связь между иконками | enengy_stream_1 |
| Веер к устройству | enengy_stream_2 |
| Первый готовый экран задания | phonescreen_activate |
| Следующий готовый экран | phonescreen_reactivate |
| Отпускание перемещённого объекта | icons_deselect |
| Общая атмосфера | ambience_loop |

Поддерживается максимум 5 одновременно активных коротких SFX плюс два актуальных loop. После смены run прежние эффекты останавливаются; принятый UI click может закончиться. Blur/hidden/service pause/mute останавливают звуки; после возврата не доигрываются пропущенные cues. Удержание прекращается при отпускании/cancel. Pagehide unload освобождает все Howl.

Howler.ctx.state проверяется до отправки play, чтобы suspended context не накопил старые SFX. Актуальные loops восстанавливаются после resume/unlock. Ошибка отдельного файла не блокирует игру. Диагностика html[data-audio]: loaded/total, played, errors, activated, muted, active, running, loops.

Service-режим не создаёт самостоятельный звук: включение звука в мастер требует отдельного согласования маршрутизации. Обычный v5 wall/client поддерживается; прежние renderer не изменены. Профили backend, разметка и сохранения не менялись.

Исходные WAV: artifacts/max-game/audio-source/20261004. Ogg/MP3: artifacts/max-game/public/webgl-v5/audio. Scoped builder включает их в build.json с SHA и обновляет start.mjs с MIME audio/ogg и audio/mpeg, проверяя прежний manifest. На сервере после обновления start.mjs процесс надо перезапустить. Текущий preview: localhost:19446.

Начальные уровни: ambience .22, hold .25, остальные .35–.5. Это отправная точка для пользовательской оценки, не утверждённый микс. Лицензия пользовательских аудио не объявляется MIT; MIT относится к Howler.
