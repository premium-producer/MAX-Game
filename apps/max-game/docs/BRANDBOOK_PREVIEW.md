# Локальная страница официального брендбука MAX

Рядом доступно [полное превью MAX для бизнеса](BUSINESS_PREVIEW.md): `http://localhost:8770/max-game/business/index.html`. Изолированный сборщик поддерживает `business` как аргумент; вызов без аргумента по-прежнему собирает только брендбук.

Полная страница `https://go.max.ru/brandbook` сохранена как отдельное превью, не связанное с состояниями игры или рендером стенда.

Адрес на работающем локальном сервере: **http://localhost:8770/max-game/brandbook/index.html**. При уже запущенном standalone8785: `http://localhost:8785/brandbook/index.html`. Отдельный сервер для этой страницы не требуется.

Воссозданы исходные разделы: шапка, четыре верхние карточки, восемь карточек логотипов, шесть цветов, четыре градиентных примера, две контактные карточки и футер. Оригинальные HTML/SVG/CSS, изображения и пять WOFF2 сохранены локально. CSS-свечение и градиентные анимации исходные; копирование цветов, мобильное меню и touch-раскрытие скачивания подключены локальным модулем. Скачивание семи вариантов и общего ZIP работает локально. Внутренне архивы имеют расширение `.bin`, поддерживаемое сервером, и сохраняются пользователю как `.zip` через `download`.

Связанные другие сайты MAX, Figma-гайды и техническая документация остаются внешними ссылками. Это полная локальная страница брендбука, а не копия всех сайтов MAX. Маркетинговая аналитика и оригинальная Svelte hydration не запускаются; исходная разметка и scoped-стили сохранены. Локальный модуль добавляет reduced motion. Цвета сайта сохраняются как оригинальные, не нормализуются автоматически к игровой палитре.

## Воспроизведение

Исходники: `artifacts/max-game/public/brandbook/`. Сохранённые официальные входы: `docs/Research/max-brandbook-site-20261001/sources/`.

```powershell
py -3 artifacts/max-game/scripts/prepare-brandbook.py
py -3 artifacts/web/tools/check_project_duplicates.py
node artifacts/max-game/scripts/build-brandbook.mjs
```

Подготовщик сохраняет `local.mjs` и `local.css`, переписывает страницу/оригинальные стили/ассеты из архивных источников. Изолированный сборщик обновляет только `apps/max-game/brandbook/`, проверяет пользовательские правки по собственному `build.json`. Основная MAX-сборка также включает этот каталог через стандартный обход `public/`. Прогресс игры, игровые bundle/CSS, источники мастера и назначения не меняются. Для новых файлов не требуется перезапуск действующего HTTP-сервера.

[Проверка комплекта](../../../artifacts/reports/max-brandbook-site-20261001/local-page-checks.json), [проверка28HTTP-хешей](../../../artifacts/reports/max-brandbook-site-20261001/local-http-checks.json), [исследование источника](../../../docs/Research/max-brandbook-site-20261001/README.md). Визуальный обход локальной страницы агентом не выполнялся; пользователь проверяет скругления/свечение, градиенты, копирование цветов, скачивание и мобильную компоновку.
