## Контракты кода

`public/config/client-missions.json`: названия, пояснения, result и массивы requires. Это единственный активный источник текста результатов. `journey-tasks.mjs`: шаги и taskFor(object), адаптирующий текст после выбора. `journey-state.mjs`: planningSteps для предварительной расстановки; availableSteps для выполнения; canPlanBusiness/canChooseBusiness для соответствующих стадий. Reducer проверяет BEGIN_ROUTE/PLACE/CONTINUE_ROUTE/OPEN/ANSWER/BRANCH. Игровые связи и свободное перемещение не считаются зависимостями задания.

Новые сессии имеют branch=null; branchChosen сохраняется только после выбора. Каждый объект хранит проверяемые answers по этапам. Восстановление старого version1 сохраняет координаты и корректно завершённые этапы, но сбрасывает прогресс зависимой задачи, если обязательная предыдущая не завершена. Старый неявный channel не считается выбором, если соответствующий объект не был размещён. Завершения пересчитываются; некорректные answers заменяются допустимым значением.
