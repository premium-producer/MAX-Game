## Палитра и расхождения

Публичная страница указывает `#471AFF` / RGB71,26,255, `#9500FF`, `#FFFFFF`, `#00BFFF`, `#6E1AFF`, `#0D001A`. Набор совпадает с действующим проектным `project-palette.json`. Сайт даёт согласованную пару HEX/RGB для синего; старый конфликт Figma остаётся историческим фактом. На просмотренной странице Figma цветовая плашка синего визуально расходится с напечатанным HEX, поэтому конфликт иллюстрации не считаем исправленным.

CSS линейного градиента сайта использует дополнительные остановки `#00CCFF`, `#007AFF`, `#630EFF`, `#AA4CFF`; фон ряда карточек — нейтральный тёмный. Это фактические значения реализации сайта, не разрешение автоматически расширить палитру игры. Не переносить сайт целиком как единственный нормативный образец.

## Что помогает привести игровые плашки к стилю MAX

Наблюдение за сайтом: крупные скругления, сдержанная тонкая кромка, локальный мягкий цветовой акцент, белая типографика Max Sans, ясное разделение основного и вспомогательного текста. На просмотренном desktop-viewport карточка сайта имеет radius48px, заголовок карточки28px, главный заголовок72px; эти числа относятся к сайту и не являются нормами LED-стенда. Заголовки сайта используют вес500, тексты карточек400. Существующие правила типографики из брендового экспорта сохраняют собственную область применения.

Для плашки игры256×256 применимы: цельный оригинальный знак, сохранение его пропорций, белая читаемая подпись, спокойный материал и свечение, которое не растворяет текст. Раскладка «верхние две трети — знак, нижняя треть — подпись», ×2 и размер шрифта задаются пользователем и носителем; это авторская адаптация, не цитата брендбука. Размещение текста внутри плашки уже реализовано в предыдущей итерации, художественная оценка пользователя пока не получена. Новые материалы в этой итерации в игру не включались.

## Полученные файлы и повторное использование

По последующему запросу о готовых решениях выделен [реальный блок карточки сайта](../../../artifacts/DESIGN/BRANDS/MAX/components/official-site-card/README.md): точный HTML, стили с responsive/keyframes и локальная иллюстрация. Он содержит готовые пропорции, кромку и мягкое орбитальное свечение. CSS-эффект работает без Svelte runtime; зависимости темы, прямые hover-переключения, reduced motion и цвета требуют адаптации при интеграции. Для WebGL-иконок копирование DOM-блока не заменяет переноса эффекта в существующий renderer.

Оригинальные HTML/CSS, ZIP, PNG и пять шрифтов сохранены в `sources/` с SHA-256. В `artifacts/DESIGN/BRANDS/MAX/assets/official-web-20261001/` лежит отдельный набор из7SVG,5WOFF2 и одного PNG. Для каждого файла в `official-web-source.json` указаны URL, хеш, исходное имя и ограничения. Старые канонические ассеты и токены не заменены. Полноцветный знак нельзя перекрашивать по шестицветной игровой палитре: он остаётся оригинальным брендовым ресурсом.

## Проверка и ограничения

ZIP CRC, XML, внутренние SVG-ссылки и отсутствие скриптов/внешних SVG-зависимостей проверены. WOFF2 проверены по сигнатуре и хешу; полнота глифов и загрузка этих новых файлов в игре не проверялись. Визуально просмотрены официальный сайт, две связанные страницы публичного Figma-прототипа, цветовая таблица и оригинальный PNG. Ни техническая целостность, ни публичность источника не означают утверждение игрового UI владельцем бренда. Браузерные вкладки игры не открывались.
