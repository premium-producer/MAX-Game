# Источники страницы Цифрового ID MAX — 01.10.2026

Публичная страница [go.max.ru/digitalId](https://go.max.ru/digitalId) сохранена по запросу пользователя для локального воспроизведения. Оригинальные HTML и JS страницы не менялись в архиве. [asset-manifest.json](sources/asset-manifest.json) содержит URL/SHA21успешно полученного ресурса и один404; [source-derivations.json](sources/source-derivations.json) фиксирует происхождение FAQ, QR и кадра видео.

SSR разметка содержит вопросы FAQ, а ответы и desktop-QR-модал находятся в публичном JS. Из него извлечены четыре HTML-ответа, исходный SVG-код и модальная разметка. Графика включает дваMP4972×2160, рамку и статичные постеры. URL постера создания возвращает404; для рабочей копии использован первый кадр соответствующего MP4. Третий video-элемент имеет пустой src и служит статичным экраном.

[Локальная адаптация](../../../apps/max-game/docs/DIGITAL_ID_PREVIEW.md), [проверки](../../../artifacts/reports/max-digital-id-site-20261001/README.md). Содержимое отражает публичный сайт на момент получения; продуктовые ограничения и требования сайта не переносились в игровую механику как новые правила.
