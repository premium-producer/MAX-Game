# MAX v5 — удержание, оболочка, логотип и ряд

03.10.2026. Последнее уточнение: телефон появляется только после подтверждённых0.8с, затем остаётся; логотип MAX проявляется после оболочки одновременно со stagger-иконками. Это заменяет preview во время удержания из phone-first.

## Проверенная готовая основа

Сохраняем installed maath0.10.8 MIT: damp для прозрачности оболочки/логотипа и имеющийся sine.inOut для пути иконок. [Репозиторий](https://github.com/pmndrs/maath) сейчас перенаправляет на pmndrs/math; API берётся из установленной версии, пакет не обновляется. [Реальный пользовательский опыт issue33](https://github.com/pmndrs/maath/issues/33) описывает телепортацию при подстановке неподходящего easing в damp. Оставляем штатный damp, новый интерполятор не пишем.

Three.js0.185.1 MIT уже рисует прозрачность в едином renderer. [Официальный Material](https://threejs.org/docs/pages/Material.html) документирует opacity/transparent. Имеющийся moving group для data-task-content принимает data-path-presence и передаёт alpha материалам; используем его для оригинального SVG логотипа, без новой текстуры каждого кадра. host.contentPresence остаётся собственностью V5DeviceMorph.

## Интеграция

Backend scan остаётся единственным подтверждением. Presentation начинается stage shell только в accept(scanned), затем ждёт deviceShown (фактическая прозрачность и положение) и decode/GPU-ready. Общий settled не используется на этом этапе: иконки ещё не созданы. Время путей и logo alpha стоят0. На следующей фазе logo damp и stagger начинают движение вместе; дальше сохраняются trace→fan→content и постоянная оболочка.

Это настройка очередности поверх существующих библиотек и backend, без второго clock/таймеров. До подтверждения ранний отпуск ничего не создаёт. После подтверждения отпуск не отменяет старт. Reset/смена контекста очищают startup как прежде.

## Ограничения

CPU проверяет backend/controller и реальные motion primitives, не GPU-изображение. Рисование data-path-presence сверено по коду renderer независимым агентом; визуальная приёмка пользователем остаётся открытой. [Проверка](../../artifacts/reports/max-v5-hold-shell-logo-20261003.md).
