# MAX: неразрывные термины, пустая справка и будущие иконки

06.10.2026, MAX-UI-COPY-20261006-R1. Узкая UI-итерация по трём снимкам пользователя, без изменения игровых правил. Применены max-game-development, max-interaction-motion и правила MAX; исходные изображения сохранены с SHA в каталоге задачи references.

Готовый механизм переноса — нативная CSS раскладка браузера, используемая существующим DOM Range → WebGL текстовым трактом. Новая библиотека/алгоритм разбиения строк не добавлены. [MDN white-space](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/white-space) описывает запрет переноса через nowrap; [word-break](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/word-break) и [overflow-wrap](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow-wrap) управляют разрывами слов. Использован неразрывный пробел U+00A0 в «Цифровой ID» плюс локальный nowrap span; дефис в «видео-сообщение» защищён тем же span. Другие слова продолжают переноситься. Это свойства браузера, не npm-зависимости; документация не копируется в поставку.

Ограничение из [MDN hidden](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/hidden): явный CSS display способен отменить скрытое состояние. Поэтому локальный селектор instruction[hidden] получает display:none!important. Сам DOM-контейнер остаётся: принятый startup warmup и syncPopup обращаются к нему безусловно.

Фактический опыт текущего движка: простого invalidate при смене hidden недостаточно. Connected GPU owners с той же sceneVersion сохраняются rebuild; повторный показ может пропустить текст, а скрытие оставить прежнюю группу. Независимый аудит нашёл это до передачи. При text→empty→text refreshPart(mounted) помечает popup и его потомков для пересборки, cancelInstruction снимает старую motion высоты. Контент устройства обновляется прежним владельцем.

Появление следующей иконки использует уже установленный maath0.10.8/MIT damp через V5MotionValue и существующий clock/V5_MOTION. Будущие узлы сохраняются в DOM/Flexbox/layout/графе, но presentation presence равна0; inert синхронизируется существующим updateTargets. На handoff новая иконка допускается только после смены отображаемой задачи на exit→pack, а не по опережающему backend snapshot. Пройденные узлы остаются видимыми. Новый RAF, таймер, физика и игровой reducer не вводятся.

Ширина справки выросла с520 до760 логических px, ограниченных свободным местом до правого края. Очень близкое ручное перемещение устройства к краю может оставить меньше места, чем длина неразрывного слова; оценка визуального fit требует пользовательского просмотра. Это не утверждение об отсутствии клиппинга при любой произвольной позе.

Версии client и managed stand проверены отдельно; client baseline воспроизведён исходным esbuild с побайтовым совпадением. Исходники server/backend/catalog/flow и медиа сохранены. Снимок Safari показывает дефект, но версия сервера по фото неизвестна; текущий сервер не читался. Браузерная проверка запрещена пользователем, технические CPU/сборочные доказательства не заменяют художественную приёмку.
