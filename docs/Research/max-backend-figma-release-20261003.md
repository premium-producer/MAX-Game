# MAX: контентный релиз из принятой структуры Figma

Источник: полная выгрузка `2026-10-03_15-19-16`, 4 миссии, 15 заданий, 84 экрана и 19 иконок. Доставка подтверждена [аудитом](../../artifacts/reports/max-content-export-audit-20261003-151916.md). Предыдущий глобальный поиск дал 23 ложные миссии; legacy coverage остаётся нулевым. Поэтому принимается только contentMap с проверкой соответствия каждой строки и файла, а не coverage/имена фреймов.

Используются существующие Mission Core, SessionPort, assertMissionCatalog, assertTaskCatalog и collectSharedBackendFiles. Новое ядро, HTTP-сервис, persistence, renderer и механизм миграции не создаются. Конвертер — явное сопоставление данных этой версии: порядок миссий/иконок/строк → смысловые IDs. Старая версия остаётся рабочей; отдельный ESM-комплект получает новые contentRevision.

Публичная/приватная ветки канала сохраняют исходные команды ядра и геометрию hotspots, масштабированную в пиксели новых PNG. Дополнительный экран результата включается перед зачётом. Другие последовательности берутся из новой карты; существующие подходящие действия/ветка биометрии сохраняются, новым экранам задаётся один переход внутри устройства. В выгрузке нет отдельного экспорта кнопок, поэтому неизвестные hit-targets не выдумываются: допустимая кнопка ниже изображения сохраняет интерактивность. Такая адаптация не подтверждает художественную точность попаданий в Figma UI.

Служебные строки «текст убран»/«Текст справки удалён по комментарию клиента» превращаются в пустую инструкцию. «Без текста, продолжение прошлого экрана» также не выводится игроку. Оригинал и текстовые blocks сохраняются в provenance. Изображения не перерисовываются. Четыре миссии — состав этого релиза; тестовые миссии остаются в предыдущем каталоге, но не выдумываются из отсутствующих в выгрузке данных. Общий финал с существующим QR сохраняется.

Готовые механизмы файловой сборки: Node.js `fs/promises`, `crypto.createHash` (поставляются Node по его лицензии, сторонний код не копируется). [Официальная fs документация](https://nodejs.org/api/fs.html#fspromisescopyfilesrc-dest-mode), [SHA-256](https://nodejs.org/api/crypto.html#cryptocreatehashalgorithm-options). Файлы копируются с проверкой SHA из журнала; manifest выпускает существующий сборщик. Реальный опыт отказа Windows rename и проверенное решение описаны в [исследовании сохранения экспорта](figma-export-windows-write-20261003.md); новый атомарный writer здесь не создаётся, публикация/перезапись пользовательских сохранений не выполняются.

Ограничение: комплект и CPU-прогон подтверждают смысловое прохождение и ссылки на контент; пользовательская визуальная приёмка и подключение к активной игре — отдельный шаг.
