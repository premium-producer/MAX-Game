# Публичная страница MAX для авторов

Источник: https://go.max.ru/authors, сохранён 01.10.2026. `sources/page.html` — неизменённая SSR-страница; `sources/asset-manifest.json` фиксирует 47 загрузок с URL/SHA, включая исходный JS. `sources/hidden-content.json` содержит три инструкции создания канала и 13 FAQ, извлечённых из публичного JS. Сохранены ролики для публичного, приватного и бизнес-канала, исходные иллюстрации десяти инструментов, стили и шрифты.

Копия сохраняет исходную композицию и CSS-эффекты для дальнейшего изучения готовых блоков. Полный Svelte runtime заменён узким локальным UI; аналитика исключена. Это образец публичного лендинга, не изменение брендовых правил и не интеграция в игру.
