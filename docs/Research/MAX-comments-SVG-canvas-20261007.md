# MAX — чёрный экран комментариев, 07.10.2026

Затронутый этап: blogger.comments.post, инструкция «Начинаем общение с подписчиками – переходим к комментариям!». Авторитетный каталог содержит изображение и hotspot «Комментарии», исходный flow не имеет отсутствующего экрана. HTTP локального сервера возвращает исходные SVG с правильным SHA и MIME. В client.html указан base href="../", поэтому относительные assets URL корректны.

Все пять поставленных SVG комментариев содержат foreignObject с пустым HTML div и backdrop-filter из экспорта Figma. Их HTML не содержит текста или фотографий. Это отдельный риск совместимости: авторы браузерных движков описывают загрязнение canvas при загрузке SVG с foreignObject через обычный URL в [WHATWG/html #10641](https://github.com/whatwg/html/issues/10641). Общие ограничения origin-clean описаны в [HTML Standard](https://html.spec.whatwg.org/multipage/canvas.html#security-with-canvas-elements).

В проекте изображение рисуется на canvas, затем загружается в CanvasTexture. Установленная Three.js r185 перехватывает исключение texImage2D внутри WebGLState, поэтому возврат initTexture сам по себе не гарантирует успешную загрузку пикселей. Это согласуется с пользовательским чёрным экраном; реальная браузерная диагностика не запускалась из-за действующего ограничения проекта.

Исправление использует существующую загрузку и переходы: из рабочих SVG комментариев удаляются только пустые служебные foreignObject blur-слои, сохраняются остальные SVG-байты, встроенные изображения, viewBox и размеры. Оригиналы пользователя не изменяются. Новый экран Цифрового ID также содержит семь видимых HTML conic-gradient слоёв: они заменены детерминированными встроенными PNG-заливками с сохранением исходных трансформаций и масок, а пустой blur удалён. Фотография, векторные пути, документы, QR и навигация сохраняются. Readiness или блокировки ввода ради обхода чёрного экрана не отключаются.

Проверка: самостоятельный CPU-проход настоящего backend, действия комментариев и их области; структура и растеризация подготовленных SVG; проверка SHA/HTTP после сборки. Эти проверки не заменяют визуальную оценку пользователем.
