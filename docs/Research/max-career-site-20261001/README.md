# Публичная карьерная страница MAX

Источник: https://team.vk.company/career-max/, сохранён 01.10.2026. Неизменённая страница — `sources/page.html`; `sources/asset-manifest.json` содержит 38 загрузок с URL/SHA. Сохранены графика, шрифты, стили, два MP4 и исходный UI-скрипт. `sources/vacancies.json` — снимок публичного API; как в оригинале, он определяет видимость авторских карточек вакансий.

Оригинальная хореография прокрутки адаптирована с теми же локальными GSAP/ScrollTrigger. Cookies, аналитика, отправка резюме и CAPTCHA исключены; вакансии и внешние сервисы открываются на официальном сайте. Скрытый в источнике видеораздел не активируется. Это локальный образец публичной страницы, не постоянно обновляемая кадровая платформа.
