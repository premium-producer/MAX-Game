# Источники публичной страницы MAX для бизнеса — 01.10.2026

По запросу пользователя сохранена публичная страница [business.max.ru](https://business.max.ru/) и необходимые материалы для локального воспроизведения. `sources/business.html` — неизменённый вход; `style-base.css`, `style-page.css` — оригинальные стили; `animate-original.js` и `main-original.js` — просмотренные UI-скрипты. Они применяют меню, container sizing, параллакс, IntersectionObserver-раскрытие и pointer-градиенты; не являются игровой state machine.

[asset-manifest.json](sources/asset-manifest.json) фиксирует URL/SHA/размеры38полученных изображений и шрифтов. ИсходныеPNG/WebP, включая адаптивные варианты, сохранены побайтово. Список обнаруженных URL — `sources/asset-urls.json`; AVIF/ICO не получены, локальная страница использует оригинальные fallback WebP/PNG и SVG-favicon. Оригинальные маркетинговые тексты, графика и CSS-цвета сохранены как источник, а не автоматически принятые правила игрового UI.

Рабочая копия, сборка и отклонения описаны в [документации приложения](../../../apps/max-game/docs/BUSINESS_PREVIEW.md); проверки — в [отчёте](../../../artifacts/reports/max-business-site-20261001/README.md). Восемь публичных разделов скопированы; личный кабинет, регистрация и связанные внешние сайты не входят в копию.
