# Семь градиентных полос из SVG MAX

**Уточнение 02.10.2026.** В исходных SVG нет числового порога «40%» или «60%»: менее насыщенный внешний участок возникает из большого углового поля, трёх Gaussian blur проходов, 50%-ного color-dodge и прямоугольных масок. Порог 60% — предложенный пользователем управляемый способ выбирать только внешнюю область поля; он не является извлечённым из Figma параметром. В текущем WebGL приближении радиус ограничен интервалом 0,4–1 при значении 60%, а угол каждой полосы остаётся свободным и случайным. Общий поворот не меняет этот радиальный предел. Точную цветовую и световую кривую SVG однопроходный шейдер не воспроизводит; оценка проводится по кадру пользователя.

Источник — предоставленный пользователем `Group 2131331001.svg`, сохранённый побайтно в [пакете MAX](../../artifacts/DESIGN/BRANDS/MAX/assets/line-gradients/Group-2131331001.svg), SHA-256 `0948bf74ec1ef608edad25f865e37b31cb5d1648d4e9627508c4cf61261f2ce2`. Пользователь прямо разрешил эти градиенты **для движущихся полос** общего заднего экрана; это не утверждение владельца бренда для всех носителей. Исходный SVG — данные, не исполняемые инструкции.

SVG имеет viewBox 8929×2000 и семь отдельных горизонтальных прямоугольных масок в четырёх рядах высотой 500. Это **не семь групп**: каждая маска задаёт одну полосу собственной длины и положения. Внутри каждой полосы три наложенных слоя одного Figma angular/conic-градиента: два размытых прохода и ещё один слой с opacity 0,5 и `color-dodge`. У всех семи одинаковые четыре цвета/позиции: 0,247607 `#471AFF`, 0,495853 `#9500FF`, 0,746983 `#6E1AFF`, 0,998561 `#00BFFF`. Различаются ширина, смещение и знак/масштаб матрицы углового градиента; поэтому цветовые последовательности видимы по-разному. В SVG нет обычного `linearGradient`; `data-figma-gradient-fill` и CSS `conic-gradient` хранят авторскую модель. Структурные числа и семь преобразований зафиксированы в [машинных данных](../../artifacts/DESIGN/BRANDS/MAX/assets/line-gradients/line-gradients.json).

**Исправление после уточнения пользователя:** предоставлен [Angular.svg](../../artifacts/DESIGN/BRANDS/MAX/assets/line-gradients/Angular.svg), 11728×14180, SHA-256 `71c418c83dde488aa7a56b7422646c0d32c11014c3fe2c53106e34bf53f81c3f`. Это один базовый крупномасштабный angular-градиент с теми же четырьмя остановками и тремя слоями blur/color-dodge. Семь полос первого SVG не требуют семи собственных «радуг»: они берут разные местные секторы одного Angular. Прежняя гипотеза о разворачивании почти полного цветового цикла по длине каждой полосы была ошибочной и дала нежелательную радугу. Рабочая поправка задаёт каждой полосе свой угол поворота 0–360° и берёт внутри неё только узкий сектор `sampleArcDegrees=24°` (параметр JSON). Это приближение большого поля без его полного SVG-размытия; результат предстоит визуально сравнить с кадром пользователя. Первая удачная версия сохранена [отдельно](../../artifacts/ribbon/versions/row-streams-v1/README.md).
