# MAX — выбор верхней точки LiDAR

06.10.2026. Запрос: использовать самую верхнюю переданную точку как касание. Основа — установленный MAX-LIDAR-COMPACT-20261006-R1, control из immediate-tap R2; SHA сохранены в task/baseline.json. Новые зависимости не устанавливаются.

Готовый механизм приёма/декодирования: [osc.js](https://github.com/colinbdclark/osc.js), локально osc 2.4.5, MIT option (upstream также предлагает GPL). Документация Port API определяет событие osc как целое декодированное сообщение или bundle, а bundle/message порождаются затем для вложенных частей. Фактический src/osc-transports.js: decodeOSC сначала emits osc(packet, packetInfo), затем firePacketEvents. Новый адаптер подписывается только на osc: библиотека продолжает владеть UDP, бинарным декодированием и разбором вложенных bundle. Не вводится второй слушатель, парсер или движок калибровки.

Реальный опыт интеграции: сохранённая запись стенда от 06.10, 185 UDP пакетов от 10.0.0.11 в 9001, 935 OSC сообщений, create/update ID,X,Y и delete ID. Это переданные producer контактные точки; границы силуэта и вершины внутри одного контакта в этом протоколе отсутствуют. Поэтому верхняя точка выбирается из доступных контактных точек, без выдуманного восстановления силуэта. Официальный внешний опыт с именно этой программой producer не найден; основание совместимости — фактическая запись и установленный osc.js.

Калибровка остаётся perspective-transform из принятого компонента: минимум Y после её map/preview. При отсутствии solver для первичной калибровки используется raw Y, что явно обозначено fallback, а не подтверждённой ориентацией стены. Все конечные mapped точки участвуют, включая outside; прежний inside gate запрещает игровое касание вне экрана. Некорректная проекция не выбирается.

Выбор выполняется после целого пакета; delete/create внутри bundle не дают промежуточного отпускания. Пока существуют пригодные контакты, смена верхнего physical ID создаёт move одного стабильного gesture ID. Удаление всех контактов — up; отсутствие потока больше 350ms — cancel и quarantine до create/delete. При частичном timeout живой контакт остаётся тем же жестом. Context reset карантинирует все физические ID. Равный Y сохраняет прежнего победителя, первоначальная ничья разрешается меньшим ID. Не добавлены сглаживание/удержание/drag.

15 CPU проверок: оба профиля/некорректные пакеты/source fence, инвертированный raw Y через настоящий solver, неизменность settings, real osc.Port с дочерними событиями без дублей, смена/deletion/timeout/reset/close. Независимый аудит — task/audit/design-review.md. Реальный replay отдельно вычисляет минимум после каждого из 185 пакетов; результаты task/replay-topmost.json. Браузерная и физическая приёмка не заявляются.
