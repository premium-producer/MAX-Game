# MAX v5 — единая форма по ассету

03.10.2026. Пользователь отменяет разделение геометрии телефон/PC: размер изображения определяет внутренний viewport, сохраняются высота800, центр, morph и расстояния ряда.

## Источники и готовая реализация

Используются нативные CSS Flexbox и aspect-ratio; библиотека собственного layout не добавляется. [MDN aspect-ratio](https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio) описывает расчёт автоматического размера из отношения сторон; [object-fit](https://developer.mozilla.org/en-US/docs/Web/CSS/object-fit) — сохранение пропорций/вписывание. Canvas изображения уже содержит backend hotspots в процентных координатах: сохраняется один прямоугольник без cover/crop.

Существующий morph работает через maath0.10.8 MIT в Three.js0.185.1 MIT. [Опыт issue33](https://github.com/pmndrs/maath/issues/33) показывает риск подмены damp произвольным easing: настройки и механизм damp оставлены. [Предыдущее исследование](max-v5-hold-shell-logo-20261003.md).

## Найденные ограничения

84экрана,21вариант исходных размеров;75экранов имеют1–2кнопки под изображением. Простое width=800×ratio не устраняет зазор: padding и footer уменьшают высоту картинки. Пустой footer также создавалgap. Поэтому применяется единая оболочка с insetX10/insetY12; непустые строки кнопок96px, между ними10px, между изображением и кнопками18px. Это явная настройка интерфейса, не рекомендация библиотеки. Слишком длинные будущие подписи требуют отдельной проверки; текущиеactions максимум2.

innerHeight=776−footer, outerWidth=20+innerHeight×asset.width/asset.height. CSS и V5_DEVICE_FRAME согласованы. Пустой footer скрывается. Native aspect-ratio задаёт canvas; исходный renderer contain не искажает изображение. Kind сохраняется как metadata backend для совместимости, но не выбирает размеры или расположение кнопок. Missing/невалидныйasset даёт392×800; splash также392×800 независимо будущегоasset.

CPU проверяет контракт, браузерная художественная оценка остаётся необходимой. [Фактическая проверка](../../artifacts/reports/max-v5-asset-fit-20261003.md).
