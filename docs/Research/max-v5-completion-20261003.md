# MAX v5 — QR и переход к следующей миссии

03.10.2026. Пользователь: оставлять иконки на местах у QR, после «Продолжить» плавно скрывать их и запускать следующую миссию с ладони.

## Готовое основание

- [maath repository](https://github.com/pmndrs/maath): готовые interruptible damping primitives; установленная версия0.10.8, MIT. Используем существующий V5MotionValue→maath.damp и его velocity/rest контракт для прозрачности. Формулу не переписываем; второй ticker не добавляем.
- [Практический issue33](https://github.com/pmndrs/maath/issues/33): параметры easing/smoothTime/epsilon не следует оценивать только по конечному значению. Проверяем промежуточную монотонность и достижение покоя при30/60/120Гц; художественное восприятие остаётся пользовательской приёмкой.
- [Motion animate](https://motion.dev/docs/animate): готовая альтернатива с playback/cancel и await завершения. Новую зависимость не вводим: нужную анимацию уже выполняет установленный maath на общем WebGL-clock. Оркестрация команд — код приложения, а не новый анимационный движок.

До исправления SharedRevealJourney выключал spread в complete, сбрасывал layout на phone-exit, main возвращал камеру и освобождал held-иконки при закрытии справки. v5 теперь запоминает видимые позы по подтверждённому финальному результату, сохраняет held-объекты и камеру до закрытия QR. Обычные задания по-прежнему перестраиваются; repack происходит после подтверждения ответа.

Переход: maath fade→нулевая видимость→существующая команда SELECT_MISSION→подтверждённый snapshot→маath fade ладони. Если следующая миссия уже запускалась, RESTART_MISSION создаёт для неё новый запуск с ладонью; завершённая текущая миссия и другие сохранения остаются. После последней миссии RETURN_MENU. Повторное нажатие блокируется, pagehide отменяет устаревший callback, hidden останавливает fade. Схема backend/пакет не изменены.

[Проверка реализации](../../artifacts/reports/max-v5-completion-20261003.md). Ограничение: CPU проверяет maath и настоящий backend; browser/GPU-приёмка не проводилась по текущему правилу пользователя.
