# MAX v5 — перенос инструментов v4 и координаты захвата

03.10.2026. Пользователь повторно указал на сдвиг вниз при первом движении и отсутствие отладки, контроллера градиентов, выбора LiDAR/стена. Предыдущая проверка захвата не моделировала вложенное поле и не доказывала исправление реального первого движения.

## Готовые механизмы

1. Захват использует существующий native Pointer Capture и maath0.10.8 MIT, как в [предыдущем исследовании](max-v5-drag-anchor-20261003.md). Исправляется только связь model→retained pose: берётся разница текущей позиции с измеренной layout-целью. CSS `guided-field` имеет inset100px; вручную обращать формулу только по hostHeight недостаточно. Разность поз учитывает и этот контейнер, и положение самой плитки. Новый ограничитель или физический solver не создаётся.
2. Вид LiDAR и карта переиспользуют `bfmViewportPlacement`/`pixelMapMarkup` из работающей v4. Нативный CSS transform масштабирует всю координатную плоскость вместе с фоном; backend и схема игровых координат не меняются. [Исследование v4](max-bfm-pixel-map-guides-20261003.md). Переключение viewport не должно вызывать configure/focus/render сценария.
3. Градиент переиспользует **Web Animations API** контроллер v4, его стабильные semantic seeds и управление playbackRate/currentTime: [исследование и реальные ограничения BFM](max-bfm-gradient-motion-20261003.md). Для WebGL используется targetless [KeyframeEffect](https://developer.mozilla.org/en-US/docs/Web/API/KeyframeEffect/KeyframeEffect) и native Animation/document.timeline. Браузер считает время/темп/паузу; существующий render loop лишь читает угол. [updatePlaybackRate](https://developer.mozilla.org/en-US/docs/Web/API/Animation/updatePlaybackRate) применяется без переустановки текущей фазы при смене скорости. Web API — часть браузера, новой npm-зависимости/лицензии нет.
4. **Three.js0.185.1 MIT** реально исполняет вращение через [Texture.rotation/center/matrixAutoUpdate](https://threejs.org/docs/pages/Texture.html), а MeshBasicMaterial.alphaMap сохраняет неподвижную форму скругления. Поворот меняет UV-матрицу, не требует Canvas repaint или needsUpdate на каждом кадре. Texture.clone сохраняет общий Source; индивидуальная матрица нужна каждой semantic плитке. Все clones освобождаются при dispose. Основная карта цвета полностью непрозрачна, ClampToEdgeWrapping исключает пустые углы; round mask не вращается. Глиф и подпись имеют отдельные прежние материалы.

## Решение и ограничения

Панель отладки/переключатели находятся вне #circles, который перестраивается при смене стадии. Диагностический SVG находится в arena, следует масштабу и не перехватывает контакт. Элементы панели остаются DOM; игровые иконки остаются WebGL. Градиентный контроллер имеет скорость, разброс скорости, разброс фаз и паузу. Hidden/reduced-motion останавливают native clock. Настройки локальны текущей странице.

Профиль темы, шрифт Max Sans и текущие градиентные краски сохраняются; используется max.naming.service. Цвета SVG измерительной сетки являются диагностикой, а не статусами игрового бренда. Физическая зона LiDAR берётся из ранее заданной пользователем границы, это не измерение датчика.

CPU проверяет API-адаптер и матрицы настоящего Three; Animation в Node заменена тестовым объектом, нативный браузерный clock и GPU там не исполняются. Художественное ощущение, работа конкретного сенсора и кадр остаются на пользовательской приёмке. [Технический отчёт](../../artifacts/reports/max-v5-drag-tools-20261003.md).
