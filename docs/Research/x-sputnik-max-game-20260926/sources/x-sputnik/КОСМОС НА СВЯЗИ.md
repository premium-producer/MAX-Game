# КОСМОС НА СВЯЗИ

Полный текст интерактива.

## Сценарный принцип

1. Задача.
2. Конфигурация.
3. Проверка.
4. Результат.

## 1. Начальный экран

- **Заголовок:** КОСМОС НА СВЯЗИ
- **Описание:** Построй спутниковую сеть для передачи данных в любую точку планеты.
- **Кнопка:** НАЧАТЬ МИССИЮ

## 2. Онбординг

### УПРАВЛЯЙ СПУТНИКОВОЙ СВЯЗЬЮ

1. **ВЫБЕРИ МИССИЮ.** Раскрывай разные масштабы спутниковой связи.
2. **НАСТРОЙ СЕТЬ.** Объединяй наземные и орбитальные элементы в единую сеть.
3. **ЗАПУСТИ СИГНАЛ.** Передавай данные в нужную точку планеты.

**Кнопка:** ВЫБРАТЬ МИССИЮ

## 3. Выбор миссии

### 3.1. Проведи сигнал

- **Уровень:** базовый.
- **Задача:** построй маршрут через спутниковую сеть, чтобы подключить абонентский терминал к интернету.
- **Шаги:**
  1. Соедини наземную и орбитальную части сети.
  2. Запусти сигнал.

### 3.2. Настрой покрытие

- **Уровень:** средний.
- **Задача:** расширь спутниковое покрытие до удалённой точки Арктики.
- **Шаги:**
  1. Сбалансируй высоту орбиты и число спутников.
  2. Учти доступность наземной инфраструктуры.
  3. Проверь зону покрытия.

### 3.3. Проложи дальний маршрут

- **Уровень:** продвинутый.
- **Задача:** передай корпоративные данные из Калининграда во Владивосток через всю страну.
- **Шаги:**
  1. Выстрой две части сети с разных концов страны.
  2. Распредели спутники с учётом расстояния.
  3. Свяжи точки через ядро сети.

## 4. Миссия 1. Проведи сигнал

- **Уровень:** базовый.
- **Исходная ситуация:** земля и орбита ещё не связаны единым маршрутом передачи данных.
- **Задача:** определи верную последовательность элементов сети и запусти сигнал.
- **Доступные элементы:**
  - ядро сети;
  - абонентский терминал;
  - интернет;
  - наземная станция;
  - спутник.
- **Кнопка:** ЗАПУСТИТЬ СИГНАЛ

### Сообщения об ошибках

**Заголовок:** СВЯЗЬ НЕ УСТАНОВЛЕНА

- Маршрут собран не полностью.
- Нарушена последовательность элементов.
- В маршруте остался разрыв.

### Успешное завершение

- **Заголовок:** МИССИЯ ВЫПОЛНЕНА
- **Результат:** абонентский терминал подключён к интернету.
- **Кнопка:** К МИССИЯМ

## 5. Миссия 2. Настрой покрытие

- **Уровень:** средний.
- **Исходная ситуация:** удалённая точка находится вне зоны покрытия, а возможности для размещения наземной станции ограничены доступной инфраструктурой.
- **Задача:** подбери высоту орбиты и число спутников, найди подходящее место для наземной станции.
- **Доступные элементы:**
  - абонентский терминал;
  - спутники;
  - наземная станция.
- **Кнопка:** ПРОВЕРИТЬ ПОКРЫТИЕ

### Сообщения об ошибках

**Заголовок:** СВЯЗЬ НЕ УСТАНОВЛЕНА

- Удалённая точка находится вне зоны покрытия.
- В выбранной точке нет необходимой инфраструктуры.

### Успешное завершение

- **Заголовок:** МИССИЯ ВЫПОЛНЕНА
- **Результат:** связь с удалённой точкой в Арктике установлена.
- **Кнопка:** К МИССИЯМ

## 6. Миссия 3. Проложи дальний маршрут

- **Уровень:** продвинутый.
- **Исходная ситуация:** терминалы в Калининграде и на судне, прибывающем во Владивосток, разделяет вся страна, поэтому одного спутника для такого маршрута недостаточно.
- **Задача:** распредели элементы сети между городами, чтобы создать надёжный маршрут для передачи важных корпоративных данных на большие расстояния.
- **Доступные элементы:**
  - 2 абонентских терминала;
  - 6 спутников;
  - 2 шлюзовые станции;
  - ядро сети.
- **Кнопка:** ПЕРЕДАТЬ ДАННЫЕ

### Сообщения об ошибках

**Заголовок:** ДАННЫЕ НЕ ПЕРЕДАНЫ

- Маршрут собран не полностью.
- Ядро сети не включено в маршрут.
- Спутники распределены между частями маршрута неверно.
- Терминал на судне не подключён к сети.

### Успешное завершение

- **Заголовок:** МИССИЯ ВЫПОЛНЕНА
- **Результат:** корпоративные данные переданы на судно, прибывающее во Владивосток.
- **Кнопка:** К МИССИЯМ
