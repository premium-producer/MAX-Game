## Привязка к текущей игре

- Документ содержит старые укрупнённые чек-листы. Действующие objective IDs/условия и их количество сохранены; EN-подписи остаются точным описанием текущей проверки с терминологией источника. Отдельная новая проверка инфраструктуры/стабильности не добавлялась.
- В документе названы INITIATE THE SIGNAL / CHECK THE COVERAGE / TRANSMIT THE DATA. Текущая игра проверяет сеть автоматически и не имеет этих кнопок; их UI не возвращался.
- Дополнительные старые ошибки вне действующих feedbackEvents не включены как новые механики. NO CONNECTION и формулировка ошибки последовательности применены к существующим событиям.
- Общий gateway в каталоге называется gateway station (миссии 1/3); в тексте миссии 2 сохранено авторское ground station. Оборудование не раздваивалось.
- Текст документа, служебные заголовки «Mission», «Checklist», «Time» и редакторские заметки различаются: заметки не выводятся игроку как инструкции.
- RU-словарь, gameplay-конфиги, таймеры и условия победы сохраняются. Начальная загрузка остаётся RU до чтения словаря; EN выбирается кнопкой или ?lang=en.
- Для onboarding.title установлен отдельный текстовый бюджет 110 символов: заголовок занимает ширину сцены при 24 px, в отличие от компактных карточных heading (82). Полная авторская строка измерена шрифтом Bureau: 1241 px при сцене 1920 px. Lint продолжает проверять остальные heading по 82 и onboarding свыше 110; формулировка не сокращалась. Это метрическая проверка, а не browser QA. Интерактивная визуальная приёмка пользователем ожидается.
