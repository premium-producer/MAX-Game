### REF-044 — Ожидаемый линк в гибридном режиме отсутствует

Уточнение: на снимке терминал и спутник, не наземная пара. Прежнее объяснение через классическую дальность этой пары неприменимо; продолжение диагностики — REF-045

- 2026-09-09, MISSION_PLAY, гибридный режим со слов пользователя; номер миссии и полная расстановка неизвестны. Связь NEW-028
- [Скриншот](screenshots/REF-044__2026-09-09__mission-play__current.png), оригинал codex-clipboard-c9ad560d-00d6-4da5-ac84-73e73b5b6090.png. Оригинал и копия просмотрены, SHA-256 совпадают

> я в гибридной механике - и почему-то тут нет линка, хотя должен вроде быть

Наблюдение: видимые круги двух объектов пересекаются, линии между ними нет. По коду наземные пары в hybrid проверяются по 3D-расстоянию, а не по пересечению экранных кругов; также требуется непосредственное соседство в маршруте. Это возможное объяснение, точная причина для снимка без координат и полной цепочки не подтверждена. Следующий REF-ID — REF-045
