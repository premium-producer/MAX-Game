# Варианты декоративного контура России

Реализовано 2026-09-08, `contour-variants-153`, NEW-012.

На странице `earth.html` в разделе «02 · Россия и контекст» поле **«Вариант контура»** переключает линию, её свечение и парную заливку. Сейчас доступны «Исходный» (`classic`) и «Декоративный · 2026» (`decorative-2026`). Новый вариант выбран в текущем сохранённом профиле; исходный сохранён отдельным вариантом. После изменения нажать «Сохранить»; возврат к сохранённому/заводскому профилю и черновики учитывают выбор. Заводской профиль использует classic для совместимости со старыми конфигами.

Каталог — `public/config/earth-contours.json`. Выбор — `rendering.earth.russiaContour` в `public/config/ui-shell.json`. Игра, редактор миссий и редактор Земли используют один каталог и один renderer. Декоративная заливка управляет тональным выделением России, а не географией суши: `Earth_Surface_4K.bin`, запрет воды и фиксированные точки не изменяются.

## Как добавить следующий вариант

1. Подготовить два SVG в развёртке **6000×3000**, `viewBox="0 0 6000 3000"`: белая линия на прозрачном фоне и белая замкнутая заливка на прозрачном фоне. Геометрия должна быть уже привязана к развёртке. Использовать абсолютные M/L/Z, кривые предварительно разбить на короткие отрезки, clipPath вычислить в геометрии. Технические замыкания заливки на шве не должны попадать в светящуюся линию. Растр, scripts, ссылки на другие файлы, transforms и CSS не допускаются. Генератор текущего декоративного варианта: `workspace/other/contour-game-ready/prepare.py` в основном проекте.
2. Положить пару в `app/public/earth/contours/<id>/` и добавить запись в массив `variants` каталога, например:

   ```json
   {
     "id": "decorative-next",
     "label": "Декоративный · следующий",
     "border": "./earth/contours/decorative-next/border.svg",
     "fill": "./earth/contours/decorative-next/fill.svg"
   }
   ```

   ID уникален: латинские строчные буквы, цифры и дефисы; первый символ — буква. Запись classic сохраняется. Линия и заливка указываются отдельно; нельзя заменять один файл другим. Runtime-файлы должны оставаться внутри `app/public`, переносимая игра не обращается к workspace или TD.
3. Из `app/` выполнить `npm run contours:check`, `npm run build`, `npm run portable:check`, затем обновить редактор Земли. Вариант появится автоматически; код JavaScript менять и сервер перезапускать для каждой новой пары не нужно. Выбрать его и сохранить профиль.

`sync-assets` продолжает обновлять только исходную пару из прежнего TD-каталога. Новые варианты и реестр не перезаписываются; после синхронизации проверяется полнота всего каталога. Сборка проверяет все пары до очистки dist; portable-check повторяет проверку готового комплекта. Подготовительный пакет пользователя сохранён отдельно, runtime SVG нового варианта побайтово совпадают с ним.

## Загрузка и сохранение

Игра готовит только выбранную пару до открытия интерфейса: border читается как SVG-геометрия, fill как текстура. Другие 6K-маски не растеризуются при старте. При выборе другого варианта редактор сохраняет старый на экране до загрузки полной пары; затем одним действием меняет uniform заливки и обе геометрии линии/источника свечения. Новая сцена, камера и canvas не создаются. Старые GPU-ресурсы освобождаются. Опоздавшие ответы при быстром выборе или закрытии страницы освобождаются без применения.

Пока вариант загружается, сохранение временно недоступно. При ошибке сохраняется прежний вариант и выводится понятное уведомление. Сервер проверяет наличие ID в каталоге, сохраняет только профиль Земли с backup/revision и защищает от устаревшего сохранения. Отсутствующий ID не подменяется молча.
