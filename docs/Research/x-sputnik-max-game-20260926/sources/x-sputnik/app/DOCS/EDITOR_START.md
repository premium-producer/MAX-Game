# Работа с редакторами

Контрольная точка 2026-09-08: editor-persistence-148.

Все редакторы используют общий локальный сервер записи. На macOS/Linux запустите `npm run dev` из папки `app`, на Windows — `START-EDITOR-WINDOWS.bat`. Сервер должен оставаться запущенным во время работы.

- [Миссии и ракурсы](http://127.0.0.1:4174/editor.html): миссии, точки, маршруты, условия, тексты RU, описание в игре, сложность, ракурсы пяти экранов.
- [Банк объектов](http://127.0.0.1:4174/object.html): оборудование, SVG, настройки, наборы.
- [Земля](http://127.0.0.1:4174/earth.html): визуальный профиль. Камера на этой странице служит предпросмотру; сохраняемые ракурсы настраиваются в редакторе миссий.
- [Тексты RU/EN](http://127.0.0.1:4174/wording.html): словарь всех экранов и миссий, поиск и проверка переводов.
- [Игра](http://127.0.0.1:4174/).

## Сохранение

Кнопка «Сохранить» или Ctrl/Cmd+S записывает изменения в `app/public/config` и `app/dist/config`. Повторная сборка берёт сохранённые значения из public. Прежняя версия сохраняется в `app/backups/editor`, `app/backups/earth-style` или `app/backups/wording`.

Черновики записываются автоматически в браузере. Это восстановление незавершённой работы, а не применение изменений в игре. После восстановления черновика нажмите «Сохранить». Экспорт JSON позволяет отдельно сохранить правки, в том числе при конфликте версий. Автоматический импорт экспортированных файлов пока не реализован; перенос значений выполняется через поля редакторов.

Миссии и банк загружают русские фразы из актуального словаря. Изменение русского текста синхронизируется с wording.json. Существующий английский перевод сохраняется и помечается для проверки. Новая фраза временно использует русский текст и в EN; отредактируйте английский вариант на странице текстов и отметьте перевод проверенным.

Если другая вкладка сохранила те же данные, запись устаревшей версии блокируется. Экспортируйте нужные изменения и перечитайте проект. Черновик от прежней версии не накладывается поверх актуального проекта автоматически. Банк не меняет ракурсы; редактор миссий сохраняет актуальный профиль Земли с диска.

Сохранение рассчитано на локальный сервер. Оно не выполняет публикацию на VPS или GitHub. Изменение открытой игры после сохранения работает через уведомление между вкладками одного origin; используйте для всех страниц один адрес `127.0.0.1:4174`.

Проверено: 214 тестов, включая HTTP-запись во временную копию и чтение после перезапуска, syntax/copy/audio, build, portable-check. Интерактивная проверка полей и визуальная приёмка остаются за пользователем.

## Ограничение поверхности

В банке оборудования → карточка типа → «Допустимая поверхность»: только суша, только вода или суша и вода. По умолчанию наземное оборудование устанавливается на сушу, спутники — над любой поверхностью. После изменения сохраните банк. Фиксированные точки миссий остаются свободно редактируемыми. В тестовом режиме отклонённый перенос восстанавливает позицию, затем показывает ошибку; в игре после возврата карточки/объекта выезжает popup. Детали: [NEW-013](LAND_PLACEMENT_RESEARCH.md).

## Варианты контура · 2026-09-08

`rendering.earth.russiaContour` выбирает пару из `config/earth-contours.json`; старые профили используют classic. В редакторе Земли поле «Вариант контура» находится в разделе «Россия и контекст». Доступны исходный и декоративный вариант 2026; выбран декоративный. Линия, заливка и источник bloom меняются вместе; startup готовит только выбранную пару. Сохранение через Earth API сохраняет остальной профиль и камеры. Добавление новых вариантов, загрузка и проверки описаны в [EARTH_CONTOURS.md](EARTH_CONTOURS.md). Игровая маска суши/воды не зависит от этого выбора.
