## 3. Цель проекта

Создать интерактивную игру о построении маршрута спутниковой связи. Пользователь собирает последовательность элементов сети, учитывает инженерные ограничения и на продвинутом уровне строит дальний маршрут через несколько спутников, шлюзовые станции и ядро сети.

Рабочая концепция предусматривает синхронизацию игровых событий со световым оформлением. Для этого запрошены 4 световые головы, Art-Net-управление от игрового сервера и полная силовая, DMX- и сетевая коммутация.
