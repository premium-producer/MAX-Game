# MAX BFM: вращение градиента кнопок

03.10.2026. Короткая итерация поверх [выбранного BFM native stack](max-bfm-presentation-20261003.md).

Выбрано: отдельный слой с существующей заливкой плитки, обрезанный её скруглением. Браузерный Web Animations API вращает только этот слой через transform; глиф, текст и hit-target остаются на месте. Фаза выбирается один раз для semantic ID кнопки; постоянный множитель скорости случайный в пределах ±15%. Настройки: общая скорость, разброс, пауза. Покадровой случайности нет.

Опора: [web.dev — high-performance CSS animations](https://web.dev/articles/animations-guide) содержит вращение через transform и измеренные примеры отличий layout/paint от compositing. Из опыта BFM Mirror (07-motion…, раздел Firefox) избегаем анимации blur больших поверхностей и конкурирующих владельцев transform. Web API реализует интерполяцию, цикл и паузу; приложение только задаёт параметры.

[Animation.currentTime](https://developer.mozilla.org/en-US/docs/Web/API/Animation/currentTime) задаёт независимую фазу; [updatePlaybackRate](https://developer.mozilla.org/en-US/docs/Web/API/Animation/updatePlaybackRate) позволяет менять темп с сохранением текущего положения. Эти методы доступны в современных браузерах; используются без CDN/npm. Это browser runtime, отдельной версии/лицензии пакета нет; BFM provenance остаётся прежним. Документация не копируется в runtime.

Рассмотрено [@property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@property): умеет интерполировать угол градиента, но не гарантирует отсутствие paint. Поэтому здесь вращается готовая заливка, без собственной математической анимации. Слой 170% от стороны квадратной плитки закрывает углы при любом повороте. Применение к прямоугольным карточкам потребует отдельной геометрии; сейчас только цветные квадратные плитки ладони и возможностей.

Ограничения: фактический GPU compositing зависит от браузера и не доказан статической проверкой; визуальную оценку выполняет пользователь. При hidden/reduced motion анимация приостановлена с сохранением фазы. Настройки действуют в текущем preview и не затрагивают backend/мастер. [Отчёт](../../artifacts/reports/max-bfm-gradient-motion-20261003.md).

Дополнение 03.10.2026: ползунок «Сдвиг фазы» 0–360° использует тот же Animation.currentTime: MDN явно подтверждает seek при running и paused, с примером Drink Me/Eat Me. Добавляется общий угловой сдвиг к текущим индивидуальным фазам; random seed и разница скоростей сохраняются. Новые плитки получают выбранный сдвиг. Отдельной библиотеки/версии/лицензии не требуется. Смена скорости не повторяет сдвиг. Настройка действует до перезагрузки.

Уточнение пользователя: нужен разброс фаз, не глобальный угол. Общий сдвиг заменён диапазоном0–360°. Штатный WAAPI currentTime распределяет стабильные random seeds внутри диапазона относительно общей фазы; на0° кнопки синхронизируются. При ненулевом разбросе скорости затем естественно расходятся во времени; для сохранения синхронности нужны оба разброса0. Смена скорости/паузы не переустанавливает фазы. Это настройка готового native механизма, нового clock/интерполятора нет.

## Кратковременная потеря скругления, 03.10.2026

В текущем DOM radius32px присутствует, но вращающийся gradient-child обрезался только inherited radius+overflow:hidden. Пользовательский кадр показывает прямые углы во время перехода. Исторический реальный опыт: [WebKit67950](https://bugs.webkit.org/show_bug.cgi?id=67950), комментарий5 описывает похожий compositing-дефект и успешное clip-path:border-box; комментарии6–7 — связь со stacking context. Этот WebKit-дефект исправлен в2022: это подтверждение класса проблемы/применённого обхода, не доказательство той же причины в текущем Chromium.

[MDN clip-path](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path) документирует geometry-box clipping, включая угловую форму, и создание stacking context при значении не none. Выбрана одна native CSS-правка на gradient-clip: border-box использует уже заданный radius, без дублирования пиксельной геометрии и без изменения тени/глифа. Browser API не npm-пакет, новых библиотек/лицензий нет; build-only esbuild0.28.2 MIT прежний. Сохранён overflow fallback. Точное кратковременное поведение требует повторной проверки пользователя; [интеграция](../../artifacts/reports/max-bfm-rounded-gradient-20261003.md) подтверждает применение в runtime/браузере, не полный transition capture.
