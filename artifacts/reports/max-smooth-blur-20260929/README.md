# MAX: мягкий blur вместо разнесённых Frost-выборок

29.09.2026. По жалобе пользователя на пятнистый Frost заменён фильтр матовых поверхностей. Старый код брал9разнесённых выборок; фон дополнительно преломлялся в каждой. На контрастных источниках это создаёт риск видимых копий/ореолов вместо непрерывного размытия. Широкие градиенты сами по себе этот дефект плохо показывают.

Новый общий фильтр:4перекрывающиеся bilinear-выборки mip-текстуры, уровень зависит от native-разрешения, capped LOD5. Преломление под матовыми контролами удалено, прозрачная внешняя панель сохранена. Kernel применяется к фону, premultiplied fibers+bloom и UI за попапом. Смещение+.mip support≤56native px, внутри halo64. Мипы/targets/проходы/RAF прежние; вместо9texture instructions4, на фоне также исключены повторные вычисления преломления. Это оценка кода, не GPU benchmark и не обещание роста общего FPS.
