# MAX: свободная сборка пути — 29.09.2026

В клиентской редакции выбор больше не ограничен ожидаемой иконкой. Слоты сохраняют неверный порядок. Красный статус относится к связи ошибочных ролей, а не к порядку независимых возможностей ID/общения. Исправление: замена свободной иконкой, обмен с установленной через меню, drag на другой объект. Единственный вариант появляется непосредственно из плюса «Финальный шаг»; при единственной возможности исправления нет однопунктового селектора.

[Контракт](../../../apps/max-game/docs/SCENARIO_LAYOUT.md).

Проверено:
- 237 CPU-тестов: полный artifacts/max-game/test; syntax пяти изменённых runtime-модулей. Новые проверки: неверный порядок, красные связи, restore, замена, swap, ID, бизнес, равноправное общение, прямой REVEAL и запрет перехода к заданиям из открытого меню.
- Штатный build: 206 файлов / 76 модулей. check-local pass; HTTP app.js совпадает с runtime.
- Одна вкладка localhost: блогер — статистика первой, затем общение, финальный канал из плюса без меню; все три ошибочных ребра красные. Drag статистики на канал исправляет путь, связи голубые, появляется «Путь намечен». Повторный выбор установленной иконки меняет объекты местами. Ошибочный порядок переживает перезагрузку. На финальной сборке при повторном выборе скрыто окно готовности, Escape возвращает его. Console error/warn пустая.
- Локальный мастер: перезапущен только max-wall-right, другие поколения сохранены; Check.bat pass, Spout sending, поток presentation визуально отображается. Нагрузка и приём TD не проверялись; полного прохода всех миссий в браузере не выполнялось.
