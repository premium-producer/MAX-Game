# MAX — непрерывный контекстный попап, 28.09.2026

Замечание: при появлении задания исходная иконка исчезала с рывком, поле выглядело нестабильно.

В коде обнаружены разные lifecycle исходного объекта и копии: objectFocus скрывал первый за200мс, popupPresence проявлял второй за280мс; OPEN/ANSWER/CLOSE заменяли весь host.innerHTML и пересоздавали GPU-группы поля. Первый попап также выделял RGBA8 mipmapped target и впервые компилировал его материал.

Теперь выбранная плитка — единственный экземпляр: hold сохраняет её реальную текущую позу, карточка и телефон раскрываются вокруг неё. Task-icon — пустой скрытый layout-якорь, без оптической маски. Caption скрывается, соседние объекты приглушаются до45%; фон и волокна сохраняются. Три слоя UI: поле под Frost, резкий попап, исходная выбранная плитка поверх него. При ANSWER приглушение соседей сохраняется. После закрытия release продолжает движение с сохранённой позиции, без скачка к базовому layout.

renderTask обновляет только попап; refreshParts сохраняет GPU-группы, материалы и motion-state поля. Завершение заменяет только группу выбранного объекта для обновления badge. Неиспользуемые материалы/текстуры освобождаются, общие SVG-геометрии сохраняются. При закрытии клавиатурный фокус возвращается к выбранной иконке. Контекстный target и shader подготовлены при загрузке, переиспользуются; без попапа нет его фильтрующего прохода. Во время попапа добавлена отрисовка слоя выбранной плитки, без дополнительного target/renderer/RAF.
