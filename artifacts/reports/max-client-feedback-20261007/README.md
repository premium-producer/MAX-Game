# MAX — правки клиента, 07.10.2026

Статус: собраны локально, технически проверены; визуальная приёмка пользователя открыта. Стенд, MASTER, серверы и опубликованные страницы не изменялись.

## Девять пунктов

1. **Ожидание:** отдельная графика MAX × Госуслуги заменена на MAX. Существующий ID элемента сохранён для настроек оператора. Ролик продолжает воспроизводиться; контрольные кадры 0/5/15/29 с содержат MAX. Новый логотип точно повторяет исходную область MAX: ноль отличающихся RGBA-байтов.
2. **Следующее задание:** будущие иконки исключены из DOM/WebGL до своей очереди во всех четырёх миссиях. Выполненные иконки сохраняются.
3. **Пустой бабл:** при пустом сопровождении скрывается вся карточка, включая сохранённую графику и стекло. Непустое сопровождение затем восстанавливается; сообщение о выполнении задания остаётся.
4. **Картинки постов:** два серых блока бизнес-канала заполнены настоящими фотографиями кофе из исходного макета. За пределами этих областей непрозрачные пиксели принятого PNG не изменились. Новые экраны комментариев также содержат исходную фотографию.
5. **Чат-бот:** на активном экране заполнения восстановлено «Заполним данные о чат-боте – логотип, название и выберем задачи, которые он будет решать».
6. **Голосовое / видеосообщение:** убран дефис, разрешены переносы длинного заголовка, исправлены границы текстовых текстур. Явные склонения «Цифровым ID», «Цифрового ID» сохраняются.
7. **Завершение Цифрового ID:** «Цифровой ID создан – с помощью сервиса вы заселились в отель, подтвердили льготу и возраст. Поздравляем с прохождением миссии!»; подпись QR «Узнать больше о возможностях MAX». Используется предоставленный SVG; оба предоставленных QR декодированы как `https://max.ru/`.
8. **Отель:** «Заселиться с Цифровым ID», в том числе в отрисованном HTML.
9. **Новые SVG:** сопоставление — `Комментарии.svg` → пост; `Комментарии-3.svg` → пустое поле; `Комментарии-4.svg` → введённый ответ; `Комментарии-2.svg` → отправленный ответ (исходный этап остаётся отключённым); `Комментарии-1.svg` → финальный пост. Зоны нажатий соответствуют новым экранам.

## Пакет и границы установки

`MAX-client-feedback-20261007.zip` содержит отдельные client, MAX_RIGHT и MASTER delta; точные пути и SHA — в `delivery-manifest.json`. Это изменения для штатного stand base. Перед установкой интегратор должен сверить базовую сборку, сохранить БД/разметку/настройки и объединить `accepted-source.patch.json` с существующим `app/max-adapter/accepted-source.json`: файл patch не заменяет полную allowlist. MANAGED_ONLY и внешний audio bridge сохранены. Никаких установочных команд пакет сам не запускает.

Исходный комплект содержал устаревшие хеши для runtime annotation-source.json, v5.css и third-party-notices.html. Их байты сверены с тем же GitHub-снимком, исходные копии и manifest сохранены здесь; после сверки manifest принят сборщиком. Необходимые LFS payload восстановлены с проверкой размера/SHA; оставшиеся исторические LFS-файлы не затрагивались.
