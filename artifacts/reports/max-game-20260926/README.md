# Проверка MVP MAX — 26.09.2026

Проверены новая игра MAX и её подключение к Stand Service. Исходный X-Спутник использовался для чтения и копирования; его приложение не запускалось и не изменялось.

- 78/78 игровых CPU-тестов: исходные переходы/инвентарь/размещения/маршрут плюс проверки трёх фактических миссий, неправильной последовательности и разрыва связи, устаревшего/скрытого/перетаскиваемого снимка, локальных ассетов, HTTP/path guards и runtime SHA. [Лог](game-tests.txt).
- 21/21 сервисный тест: 18 существующих и 3 новых. Проверены `/max-game/` в dev/run, redirect, bundle, миссии, SVG, шрифт, бинарная маска Земли, недопустимый путь, неизменность назначений и наличие игры в сборщике полного комплекта. [Лог](service-tests.txt).
- Штатно собраны `apps/max-game` и Stand Service с сохранением существующего native-бинарника. Полный переносимый ZIP заново не выпускался. Работающий мастер не перезапускался; проверка маршрута выполнена на изолированных экземплярах сервиса.
- В одной вкладке localhost кратко проверены старт, обучение, карта и первая миссия. Видны MAX, Земля, инвентарь и нижний маршрут; сохраняются пропорции 16:9 с полями. После финальной сборки новых warn/error нет. Обнаруженные при первом запуске предупреждения Clock/SVGLoader устранены; старые записи журнала браузера отделены по времени.
- Итоговые node --check, AST трёх Python-сборщиков, JSON, SHA runtime/исходного X-Спутника и ссылки новых документов — [verification.json](verification.json).

Команды тестов из корня:

```powershell
node --test --test-isolation=none artifacts/max-game/test/*.test.mjs
node --test --test-isolation=none artifacts/service/server.test.mjs artifacts/service/max-game.test.mjs
```

Проверка трёх миссий использует корректные синтетические размещения и снимки проекции: это проверка правил, а не заявление о ручном прохождении в браузере. Нагрузочные GPU-прогоны, видео и длительные UI-проверки не проводились. FPS, пригодность к сенсорному стенду, художественная приёмка и Spout-подключение не подтверждены.
