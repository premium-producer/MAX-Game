## Реализация

`journey-motion.mjs`: аналитическая критическая пружина с сохранением value/velocity, единый registry по зоне+step. Выбор ретаргетит цель, владелец поля принимает состояние после достижения малой ошибки и скорости. Caption плавно скрывается на перелёте для незаметной смены переносов, badge проявляется после посадки; size/radius/glow сохраняются. Уход остальных иконок также пружинный. Token защищает commit от отмены; Escape/pause/layout не оставляют отложенное размещение. MOVE патчит координаты, SVG-геометрия кэшируется. Новых GPU targets/проходов/ticker нет. Mesh/material при PLACE всё ещё перестраивается: непрерывным остаётся motion-state, а не физическая идентичность Mesh.

Центр плитки измеряется через фактический rect без transform; offsetLeft/Top округляли дробные координаты. Короткая DOM-трасса `dom-trace-prepared.json` различает новый неподготовленный hit-target и кадр после prepare. Последний menu→первый подготовленный field:410.838/410.822→410.767/410.742display px, около0.106px за40мс; size86.395→86.398px. Это движение между двумя моментами, не доказательство нулевого скачка каждого GPU-кадра. Промежуточный DOM без transform не является отрисованным WebGL-кадром; ранние dom-trace*.json сохраняют диагностику этого различия.
