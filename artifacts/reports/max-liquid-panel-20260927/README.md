Внутри действует слабая плавная деформация, по краям сильнее преломление, светлая кромка, тень и брендовый glow. Контур смещается только внутрь на0–4 logical px. Внутренних сфер в этой итерации нет. ## Бюджет и ограничения

Тот же один reusable HalfFloat RT и существующий renderer, без дополнительных контекстов/CPU readback. Прежнее отсечение пустых тайлов сохранено (четыре glass-прохода текущего профиля). Внутри маски теперь исходная выборка+9 blur taps вместо2 выборок сфер — стоимость выше по числу fetch, отдельный замер не выполнен. Blur мягкий (не более10 native px и18 logical px); на исходно плавных градиентах визуальная разница blur меньше, чем на детализированной текстуре.

Отражения аналитические, без dispersion, screen-space материал не официальный Apple SDK и не объёмный ray tracing. Цвета только MAX, белые glints защищены от области текста. Reduced motion и пауза следуют наследуемому времени. Самостоятельная страница игры вне Service сохраняет CSS fallback. Художественная/LED/LiDAR-приёмка открыта. Без тяжёлых GPU-прогонов, записи видео и проверки3D/TD. Git stage/commit/push не выполнялись.
