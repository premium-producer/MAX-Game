# MAX 0.5 — игровые зоны на прямой части стены

Реализованы два варианта в одном приложении: two — два независимых квадрата со скруглением [2264,272,864,864], [3160,272,864,864]; single — одна широкая зона [2264,192,1760,1024]. В двух зонах всего четыре декоративных стеклянных круга, в одной — три. Небольшой дрейф отключается при reduced motion и паузе. Это CSS-проектная адаптация слоистого стекла, не физическая рефракция и не оригинальный AE-эффект. Сохраняются WebGL-узлы, волокна, частицы и общий фон.

## Геометрия и ввод

Read-only измерение POSITION/TEXCOORD_0 SCREEN_RIGHT в artifacts/web/assets/stand.glb: длинная плоскость U=.5351623…1, X2192.025…4096 на4096×1280. World X=3.652495м, Z=-.620406…3.244156м; длина3.864562м. Исходная/runtime GLB имеют одинаковый SHA256 8c62d4e355f45b06178ca3ee7aa0e784a1eac3a7bbf3bfcde3eb0981184c637a. Модель не изменялась. Первые~2192px — загиб/короткая задняя плоскость; это только фон.

Контейнеры и WebGL clip находятся внутри прямого участка с запасом~72px по краям. Размещение/перемещение ограничено внутренней областью каждого прямоугольника; попадание в загиб и чужую зону отвергается. Масштаб signalRadius следует ширине зоны для сохранения проходимости широкого варианта. Viewer focus перенесён на U3144/4096, V.5. Это программная геометрия, физическая LiDAR-калибровка не выполнена.

## Управление и состояние

В toolbar фактического presentation MAX доступен выбор «2 зоны / 1 зона», отсутствующий на других сервисах. settings.layoutMode сохраняется через revision-checked /api/config; legacy spin-only нормализуется в two. Worker передаёт режим в max-service-state, не перезагружает iframe. Игра хранит отдельные сессии two/single в памяти; переключение отменяет жест/selection/hold, сохраняет размещённые узлы и завершение миссии. Перезапуск источника всё ещё очищает сессии.

## Проверка

- Сборки MAX (175 файлов/39 модулей), Stand Service (82) и Viewer (67), JS syntax прошли.
- 111 MAX/service тестов и119 Ribbon/Viewer тестов прошли. Добавлены границы обеих раскладок и запрет ввода вне плоской области; settings migration, revision409/invalid400, persist/SSE без respawn. check:local подтвердил560 неизменных upstream-файлов и отсутствие чужих зависимостей.
- Первый запуск обновлённого backend требовал штатного Stop/Start. Песочница блокировала Electron spawn EPERM; повтор штатного Start вне песочницы успешен. После применения все5 источников running/Spout sending (check.txt). Это первый полный перезапуск для нового validator; дальнейшие переключения режима не перезапускают источники.
- В одной вкладке действующего presentation просмотрены оба варианта. В two виден собранный маршрут первого квадрата и меню второго; в single видна отдельная игровая сессия с узлами. Возврат two сохранил готовый маршрут и меню второго. Generation до/после переключения одинакова, кадры продвигаются. Console warn/error пустая. Снимки two-zones.png и one-zone.png. По завершении выбран two.
- HTTP сравнения с runtime: http-checks.json. Общие документы, эксплуатационные контракты и skills обновлены.

Применены max.glass.limit, max.glass.dispersion, max.glass.highlights, max.overlay.layering/paint и шесть цветов project-palette. Присланные изображения ошибок трактуются как запреты, исторические исходники брендбука не менялись.

Открыты художественная оценка стекла, аппаратный LiDAR/touch и приём TD. Все миссии в обоих режимах полностью не проходились. 3D-ввод после переноса focus не проверялся живым прогоном; границы сверены с GLB и CPU-тестами. MAX около5.2FPS при общей нагрузке; целевые60FPS не достигнуты. Тяжёлых GPU-прогонов/видео нет. Полный master portable ZIP не обновлялся.
