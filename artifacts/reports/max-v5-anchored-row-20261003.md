# MAX v5 — ряд вокруг перенесённого телефона, 03.10.2026

Запрос: левые/правые иконки следуют за телефоном; после действия телефон остаётся на месте, иконки восстанавливают общий Y и равные промежутки около400px. Причины в коде: revealPhoneLayout сдвигал только правую affected сторону; focusCurrent перецентрировал камеру после snapshot; step reset удалял manualPhones. Попутно установлен mismatch descriptor360px и CSS demo-app392px.

В v5 добавлен presentation adapter V5RevealJourney. Native CSS Flexbox row/align-items:center/gap400px/flex:none рассчитывает позиции измерительного ряда, адаптер считывает offset centres. Кэш по составу/активному шагу/device/nodeWidth, измерения не повторяются каждый кадр. Невидимый aria-hidden/inert probe не рисуется WebGL и не получает ввода. Цели обеих сторон привязаны к временному phone anchor; существующие IconMotion/Three.Group/publishGlassFrame анимируют отображение и hit-target. Учитывается прежний -100px offset ряда иконок.

Принятый answer снимает временные drag иконок; повтор со старым token отклоняется. Anchor телефона переживает смену экрана/задания внутри текущего run, камера после ручного drag не центрируется заново. Menu/restart очищают anchor; backend/save format не меняются. Inverse drag теперь начинается от видимого положения v5. Корпус phone в v5 width100% соответствует метрикам устройства. Другие renderer и runtime не переключались.

PASS:20 CPU тестов (17 общих +3 v5): движение обеих сторон/Y/400px; ответ/повтор; смена задания/рестарт, все6 миссий в общей модели. Первый прогон v5 дал416 вместо400: fixture предполагал392px, descriptor был360px; fixture исправлен, CSS корпус приведён к фактическому размеру. PASS2 JS syntax, duplicate guard, scoped build/CSS (169 модулей,1449754 байт), HTTP/runtime SHA7/7. [Машинное подтверждение](max-v5-anchored-row-20261003.json), [обоснование](../../docs/Research/max-webgl-v5-bfm-theme-20261003.md).

CPU использует измерительные fixtures, не симуляцию Flexbox. Native CSS/GPU/hit-target после интеграции визуально не проверены; пользовательская приёмка открыта. Новый collision solver не вводился; отсутствие всех пересечений на промежуточном пути не подтверждено. Декоративное парение даёт небольшое отклонение от номинального зазора.

Проверить не более3 действий: открыть телефон; перетащить по X/Y и посмотреть движение обеих сторон; нажать действие на телефоне — его положение сохраняется, иконки приходят в ряд с равными промежутками.
