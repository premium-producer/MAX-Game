# MAX Guided Reveal — проверка 30.09.2026

Цель: ладонь в начале, раскрытие всех иконок, композиции по миссиям, временный телефон у активного задания, сохранение пройденных связей и автоматический переход.

## Критерии

| Критерий | Проверка |
| --- | --- |
| Начальный экран содержит ладонь, без отдельного старта MAX | Браузер, обычный URL |
| Иконки раскрываются без раннего зачёта | CPU, stagger/presence/phase |
| Все миссии и бизнес-ветки завершаются | CPU, все варианты ответов |
| Присутствуют все иконки, один телефон, 5 входов | Браузер |
| Порты телефона покрывают10…90% высоты | CPU и видимый кадр |
| Задание ждёт посадки; закрытие отменяет открытие | CPU и браузер |
| Ответы, ручные позиции, восстановление сохраняются | CPU |
| Физическая читаемость/Hokuyo/TD новой композиции | NOT RUN, эксперимент не назначен стенду |
| Художественное утверждение | Ожидается просмотр пользователем |

## Целостность исходников

В начале обнаружены расходящиеся numbered-копии.20пар MAX и затронутых общих документов сравнены, обе стороны сохранены в `artifacts/workspace/backups/max-guided-reveal-20260930/`, изменения реализации восстановлены, уникальные записи документации объединены. Runtime MAX восстановлен штатным сборщиком. Остальные приложения и настройки мастера в рамках этой задачи не исправлялись. Последний глобальный duplicate guard — PASS: внешние конфликты больше не обнаружены; их устранение не приписывается этой работе.

## Результаты

- CPU:104/104 PASS в восьми наборах Guided/Reveal/Line/Links/Motion/Popup/Transition/Topology. Четыре основные и две тестовые миссии, три бизнес-ветки, три варианта ответов; отмена контакта, единый владелец, скрытие страницы, stale/повторный ответ, восстановление без автооткрытия, база/временные сдвиги, перенос позиции общего бизнес-узла на выбранный инструмент. Фазы проверены при30/60/120Hz и reduced motion. Это проверка логики, не FPS рендера.
- Guard PASS; node --check изменённых JS/MJS PASS; штатная сборка и check-local PASS:214 runtime-файлов,89 исходных модулей. Все Guided-страницы включены. Runtime и HTTP SHA совпадают для новой страницы, guided-app.js и CSS, HTTP200.
- Одна IAB-вкладка: обычный старт показывает центральную ладонь без отдельного MAX-старта; короткий контакт отменяет заполнение. Полное раскрытие проверялось через явный ephemeral `?review=<mission>`: fixture вызывает реальные down/tick контроллера и не сохраняет прогресс. Само физическое удержание0,8s покрыто CPU, touch/Hokuyo отдельно.
- Блогер: канал пройден до автоматического открытия общения. Бизнес в `geometry=wall`: аккаунт → сфера «Магазин» → подключение → автоматический выбор инструмента → бот. Узел заменился, задание открылось без подтверждения. Закрытие пустым полем → paused, телефон исчез, появилась подпись продолжения; нажатие текущей иконки снова открыло тот же этап.
- ID: все пять узлов, один телефон,5 входящих/0 исходящих до результата; оригинальное изображение и hotspot «Создать QR» переводят на следующий клиентский экран. Guided Line: один телефон,5/5 пучков по полной грани. Прежний Guided: центральный телефон и отдельная инструкция сохранены.
- Просмотрены обычная геометрия и `geometry=wall`, viewport1280×720 и795×618; предупреждения/ошибки console отсутствуют. На малом viewport масштаб всей логической сцены уменьшается; физическая читаемость на стенде этим не доказана. Новая композиция не назначена мастеру.
