# MAX — понятные состояния редактора, 03.10.2026

Причина дефекта: щелчок по превью передавал point в openEditor, после decode безусловно вызывался setRect. Повторное открытие заменяло сохранённую рамку точкой открытия. Исходная область каталога также выглядела как уже выбранная.

Исправление: превью только открывает редактор. Для нового действия — «Действие не размечено»/«Разметить действие»; для отмеченного — «Действие размечено», «Показать действие», «Разметить заново». Показ выводит только выбранное действие; внешняя кнопка имеет отдельное представление под изображением. Повторная разметка имеет отмену и сохраняет прежние данные до явного нового щелчка. Статус серверного сохранения поднят рядом с основными кнопками. Готовый Annotorious сохранён; новый механизм геометрии не вводился.

Проверки: независимый субагент подтвердил причину; syntax/duplicate/build PASS, HTTP90/source52 SHA PASS. Внутренний браузер: существующая рамка572/127/226/99 сохранилась при показе, начале/отмене повторной разметки, закрытии и открытии через превью, затем reload. Неразмеченный экран2 показывает «Разметить действие». Console[]. API уже отвечает200 после перезапуска в другой задаче; в этой итерации мастер не перезапускался. Пользовательские отметки и2настройки экранов не менялись. Новые отметки не записывались ради проверки в процессе работы пользователя.

Техническая и визуальная самопроверка PASS; пользовательская оценка OPEN. Настройки активности/финала всё ещё не подключены к игровым маршрутам, как и в предыдущей итерации.
