# MAX v5 — первая локальная сборка

Адрес: http://localhost:8770/max-game/webgl-v5/?backend=local&layout=wall

Статус: **техническая сборка готова; визуальная приёмка открыта**.

## Сделано

- Исходный GuidedReveal WebGL entry, SharedRevealJourney и общий mission backend; отдельный visual flag не переключает reference motion.
- Существующий GPU материал градиентных плиток, фиолетовой справки и оболочки устройства; скруглённый стартовый знак, подписи под плиткой и официальный MAX логотип.
- Живой common-map фон с mask=stand. Фон не изменён в master/TD.
- Отдельный runtime apps/max-game/webgl-v5, собственные CSS и build.json; прежние bundles не перезаписываются этим сборщиком. Локальный профиль v5 отделён от предыдущих сохранений, автоматического импорта/сброса нет.

## Малые проверки

- PASS node --check: два изменённых source JS и scoped builder.
- PASS duplicate guard.
- PASS 30 существующих CPU проверок webgl-session, webgl-shared-reveal и journey-icon-scale: шесть миссий, неверное/повторное действие, удержание/отмена, рестарт, восстановление, временное перемещение. Это проверки общего адаптера, не фактического GPU кадра v5.
- PASS esbuild0.28.2 bundle: 166 modules, 7 files. Three.js0.185.1 реально включён; builder требует исходный renderer и общий session backend и отвергает bfm-main.mjs. CSS v5 проходит esbuild parse без warnings.
- PASS HTTP/runtime SHA всех7 файлов; JSON доказательства рядом.
- Первый build выявил отсутствие nodePaths для внешних service/ribbon модулей; применён путь к уже установленному max-game/node_modules, как в действующем WebGL builder. Зависимости не устанавливались.

## Непроверенное и оставшееся

Открытие новой вкладки отклонено автоматической проверкой: AGENTS запрещает самостоятельные вкладки. Запрошено явное разрешение; обхода не выполнялось. **GPU compile/console/кадр v5 не проверены**, screenshot отсутствует. Тяжёлые GPU тесты/запись видео не запускались.

Точная LiDAR раскладка и BFM панель фазы/скорости пока не перенесены. Исходные движение и layout намеренно сохранены в этом коротком шаге. Художественное совпадение и исправность всего прохождения v5 не объявлены.

Пользователю: открыть новый адрес → выбрать «Стать блогером» → удержать ладонь и оценить раскрытие/первый экран канала. Не требуется обнулять предыдущие версии.
