# Самодостаточный контекст разработки MAX

26.09.2026. По запросу пользователя перенесены оставшиеся материалы разработки X-Спутника. Действующий MAX и его игровое поведение не менялись.

## Состав и проверки

- 560 исходных файлов, 81 321 313 байт: полный исходный WEB src/scripts/test/public, HTML редакторов, server, package/lock, 13 web-skills со всеми ресурсами; GDD, инженерные документы, история, комментарии и референсы пользователя. SHA и исходные/локальные пути — `artifacts/max-game/upstream/manifest.json`.
- Все 560 SHA проверены локально. Чужой каталог при проверке не читается. `check:local` выполнен под Node permission model с разрешением чтения только VK_DigitalProducts; проверены 53 входа сборки и 168 runtime-файлов, включая realpath для защиты от внешних symlink.
- Сборка выполнена с чтением Node только внутри проекта и записью в apps/max-game. Для esbuild разрешён дочерний процесс; это не утверждение о полной OS-изоляции child process. Все фактические входы esbuild перечислены в source-manifest и проверены внутри проекта.
- Готовая игра: 168 файлов, 13 205 812 байт; исторические материалы и skills не добавлены в пользовательский runtime.
- 78/78 игровых тестов прошли. Проверки ассетов: 21 аудиофайл, 19 semantic events; 2 полные пары контурных SVG. JS новых/перенесённых активных scripts проходит node --check; prepare-surface-mask.py — AST. Генератор маски не запускался, игровые данные не менялись.
- Проверены локальные ссылки в восьми входных документах/skills. `quick_validate.py` не запустился из-за отсутствия PyYAML; использована локальная проверка frontmatter/name/description и ссылок. Дополнительные пакеты не устанавливались.
- Ни один из 560 snapshot-файлов не исключён Git ignore. Для источников MAX, его runtime и неизменённых исторических документов добавлены точные `-text`-правила: Git не меняет байты и SHA при checkout. Другие приложения не затронуты.

## Использование

Начальная точка — [DEVELOPMENT](../../../apps/max-game/docs/DEVELOPMENT.md) и [max-game-development](../../skills/max-game-development/SKILL.md). `npm run check:local` проверяет целостность, `npm run check:assets` — аудио/контуры. Исторические редакторы и их код доступны локально, но не объявлены подключёнными к MAX UI.

Полный snapshot хранится файлами, без нового ZIP. Чужие доступы/VPS/TD, node_modules, сборочные выходы и резервы не переносились. Исходная директория не изменялась. Commit/push, перезапуск серверов и повторная UI/GPU-проверка не выполнялись: изменены контекст, инструменты и README runtime, игровая реализация осталась прежней.
