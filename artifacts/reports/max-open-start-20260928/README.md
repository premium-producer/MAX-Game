# MAX: общий первый шаг «Открыть MAX»

28.09.2026. Локальная реализация уточнения пользователя: первый шаг во всех четырёх миссиях — отдельный старт с фирменным знаком, а не переименованное реальное задание.

## Реализация

- starts[mission] хранит open-max и координаты. BEGIN_ROUTE не добавляет channel/create-id/call/sector в runs; эти задачи доступны через второй плюс. Старт не входит в TASKS, не имеет badge и не завершает миссию.
- Подписи: «Твой первый шаг к блогу», «…к Цифровому ID», «…к общению», «…к развитию бизнеса». Заголовок всегда «Открыть MAX».
- Оригинальный brand/assets/logos/max-symbol-white.svg, WebGL Image texture без изменения пропорций. Decode до запуска сцены. Builder копирует канонический SVG из брендового пакета; check-local проверяет наличие и SHA. SHA256 2DFE98323A15E850F3903C53465380C471DBBE2D55CAC144CEB0F041F5CFB537 совпадает в брендовом пакете и runtime.
- Правила max.logo.symbol, max.logo.background, max.logo.no-recolor, max.logo.no-outline: отдельный монохромный знак для ограниченного места на градиенте; без перерисовки/обводки/перекраски. Согласование владельцем бренда не заявляется.
- Старт наследует pose круга и участвует в links под отдельным id, затем в свободном drag. Старые реальные задачи/ответы/координаты сохранены при миграции. Ряд до6 узлов и подписи адаптированы к узкому экрану.
