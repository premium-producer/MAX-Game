# MAX: WebGL Liquid Glass — 27.09.2026

В мастер-проект подключён собственный шейдер экранного преломления реального фона. Это screen-space refraction, не официальный компонент Apple и не объёмная трассировка лучей. Standalone-страница игры без Service сохраняет CSS fallback: у неё нет текстуры общего фона.

## Реализация

`max-shared-background.js` рендерит существующий фон в дополнительный HalfFloat target. `max-liquid-glass.js` считывает его и выводит результат в существующий GPUAtlas: закруглённая фаска панелей, круглые линзы, refract с IOR 1.46, Fresnel, лёгкое размытие, контактная тень и голубое/фиолетовое краевое свечение. Формула преломления соответствует [GLSL refract](https://docs.vulkan.org/glsl/latest/chapters/builtinfunctions.html). Дисперсии нет. Геометрия и предел смещения вынесены в `max-glass-model.js`.

Для двух зон используются четыре декоративные линзы, для одной — три, с небольшим дрейфом. Текст и игровые узлы рендерятся поверх стекла без искажения. Состояние меню берётся из DOM игры: центральная текстовая колонка маскирует яркие отражения. Reduced motion останавливает дрейф. Пикселизация не возвращалась.

Границы полностью совпадают с игровыми: two — [2264,272,864,864] и [3160,272,864,864]; single — [2264,192,1760,1024]. Все внутри прямого участка X2192.025…4096. Смещение текстуры ограничено запасом тайла, обратной связи чтение/запись одной текстуры нет; sRGB-преобразование выполняется существующим atlas один раз.

Дополнительный target текущего профиля 2176×1208 занимает около 20.05 MiB и переиспользуется для шести тайлов. Добавлено шесть quad-проходов за кадр; новый WebGL-контекст, RAF или CPU readback не создаются.

## Ограничения

Художественная и аппаратная приёмка остаются пользователю. Тяжёлый GPU-прогон, запись видео, повторная проверка TD/3D и всех миссий не проводились. Краткий статус показывает MAX порядка 19–24 FPS; это не A/B-замер стоимости стекла и не подтверждение 60 FPS. Отдельная [диагностика производительности](../max-fps-diagnostic-20260927/README.md) остаётся актуальной.

Последние три public-модуля доставлены выборочным builder с обновлением manifest; Service ZIP после этой финальной правки и полный master ZIP не обновлялись. Действующее локальное приложение обновлено. Git stage/commit/push не выполнялись.
