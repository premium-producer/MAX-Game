# MAX: отдельный материал кнопок

27.09.2026. Пользовательский референс сохранён в `artifacts/max-game/incoming/glass-buttons-settings.png` и `glass-buttons-reference.png`; [профили](../../DESIGN/BRANDS/MAX/glass-profiles.json). Light −45°/80%, Refraction 100, Depth 33.47, Dispersion 0, Frost 56.25, Splay 0. Параметры большой панели не изменены.

## Реализация

Shader рисует матовые фиолетовые контролы под DOM: отдельное краевое преломление, 5 bilinear taps фоновой текстуры с калиброванным радиусом 9 logical px, направленный блик. Выборки учитывают преломление панели; все суммарные offsets по каждой оси ограничены 56 native px. Передний план не размывается. Новых RT/контекстов/RAF нет, вычисления добавлены локально под кнопками; бесплатными они не объявляются.

Worker кэширует DOM bounds по revision, обновляет при renderZone/fit. CSS сохраняет формы, добавляет фиолетовые значки с белыми цифрами и отменяет сдвигающие форму hover/active transforms. Самостоятельная игра имеет декоративный CSS fallback, а не тот же shader.
