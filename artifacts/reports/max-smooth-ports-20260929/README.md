# MAX: плавная смена граней — 29.09.2026

Исправлена мгновенная замена портов: TileEdgeMotion хранит два угла со скоростями на стабильном ребре. Critical spring omega14 движет их по кратчайшей дуге; пересечение луча со скруглённым прямоугольником держит точки на реальном контуре. Нормали, управляющие точки и изгиб перестраиваются непрерывно. Трансляция/размер/радиус плитки применяются сразу; интерполируется только локальное положение порта. Сохранены прежний выбор грани, цвета и волокна. Обсуждавшийся новый приоритет граней не реализован по указанию пользователя.
