# MAX: ближайшие связи и волокна — 28.09.2026

Сверены локальные upstream/app/src/webgl-field.js, mission-game.mjs, screen-connectivity.mjs, mission-evaluation.mjs и public/config/ui-shell.json. Upstream содержит маршрутную/экранную политику, поэтому свободная сеть MAX не выдается за дословно перенесённый алгоритм X-Спутника. По уточнению пользователя новая сеть — кратчайшее связующее дерево между ближайшими деталями (Kruskal MST), без фиксированного hub по смысловой роли. Восстановлены исходные характер и формула независимого движения частиц.

Причины отклонения:
- journey-main строил звезду вокруг channel/create-id/group/account;
- Journey override lineWidth0.014/intensity1.65 и широкие пологие волокна с частотой1.4 давали сплошные яркие дуги;
- частицы были зафиксированы на тех же нитях, а не двигались с независимой волновой фазой, как upstream;
- phase offset существующей связи пересчитывался из индекса списка, что давало скачки при изменении состава.

Теперь nearestLinks вызывается отдельно для каждой зоны и учитывает актуальные --x/--y при drag. Декоративный bob исключён из выбора соседей; anchors продолжают следовать видимым иконкам. n≤5, до10 кандидатных рёбер, n−1 активных связей; равные расстояния стабилизированы ID. Завершение заданий/миссий не зависит от связей.
