## Исправление get_componentProperties

Пользователь прислал реальную ошибку `in get_componentProperties: Component set for node has existing errors`. Источник найден в fingerprint: прямое чтение getter при проверке изменений. Добавлен узкий fallback для componentProperties с диагностикой слоя, без изменения исходного компонента и требований к файлам.

Проверено 28 collector-тестов и 4 серверных теста. Два новых регрессионных сценария: вложенный INSTANCE с точно таким выбрасывающим getter проходит скан и последовательную передачу двух экранов с предупреждением; восстановившийся getter делает старый скан неактуальным. Здоровые экраны не получают новое поле readWarnings, ключ продолжения не меняется. node --check runtime/code/tests; code.js пересобран. UI и сервер не изменены, новая браузерная проверка не проводилась; воспроизведение в настоящей Figma остаётся на стороне пользовательского файла. Для применения закрыть и снова открыть плагин, повторить «Найти экраны».
