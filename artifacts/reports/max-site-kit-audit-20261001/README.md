# Аудит комплекта для новой игры MAX

01.10.2026. Сравнение [нового пакета официальных сайтов](../../DESIGN/BRANDS/MAX/site-kit-20261001/README.md) с исходниками текущей клиентской игры и Guided Reveal. Это аудит доступных материалов и реализованной логики, не визуальная приёмка работающего экрана. Машинный снимок — [baseline.json](baseline.json), проверка пакета — [checks.json](checks.json).

**Вывод:** пакет покрывает фирменный язык и значительную часть оформления. Он не содержит полного набора игровых экранов, пиктограмм и состояний. Полностью новая игра на его основе возможна; до переноса всех шести миссий требуется закрыть перечисленные пробелы. Семь исходных роликов не заменяют интерактивные задания.

## Что отсутствовало уже в предыдущей сборке

`missionCoverage` отмечает: **Общение** — создание/результат группы и стикеры/реакции; **Бизнес** — подготовка/отложенная публикация, новый заказ, каталог/карточка товара и клиентская витрина; **Бизнес · тест** — итоговые бизнес-сцены по выбранной ветке. Это старые пробелы, не результат новой упаковки. В остальных трёх миссиях этот механизм не отмечает заглушки.

## Следующий небольшой шаг

Собрать отдельный первый экран и одно задание блогера из выбранных компонентов пакета, с собственным runtime/сохранением и без импортов старого визуального стека. Проверить пользовательским скриншотом; только затем расширять на остальные состояния и миссии. Старую игру и мастер сохранить. Игровые требования остаются ориентиром поведения; данная упаковка не переписывает механики и не запускает новую сборку.
