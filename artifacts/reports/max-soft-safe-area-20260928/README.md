# MAX: отдельная область движения и мягкие границы — 28.09.2026

Запрос: UX остальных экранов1–1.8м, перемещаемые иконки0.8–2.2м с плавным замедлением. Только локальная версия.

## Реализация

- MOVEMENT_BAND413…1121 по текущим SCREEN_RIGHT/нулю пола GLB. INTERACTION_BAND615…1020 не изменён. Поле с18px запасом: Y431…1103, независимо от UX-host. Запас учитывает badge и парение; нормализованная позиция описывает весь объект с подписью.
- Движение: C1-квадратичное сопротивление в последних14% интервала каждой оси, скорость передачи ввода у крайней точки равна нулю. Обратное преобразование начальной позиции исключает скачок при новом захвате. За крайней точкой сохраняется защитное ограничение. Один существующий WebGL spring-clock, без дополнительных GPU-проходов.
- PLACE/MOVE/restore валидируют0…1; убраны прежние .08…92/.12…80. Старые сохранённые нормализованные координаты отображаются на расширенном поле, прогресс задач сохраняется.
- Если плитка вне UX-полосы, она остаётся единственным экземпляром на поле; инструкция без пустого места под копию и портретный телефон располагаются внутри UX. Меню и плавающий «Назад» также остаются там. Standalone занимает доступную область окна; физические метры применяются к стене.
