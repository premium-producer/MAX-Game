# MAX v5: инерция ряда, телефона и привязка справки

Рабочий адрес: http://localhost:8770/max-game/webgl-v5/?backend=local&layout=wall&v=inertia-1

Причина резкого phone drag подтверждена кодом: pointermove одновременно менял цель и непосредственно записывал phoneX/Y.value, сбрасывая velocity. Позиция справки по X выбиралась фиксированно по стороне поля; InstructionMotion после resize сохранял абсолютный top. Ряд на стадии task использовал omega20.

Только v5: реальное `maath@0.10.8 easing.damp` выполняет X/Y демпфирование через адаптер MotionValue (iconsOmega6.5, phoneOmega14). Регистр/Three.Group/clock сохраняются. Повторная подготовка не заменяет уже адаптированного владельца; position/velocity не сбрасываются при retarget. Phone pointermove задаёт только цель, повторный захват начинается с видимой позы. Справка по X/Y следует фильтрованному телефону, nominal gap64px; resize высоты сохраняет эту привязку. Убран входной scale родительского popup только v5, чтобы не сдвигать справку относительно телефона. Backend, тексты, фон, шаги, старые runtime не менялись. [Источники/ограничения](../../docs/Research/max-webgl-v5-bfm-theme-20261003.md).

Пользовательская проверка:1) потянуть телефон по X/Y, резко остановить/отпустить;2) повторно захватить до полной остановки — справка следует без отделения;3) переместить иконку и выполнить действие — ряд плавно восстановится, выбранное место телефона сохраняется.
