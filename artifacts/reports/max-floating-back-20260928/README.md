# MAX — плавающий возврат, 28.09.2026

Кнопка «Назад» появляется после первого объекта. Привязана к плитке с минимальным X (при равенстве — верхней), целевая позиция выше/левее с18px отступом. Весь hit-target ограничен интерактивной зоной; возле её края пространственное ограничение приоритетнее отступа. При смене крайнего объекта цель меняется без сброса позиции/скорости. Пружина omega10, покачивание2×3logical px на общем clock. Reduced motion отключает колебания. WebGL-текст/глиф/стекло и DOM hit-target используют один transform; новых RAF/RT нет. Пустое поле сохраняет центральный CTA. Возврат ведёт к миссиям.

Syntax/check-local(58 compiled inputs)/штатные сборки прошли; первый Ribbon-build: известный Errno22 при копировании шрифта, повтор успешен.
