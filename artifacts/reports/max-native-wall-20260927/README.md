# MAX: прогулка, общий фон, палитра — 27.09.2026

**Собрано, применено и проверено на работающем мастере после явного указания пользователя запустить проект.** Ниже сохранены результаты предыдущего этапа; итоговая проверка описана в конце.

- Viewer разрешает ввод по MAX только в прогулке с Pointer Lock. Начало по центру прицела, относительное движение перемещает контакт; взгляд/WASD на время контакта удерживаются. Потеря lock отменяет жест. Подход к MAX задаётся по UV реальной геометрии при высоте глаз 1,7 м.
- Worker соединяет прежний rear-wall renderer/SurfaceField с прозрачной DOM/WebGL-игрой в одной native-композиции. Общие координаты, crop/halo и транспортные часы восстановлены. Дополнительный renderer фона находится в том же worker; его фактическая нагрузка ещё не измерена.
- Поле 1351,111 × 760: x=2273,185, y=464, сдвиг вправо 900,741 px, ровно 2/3 ширины. Геометрия стенда не изменялась.
- Авторские HEX/RGB в source/config, GLSL-акценты, presets/defaults Земли и статусы приведены к шести цветам пользователя. Исходные SVG/фото и архив upstream сохранены; Земля использует яркость исходной карты с брендовым tint. Main в игре адаптирован через CSS override. Освещение/alpha/интерполяция дают промежуточные значения пикселей.
- Обновлены max-brand, max-game-development, vk-webgl-neon, brandbook-ingest и решение project-palette.json.

Проверено: 208/208 CPU-тестов (механика MAX, Ribbon, raycast/Pointer Lock, блокировка обзора, drag/cancel, физический layout, palette allowlist); синтаксис 45 JS/MJS; check:local — 560 upstream файлов, 13 исходных skills, 55 входов, 168 runtime файлов. ## Завершение живой проверки

27.09.2026, мастер run запущен штатным start.mjs --run --no-open на localhost:8770. Пять источников running, обе задние стены Spout sending. При исправлениях перезапускался только MAX; поколения четырёх прочих источников сохранены.

Устранены фактические дефекты: Chromium перекрывал фон непрозрачной подложкой iframe из-за несовпадения color-scheme; общий dark восстановил прозрачность. Красные частицы общего движка справа заменены на MAX purple/cyan. Дистанция подхода теперь выбирается по свободной линии взгляда с высоты глаз: первоначальная нормаль на уровне центра экрана не замечала наклонную арку. Для браузеров, отказавших в Pointer Lock, добавлена рабочая прогулка с обычным курсором, RMB-look и WASD. Старые сценарии отказа без opt-in сохраняются.

В одной вкладке последовательно проверены presentation и Viewer: фон виден под прозрачной игрой, сдвиг сохраняется, в прогулке реальный клик на CTA сменил стартовый экран на игровой. Фазы down/up дошли до SCREEN_RIGHT, generation=287ac836-66f8-49ed-9cb3-4dc098a93c11. Console warn/error: 0. [Снимок](walk-game.jpg), [DOM-диагностика](walk-browser.json). Pointer Lock встроенный браузер не разрешил; его ветка/drag/cancel проверены CPU, реальный аппаратный touch не проверялся.

Ограничения: около 6 FPS MAX (Spout) при пяти активных источниках, 60 FPS не достигнуты. Это короткое наблюдение текущего мастера, не нагрузочный benchmark. Viewer сообщал, что источник силуэта занят другой прогулкой; захват чужой сессии не выполнялся, ввод MAX от этого не зависит. Физическая LED-синхронизация шва и художественная приёмка остаются пользователю. Причина выключения ПК этой проверкой не установлена. Мастер оставлен работать, его страница открыта.
