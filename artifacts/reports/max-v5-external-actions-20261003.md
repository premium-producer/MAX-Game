# MAX v5 — внешние кнопки устройства, 03.10.2026

Статус: код и локальная сборка готовы; визуальная приёмка OPEN.

Изменены v5.css и journey-v5-device-morph.mjs. CSS выносит actions ниже силуэта и центрирует с cap392. Размер asset viewport больше не зависит от количества кнопок. Backend, сохранения, тексты, hotspots и фон не менялись.

Проверки:
- 14/14 Node: webgl-v5-device-morph.test.mjs + webgl-v5-startup-assets.test.mjs. Все84screens сохраняют aspect, controls не влияют на метрики; morph30/60/120Hz, content readiness, late decode/cancel и startup markup проходят.
- node --check модуля PASS; duplicate guard PASS.
- Scoped build:28файлов,200модулей. HTTP SHA всех28 runtime файлов и SHA200 source inputs PASS.
- Независимый device_actions_review без изменений файлов: selector specificity, transform ownership, ввод, fade/inert и prewarm — блокеров не найдено.
- Внутренний браузер: запуск обновлённой страницы PASS; существующая миссия восстановлена. Нажатие «Канал» вернуло меню вследствие истёкшего таймера. Экран с действиями не был достигнут: фактическая геометрия и click внешней кнопки НЕ подтверждены. Полный старт требует удержания0.8с; доступный инструмент не предоставляет длительность удержания. Прогресс не подменялся для обхода.
- Console: прежняя отдельная ошибка «MAX background: Ожидается живая маска стенда»; новых замеченных ошибок нет.

Оставшаяся приёмка: обычный портретный экран, широкий экран (cap392), Digital ID с двумя действиями; совпадение центра, зазор и нажатие после движения устройства. При сильном смещении устройства вниз внешние кнопки могут выйти за viewport: это не новый clamp.
