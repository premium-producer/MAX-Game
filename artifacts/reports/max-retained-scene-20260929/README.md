# MAX: аудит архитектуры и исправление передачи визуального состояния

29.09.2026. Только локально. Основание: [общий аудит](../max-motion-audit-20260929.md), [воспроизведение пустой подложки](../max-placement-state-audit-20260929/README.md).

## Диагноз

Стабильный MotionRegistry уже существовал, но render заменял DOM-владельцев, rebuild очищал сцену, а оптика читала новую разметку до применения анимационной позы. Отсутствующий uiFade означал видимую подложку. Каждый тик иконки также читал браузерную раскладку после записи transform.

## Реализовано

- `journey-retained-field.mjs` сохраняет смысловых владельцев поля и навигации. Выбранная летящая кнопка становится кнопкой поля; смена роли обновляет содержимое, сохраняя владельца. Остальные иконки переиспользуются.
- WebGL-сцена обновляется инкрементально: неизменившиеся группы, материалы и текстовые ресурсы остаются. При смене роли сохраняются Three.Group и MotionRegistry; дочерние примитивы обновляются под новую раскладку, векторная геометрия кешируется. Частичное обновление/загрузка изображения тоже сохраняет группу.
- `setTarget` получает цели непосредственно из модели, preview раскладки и drag. `journey-scene-pose.mjs` вычисляет мировую позу из IconMotion для WebGL, tile/caption/badge и связей. DOM-transform зеркалит её для ввода. Первичное измерение размеров/текста и повторное после resize сохранены.
- Общая оптика получает `publishGlassFrame`: подготовленный снимок контролов. Между заменой DOM и подготовкой следующего кадра читается прежний согласованный снимок, а не новый fallback uiFade=1. Фон standalone, стекло связей и worker используют этот контракт; viewport учитывает letterbox.
- Новые renderer, RAF, render targets и библиотеки не добавлены. Сценарии и пружины сохранены.

## Ограничения

Исправлено ядро движения и жизненный цикл сцены. DOM остаётся для текста, первичной раскладки, доступности и ввода; шаблонные контейнеры/попапы ещё обновляются разметкой. Полного удаления DOM/layout-чтений не заявляется.

Оптика больше не читает неподготовленные контролы, но native output и iframe сохраняют разные циклы. Полная синхронизация доставки GPU-кадров и производительность всего тракта остаются отдельной задачей. Краткий Check показывает MAX около25FPS; достижение60FPS и измеренный прирост не заявляются.

Без видео, тяжёлого профилирования, Selectel и Git-публикации. Снимок подтверждает конечный вид, а не отсутствие любого однокадрового дефекта. Художественная приёмка всех переходов остаётся за пользователем.
