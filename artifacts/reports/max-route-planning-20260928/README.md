# MAX: пошаговая сборка пути — проверка реализации

28.09.2026. Локальная ветка `codex/project-structure`. [Контракт интерфейса](../../../apps/max-game/docs/JOURNEY.md), [архитектура](../../../apps/max-game/docs/DEVELOPMENT.md).

## Изменено

- Первый плюс становится первым контекстным объектом без выбора из меню; исходная поза круга передаётся в MotionRegistry.
- Следующий плюс справа подписан «Твой второй/третий/четвёртый/пятый шаг»; в меню только оставшиеся шаги или три явных инструмента бизнеса. Навигационная иконка «Миссии» убрана из пикера. Плавающий внешний «Назад» сохранён.
- Ряд адаптивно центрируется. Существующие пружины сохраняют положение и скорость; links используют текущие центры во время планирования и перелёта. Выбор инструмента бизнеса и его постановка происходят одним действием.
- `plans[mission]`: building → ready → playing. До Continue значки задач скрыты; размещение не засчитывает выполнение. Матовый ready-попап использует существующие Frost/слои/clock. После Continue доступны задачи и свободное перемещение.
- Зависимости клиентского сценария проверяются при выполнении; расстановка допускается заранее. Восстановление активного прежнего прогресса сохраняет ответы, координаты и свободную фазу playing. Фазы новых планов сохраняются независимо по миссиям.

Профильные тесты проходят полный путь четырёх миссий, все бизнес-ветки, промежуточный/неверный ответ, сохранение и миграцию, невозможность пропустить Continue, отдельные стадии планирования/выполнения, порядок выбранных шагов, адаптивную геометрию для ширин1712/816/1520/820, непрерывность пружин и отложенный reveal badge. Геометрическая проверка выявила ограничение крайних координат узкого standalone; расчёт шага ряда исправлен с учётом полного hit-target и полей18px.

## Ограничения

Сборка проверена отдельно; применение к работающему стенду и видимый результат новой механики не проверены. Мастер оставлен выключенным по предыдущей команде пользователя, штатная read-only проверка подтвердила offline. Браузер, аппаратный FPS, художественная плавность и приём TouchDesigner не заявляются. Новая версия на Selectel не опубликована. Нет новых renderer/RAF/RT, видео, тяжёлых GPU-прогонов, Git-операций или shutdown. Несвязанные изменения стелы сохранены.
