Изменены создание цветовой Texture и его подключение в journey-webgl-ui. Скругление alphaMap, механизм вращения, скорость и фаза сохранены. [Обоснование](../../docs/Research/max-v5-gradient-coverage-20261003.md).

- 3 CPU-теста: controller phase/rate/pause, неподвижная alphaMap без переотправки текстуры, UV всех четырёх углов через каждый градус полного оборота. Контрпример старой матрицы при 45° воспроизведён.
- node --check двух изменённых модулей; duplicate guard PASS.
- Локальный build-webgl-v5-runtime: 28 файлов / 197 входных модулей. SHA всех 28 HTTP-файлов и 197 исходников соответствует manifest.

## Визуальная самопроверка — PASS для покрытия
