# Декоративные реакции MAX — локальная итерация

## 01.10.2026 — итог: декоративные реакции удалены

По прямому указанию пользователя из локальной `site-game` удалены все кружки, emoji, их DOM/CSS, генерация поз, тайминг и тест огибающей. В игре этот декоративный слой больше не создаётся. Исходный SVG пользователя сохранён только в этом отчёте как [референс](reaction-icon-reference.svg), SHA-256 `9f5329cf0ddcbeadf37dc34ddab74e6b8fa3a4d3ff29dcdd34d425b2f854ad72`; из source/runtime игры он удалён. Ниже — история отменённых вариантов, а не действующий дизайн.

Техническая проверка — PASS: синтаксис двух модулей, 13 CPU-тестов, duplicate guard, изолированная сборка (25 файлов), SHA исходника/runtime для JS/CSS/HTML, отсутствие SVG в runtime и manifest, HTTP 200. Визуальная самопроверка не выполнялась по прямому указанию пользователя. Адрес: `http://localhost:8770/max-game/site-game/index.html?layout=wall&v=no-reactions34`.

## 01.10.2026 — сверка стекла до следующей правки

Цель по кадру пользователя: тёмный круг, сквозь который заметно смягчается окружающий фон, тонкий серебристый край, мягкая глубина под ним и резкий цветной emoji сверху. Текущая правка с `icon.svg` даёт форму и тень, но его непрозрачный квадрат и чёрный диск лежат внутри элемента и закрывают фон; `backdrop-filter` на тонкой псевдообводке не создаёт стеклянную поверхность. На локальной странице брендбука MAX `.animated-card__glow-inner` использует полупрозрачный `#1c1c1fc7` и `backdrop-filter:blur(30px)`; это рабочий материал сайта, но круглая реакция из референса там готовым компонентом не представлена. Критерий правки: вся площадь круга размывает реальный фон, край остаётся тонким, emoji не размыт; прежний размер и траектории сохраняются. Технический статус исходного кода — известен; визуальный статус следующей сборки — ожидает кадра пользователя.

После правки: активный круг использует `#1c1c1fc7` и `backdrop-filter:blur(30px)` на всей поверхности, как стеклянный внутренний слой локальной страницы брендбука MAX. Тонкая светлая граница, мягкая внутренняя светотень и отдельный резкий emoji остаются поверх. SVG пользователя сохранён как исходный референс, но больше не перекрывает фон в игре. Периодичность и траектории прежние. Технический статус — PASS: JS-синтаксис, 14 CPU-тестов, duplicate guard, изолированная сборка, совпадение SHA source/runtime и HTTP 200. Визуальная самопроверка — BLOCKED прямым указанием пользователя не открывать браузер; ожидается его кадр. Адрес: `http://localhost:8770/max-game/site-game/index.html?layout=wall&v=reaction-glass33`.

## 01.10.2026 — пример основы иконки от пользователя

Получен [icon.svg](reaction-icon-reference.svg), SHA-256 `9f5329cf0ddcbeadf37dc34ddab74e6b8fa3a4d3ff29dcdd34d425b2f854ad72`. SVG имеет холст 1056×1056, полупрозрачный чёрный круг диаметром около 630 единиц, плотный центральный квадрат 400×400 и широкую мягкую тень. Emoji внутри файла нет. В локальной сборке CSS-имитация фона заменена этим исходным SVG; emoji остаются отдельным верхним слоем, а видимый диаметр круга сохранён через масштабирование полного прозрачного холста. Периодичность и траектории не менялись.

Техническая проверка — PASS: JS-синтаксис, 14 CPU-тестов, duplicate guard, изолированная сборка (26 файлов), совпадение SHA исходника/runtime для SVG/CSS/JS/HTML, HTTP 200 для страницы и SVG. Визуальная самопроверка: BLOCKED прямым указанием пользователя не открывать браузер. Художественная оценка ожидает его кадра. Адрес: `http://localhost:8770/max-game/site-game/index.html?layout=wall&v=reaction-svg32`.

До правки: в изолированной игре таких элементов нет. Цель: до четырёх матовых полупрозрачных кругов с реакциями, плавным входом/уходом и медленным дрейфом по всему полотну 4096×1280, включая пространство левее игровой зоны. Слой не принимает касания и не закрывает игровые кнопки.

Техническая проверка — PASS: `node --check` двух изменённых модулей, 14 CPU-тестов, duplicate guard, изолированная сборка `site-game` (25 файлов), SHA-256 исходника/runtime для четырёх изменённых ресурсов и HTTP 200. Художественное утверждение: ожидается. Адрес проверки: `http://localhost:8770/max-game/site-game/index.html?layout=wall&v=reactions31`.
