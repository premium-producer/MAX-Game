# MAX site-game: свет карточек — сравнение по референсу

Уточнение по отзыву пользователя: технически доставленная версия `card-glow40` не сохранила движущийся эффект брендбука, поскольку `animated-card__glow-outer` был скрыт. Это **визуальный FAIL** исходного варианта. Локальная правка `card-rim41` восстанавливает орбитальный слой с приглушённой обычной и яркой контактной фазой. PASS: duplicate guard, 14 CPU-тестов, сборка 25 файлов, source/runtime CSS SHA-256 `8D47F124AE116646B39FCACB3DA5CAE9022683F53A6C217EB213D8D86E8ACD68`, HTTP 200 HTML/CSS новой версии. Визуальная самопроверка заблокирована действующим указанием не открывать браузер; новая оценка пользователя ожидается.

Референс пользователя: [фрагмент](card-glow-reference-20261002.png), PNG 362×405, SHA-256 `B239D1A4C3473BDE4505DFD0264541E888C7A9945E824442CF95879B73963D0D`. Это пользовательский снимок локальной игры; точные URL, фаза и масштаб неизвестны. Он задаёт роль **света кромки и наружного ореола**: ровная яркая тонкая линия вокруг плитки MAX, мягкий свет снаружи; белый знак и подпись остаются резкими. Пользователь уточнил, что в спокойном состоянии свет должен быть приглушённее и фиолетово-пурпурным, а при контакте — ярким. Цвет цианового исходного снимка не переносится как цель нового оформления.

| Критерий | До правки | Цель текущего шага | Статус |
| --- | --- | --- | --- |
| Тонкая скруглённая кромка | У узла стекло со светлой рамкой; у меню — отдельный орбитальный источник | Градиент по кромке всех интерактивных карточек без выхода за радиус | Ожидает кадр пользователя |
| Свет на стекле | У узла нет локального светового акцента | Слабое ограниченное пятно внутри заливки, резкий знак/текст | Ожидает кадр пользователя |
| Нажатие | У route drag есть циановый box-shadow, у меню glow от hover | Яркий фиолетово-пурпурный контур при реальном контакте | Ожидает кадр пользователя |
| Цвет связей | Циановые SVG stroke/halo/частицы | Фиолетовый градиент по пути | Следующая итерация |

Сравнимые ROI после сборки: плитка MAX в ряду без касания и при касании; карточка миссии в меню без касания и при касании; край скругления и нижняя часть стекла на масштабе не меньше исходного фрагмента. Техническая проверка **PASS**: duplicate guard, 14 CPU-тестов, изолированная сборка 25 файлов, source/runtime CSS SHA-256 `5B4FFD259BC0A29D9A4E8D28DFED10E56E286062992ABEBAABABC30D9549C7BF`, HTTP 200 HTML/CSS версии `card-glow40`. Самостоятельный браузерный снимок запрещён действующим указанием пользователя, поэтому визуальная самопроверка и приёмка пока **BLOCKED/ожидается**.
