# MAX: Site и актуальные ассеты подключены к общему ядру

02.10.2026. Три независимых блока выполнены параллельно: каталог и клиентские правки, подбор ресурсов, адаптер существующей Site-страницы. WebGL не подключался и не пересобирался; отдельный визуальный стенд не создавался.

## Реализовано

- Один `MISSION_CATALOG`, `missions-20261002-v2`: шесть миссий, 16 заданий. Совместимые старые content shapes являются проекциями этого каталога. Ответ подписчику, сокращённая статистика, голосовое перед видео и удаление группы подтверждены. Бизнес и тестовый бизнес: сфера → платформа/верификация → канал → бот → мини-приложение. Все инструменты обязательны, ID и создание бизнес-аккаунта отсутствуют.
- Существующий Site entrypoint получает snapshot/actions через SessionPort. Правила, scan, ответы, прогресс, таймер, результат и reset принадлежат ядру/application. Browser PersistencePort — отдельный явно выбранный локальный preview-профиль, ключ `max-site-shared:v1:missions-20261002-v2`. Старые ключи не изменяются. Серверный профиль подготовлен с авторизацией и без автоматического local fallback; SQLite API мастера остаётся выключенным.
- DescriptorView сохраняет текущую оболочку, материалы, общий RAF и crossfade 700 мс. Действия внутри устройства, справа только информация; PC для горизонтальных кадров. Быстрые updates объединяются до последнего, одновременно не более двух кадров. Поздняя загрузка после dispose или 12-секундного deadline не применяется. Загрузка показывается после неожиданной задержки 800 мс; ошибка/timeout дают retry внутри устройства.
- Предзагрузка текущего задания и первых двух кадров следующего. Все ресурсы и MP4 разом не декодируются. Восстановление результата не начисляет второй зачёт; drag задерживает визуальное закрытие/открытие независимо от backend-профиля.
- [Подборка ассетов](../max-game/design/assets-selection-20261002.json) и [таблица покрытия](max-site-assets-selection-20261002.md): 303 ресурса, 65 экранных IDs, 59 уникальных ассетов актуальных заданий. Оригиналы сохранены. Реальные пробелы не получают успешный зачёт; конфликтный/недостающий кадр показывается как явный пробел. Правка UI в лапах Мишки отложена.
- `build-site-runtime.mjs` выпускает Site, shared ESM и канонические ресурсы без Legacy/esbuild. Site compatibility modules ссылаются на shared content, а не создают вторую копию правил. Сборщики защищают пользовательские изменения runtime.

## Проверено

- **164/164 CPU**, 541 мс: shared core/ports, версии/импорт, обе приватности, следующие задания/reload, CAS/повреждённое сохранение, раннее отпускание, result reload, rapid descriptors, late decode и image deadline; существующая геометрия и motion CPU-тесты.
- Синтаксис 15 модулей, архитектурный guard 20 shared modules, duplicate guard — PASS.
- Сборка: 50 Site-файлов; 20 shared modules; 17 task descriptors (16 mission tasks плюс самостоятельный каталог канала); 130 asset IDs с 120 физическими путями.
- SHA всех 50 Site-файлов, 20 shared modules и 130 canonical asset entries совпали с manifest; 19 относительных импортов Site разрешаются в комплекте.
- 13 HTTP/SHA проверок `localhost:8770`: index/app/DescriptorView/content wrapper, общий каталог/application, первый кадр канала, ID SVG, сюжетное фото, бизнес-кадр и QR — PASS. Это проверка доставки статических файлов, не визуальная приёмка.
- Четыре Legacy-файла (`app.js`, `guided-app.js`, `src/journey-guided-reveal.css`, `index.html`) сохранились побайтно. Мастер не перезапускался, API не включался, публикации/браузерного обхода не было.

## Локальная приёмка пользователем

`http://localhost:8770/max-game/site-game/?backend=local`

Первая проверка: блогер → ладонь → плюс внутри скриншота → приватная или публичная ветка → ответ подписчику → статистика → QR. Перезагрузить на промежуточном экране: затем текущий узел должен продолжить сохранённое задание. В меню ↻ сбрасывает новый профиль. Для геометрии стены добавить `&layout=wall`.

Бизнес и общение имеют явные пробелы исходного контента, поэтому просмотр с пропусками заканчивается неполным результатом. Подключение server-профиля к активному мастеру, WebGL, художественная приёмка и исправление телефона внутри сюжетных фотографий не входят в эту итерацию.
