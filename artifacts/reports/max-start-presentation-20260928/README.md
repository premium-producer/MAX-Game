# MAX — презентация первого шага, 28.09.2026

## Изменение

Первый MAX наследует центр/размер круглого CTA. Плюс плавно уступает место оригинальному MAX SVG, знак увеличивается от30% до100% за240ms. После полного появления центр сохраняется ещё500ms; затем critical spring omega10 перемещает тот же объект влево. Подпись проявляется на месте; следующий плюс скрыт/inert до посадки. Семантика BEGIN_ROUTE и сохранения не менялась.

JourneyIntroBurst рисует12 расходящихся изогнутых струй с ядром/ореолом и900ms lifetime. Пул2 плоскостей для двух зон, общий foreground renderer/clock, precompile при загрузке, clipping по зоне, без новых RT/RAF. Это процедурная визуализация флюидного всплеска, не дополнительная физическая симуляция жидкости. Пауза сохраняет фазу, reduced motion без burst/hold, смена layout очищает transient state. Клиентские phone-scenes по-прежнему заглушки.

Применены max-webgl-motion, max-game-development, vk-webgl-neon, max-brand, vk-live-verification. Оригинальный знак и его пропорции сохранены; шесть цветов проектной палитры, без новых брендовых ассетов.
