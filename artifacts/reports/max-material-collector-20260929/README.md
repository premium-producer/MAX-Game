# Проверка сборщика материалов MAX — 29.09.2026

## Адаптация под структурированный клиентский макет

Завершена сборка структурного режима (по умолчанию). 22 CPU-теста проходят; новые проверки покрывают SECTION→FRAME и SECTION→SECTION→FRAME одновременно, числовой порядок 1/2/10 вопреки координатам, landscape, вложенные UI-фреймы, дубли выделения, одинаковые названия разных контейнеров, игнорирование посторонних текстовых заголовков, ручной порядок и назначения, экспорт sectionPath, отказ после изменения родителя, Unicode-папки и метаданные unpack. Синтаксис core.cjs/runtime.js/code.js/unpack.mjs проверен. Существующий UI-test проверяет сообщения scan/export и редактирование группы через mock DOM.

Макет не меняется. Браузерная проверка остаётся недоступной после ранее зафиксированного file:-запрета; обход не выполнялся. Реальная структура клиентского Figma-файла и нативные PNG на ней ещё не проверены. CPU-проверки не являются визуальной приёмкой.


Подготовлена отдельная папка artifacts/DESIGN/figma-plugins/max-material-collector. Инструмент только читает Figma, не создаёт страницу, не изменяет слои/выделение, не использует сеть. Готовые code.js/ui.html/manifest.json, исходники, инструкция и unpack.mjs сохранены без ZIP.

Проверки: 17 CPU-тестов классификации/контрактов и распаковки; node --check собранного sandbox-кода и unpack.mjs; синтаксис inline UI; manifest JSON — pass. Тесты покрывают безымянные экраны под заголовками, публичный канал в Section/Group, конфликт имени контейнера и локального заголовка, соседние секции, вложенные/растровые телефоны, большую вертикальную доску, общую подготовку фото, порядок чтения, ручное назначение, работу после смены страницы, ошибки/отмену и безопасную распаковку без перезаписи. Mock UI проверяет сообщение сканирования, групповое назначение и контракт экспорта. Эти проверки не заменяют запуск настоящего Figma API.

Реальный клиентский файл Figma недоступен: URL не передан, поэтому состав узлов, точность эвристик, нативный экспорт и скачивание внутри Figma ещё не проверены. Базовый браузерный просмотр локального ui.html был заблокирован политикой браузера (file:// недопустим); обход не предпринимался. Интерфейс проверен синтаксически и через mock DOM, визуальная браузерная приёмка остаётся открытой. Игра/мастер/Selectel этим заданием не изменялись, видео и тяжёлые GPU-тесты не запускались.

Основные ограничения: только текущая страница, эвристическое сопоставление и геометрический порядок, без OCR/шрифтовых файлов/видео, без восстановления произвольных нарисованных стрелок. Нет автоматического доказательства полноты заданий. [Контракт](../../../apps/max-game/docs/MATERIAL_COLLECTOR.md). [Исследование](../../../docs/Research/max-figma-material-collection-20260929.md).
