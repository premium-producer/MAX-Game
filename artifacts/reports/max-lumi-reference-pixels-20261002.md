# MAX: плотность и цвет клеток по пользовательским кадрам

Измерение CPU (Pillow/NumPy), без браузера и GPU. Референс: `codex-clipboard-0f269ba5-875c-4543-b5aa-8bb5ce1aeee1.png`, 1291×409. Предыдущий кадр игры: `codex-clipboard-2275f9a3-ae23-47f6-bfed-17400d74851c.png`, 2543×1227. Исходный pattern из SVG: 1536×672.

На горизонтальном сигнале яркости (ROI X2–37%, Y45–52%, производная для удаления плавного градиента) первые основные пики автокорреляции: референс13px, игра39px, исходный pattern15px. Исходный шаг15×3591/1536≈35.07 единиц SVG. Референс соответствует ~102 столбцам, прежний кадр игры — ~65. Причина в коде: pitch35×max(width/3591,height/1113), то есть cover увеличивал клетки при высоком окне и обрезал боковые участки. Теперь pitch35×width/3591; композиция центрируется вертикально, плотность по ширине сохраняется.

Цветовой диапазон P10→P90 ROI шириной15px, Y45–55%, X8%: референс RGB(27,9,93)→(32,35,122), предыдущая игра(32,9,106)→(41,15,126). В центре X50%: референс(42,13,94)→(62,28,103), игра(33,5,94)→(48,16,118). В исходном pattern видны голубые боковые участки и розово-сиреневый центр. Прежняя чисто фиолетовая палитра почти убирала зелёный канал центра. Новая палитра эмиссии: cyan(.08,.78,.96), blue(.24,.18,.88), lilac(.90,.40,.98), энергия×1.25, прежнее смешение pattern20% сохранено. Это калибровка по источнику, не доказательство точного совпадения GPU-результата.

Периоды анимации4/8/16с, амплитуды, blur и фоновые заливки сохранены. Диагностика `background-debug=1` показывает pixels-03.

PASS: CPU native viewport/DPR4, плотность столбцов, независимость шага от высоты окна, clock30/60/120Hz и pause/resume. Визуальная самопроверка нового GPU-кадра: BLOCKED по установленному процессу (браузер не открывать, кадр присылает пользователь). Полное цветовое совпадение и утверждение пользователем остаются открытыми.
