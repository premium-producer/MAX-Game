# MAX: клиентские миссии и 2D-поле — проверка 27.09.2026

## Изменения

По прямому указанию пользователя: старт с выбора четырёх клиентских миссий, цифры вместо космических иконок, новые названия и описания. Земля, орбиты, вступительный CTA и боковые плашки исключены. DOM/SVG-поле сохраняет принцип сборки маршрута по порядку и близости. Бизнес имеет три альтернативы; условный порядок ID/общения указан в результатах. Обновлены max-game-development, AGENTS и действующая документация.

[Полные правила](../../../apps/max-game/docs/CLIENT_MISSIONS.md). Бренд: max-brand, оригинальный монохромный логотип, Max Sans, пользовательская палитра из шести HEX; фон мастера сохранён. Финальная художественная и физическая LED/touch-приёмка не заявляются.

- [110/110 обязательных ribbon-тестов](ribbon-tests.txt).
- Штатные MAX build и Stand Service build_service.py --preserve-native выполнены. Бинарник/нативные bindings не менялись. MAX: 15 runtime-файлов, 204 290 байт, 3 JS-входа, без Three.js/Earth в активном bundle.
- check:local: проверены 560 неизменных upstream-файлов, 13 skills, 3 входа bundle и SHA всех 15 runtime-файлов. Внешний X-SPUTNIK не использовался.
- [HTTP SHA](http-hashes.json) совпали для bundle, CSS, каталога миссий и worker после окончательной сборки.

## Живой путь

Stand Service run, http://localhost:8770 → max-wall-right → Electron iframe → Spout/WebRTC → одна вкладка presentation. Перезапускался только MAX; поколения четырёх остальных источников не изменились. [До](before.json), [после](after.json); все пять источников running, error=null, кадры MAX идут. Полный state и токены не сохранялись.

В потоке мышью открыта первая миссия, два действия размещены тапами, третье перетащено. Появился итог «Маршрут собран»: [подтверждение](live-route-complete.png). Это проверка основной сборки до заключительной правки нижней границы и отмены удалённого жеста. После этих правок повторно выполнены тесты/сборка, смена generation, HTTP SHA и видимая проверка меню окончательного источника: [итоговое меню](live-menu.png).

В той же вкладке отдельно открыт standalone: видны четыре клиентские миссии. Клавиатурой проверен выбор бизнес-ветки «Чат-бот»: третий узел меняется, два размещённых общих узла сохраняются. Проверку ветки мышью не засчитываем: наблюдалось несовпадение размеров окна между DOM и снимком, действие не было подтверждено. Ошибок/warn в консоли наблюдавшейся вкладки нет.

Дополнительно исправлено: y размещаемого узла ограничен с запасом под подпись; при удалённом cancel worker синхронно отменяет preview игры до native mouseUp. Полный живой прогон cancel/паузы всех веток и повторный 3D-walk не выполнялись. Контракт координат/жестов проверен CPU; 3D-viewer в этой итерации не менялся. Тяжёлых GPU-прогонов и записи видео нет. Конкретный FPS не измерялся; отсутствие WebGL внутри игры не означает отсутствие GPU у всего стенда.

Полный переносимый master ZIP в этой итерации не обновлялся; действующие apps и комплект Stand Service обновлены. Git staging/commit/push не выполнялись.
