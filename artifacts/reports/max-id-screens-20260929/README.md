# Проверка исходных экранов создания ID · 29.09.2026

[Контракт](../../../apps/max-game/docs/DIGITAL_ID_SCREENS.md), [исследование источника](../../../docs/Research/max-digital-id-screencasts-20260929/README.md).

## Проверено

- Создание ID в обеих редакциях (`create-id`) и обеих тестовых миссиях (`demo-id`) использует единый набор из 13 исходных кадров. Хеши PNG совпадают с переданным экспортом, 360×800, пропорции сохранены. Внешняя сборка сети не изменялась.
- 130/130 Node-тестов journey*.test.mjs + client-webgl.test.mjs. [Лог](node-tests.txt). Покрыты четыре места использования, включение/пропуск биометрии, отказ от согласий/входа, полнота кадров, restore после каждого шага, миграция старого выполненного/незавершённого ID и работа автоматических переходов при остановке/закрытии.
- Синтаксис 9 изменённых JS-модулей; после исправления крестика повторная проверка изменённых двух модулей и 130 тестов.
- Штатная сборка: 193 файла / 76 compiled inputs; check-local pass. Применены только локальные исходники/комплект MAX.
- Одной вкладкой пройден demo-id в бизнес-миссии: Создать QR, Добавить документы, автоматическая заставка, отказ на согласии без продвижения, оба согласия, вход, ПИН/повтор, биометрия, готовый ID, завершение. Перезагрузка сохраняет выполненный ID. После закрытия доступно следующее бизнес-задание.
- Визуально проверены светлые клиентские экраны внутри телефона, пропорции, карточка инструкции, готовый QR и закрытие. Во время проверки найдено перекрытие крестика обновлённым изображением/недостаточный контраст на белом: крестик обновляется последним, перенесён на сторону карточки и использует SVG. Финальная сборка повторно открыта; крестик виден и закрывает попап.
- Console error/warn = []. Отдельного полного браузерного прохода остальных трёх мест использования не было: общий сценарий проверен там CPU-тестами.
- Все 15 файлов (app.js, CSS, 13 PNG) по HTTP побайтно совпадают с apps/max-game; [SHA-256](verified-files.json).
- Check.bat pass, пять источников running/error=null; MAX generation `aaac26b1-f0df-44a3-ab6e-3dc1c0a614a4`. Четыре остальных generation сохранены. Проверка Spout sending не подтверждает приём TD.

## Ограничения

Кадры статические, выбранные промежуточные длительности не являются таймингами исходного видео. ПИН показан по касанию области клавиатуры, цифры не собираются. Биометрия и Госуслуги — симуляция без реальных API/учётных данных. Фото и остальные скринкасты не интегрировались в этой задаче. QR внутри изображения — клиентский образец, скан не проверен; финальный QR сайта MAX сохранён отдельно. Художественная/аппаратная приёмка и 60 FPS не заявляются. Тяжёлые тесты/запись видео/Selectel/Git commit/push не выполнялись.

Применены проектные правила MAX: max.naming.service, оригинальные исходные изображения без перерисовки, прежняя матовая оболочка/контекстные переходы. Это не утверждение юридической актуальности показанных согласий.
