# MAX на правом экране — проверка 27.09.2026

Реализованы адаптер полного DOM/WebGL-кадра, штатный GPU/Spout program, WebRTC-превью, pointer-ввод и пауза. Правый экран 4096 × 1280 использует `max-wall-right`, без изменения пользовательских назначений. [Рабочий контракт и размеры](../../../apps/stand-service/docs/MAX_GAME.md).

## Проверено

- CPU: игровая логика, геометрия центральной зоны, program/stamp, game input lifecycle, отмена по паузе/отключению/тайм-ауту, маршруты dev/run, LAN release digest и существующие сервисные регрессии. Итог: 124/124; лог — `tests.txt`. Node --check: 19 файлов; check:local: 560 snapshot-файлов, 13 skills, 55 входов и 168 runtime-файлов, pass.
- Изолированная проверка одного Electron-worker 960 × 300 выполнена после явного согласия пользователя. Native ACK дошёл до frameId=1204, WebRTC содержит интерфейс и Землю, нажатие переключило старт на обучение. Spout в fixture выключен. Fixture штатно остановлен.
- При проверке исправлены неправильный тип пикселей ImageData, видимость ссылки «К мастеру» на стене и блокировка основного кадра CPU-кодированием preview.
- Затем выполнено штатное применение к рабочему мастеру run на localhost:8770. Проверены projectId/nodeId до остановки. После изменения серверного host потребовался один полный stop/start; последующая правка preview применена перезапуском только MAX.
- Все пять существующих источников вернулись в running без ошибок. MAX: scene 4096 × 1280, program 4096 × 1282, Spout sending / registered, новая generation и рост frameId. В рабочем presentation нажатие перевело игру на обучение, консоль без warn/error. После последней правки preview повторно виден стартовый экран. [Снимок реального потока](live-right-screen.png).
- `before.json` / `after.json` содержат безопасный срез состояния без csrf. Профили, назначения и outputs сохранены. HTTP-хеши совпали с текущим runtime. Полный комплект: `artifacts/workspace/dist/vk_master_0.12.0_windows_x64.zip`, 602 файла, 431 985 320 байт; CRC и SHA проверены.

## Ограничения

Это базовая техническая проверка, не длительный GPU-прогон. Около 15 FPS program при открытом preview и остальных рабочих источниках — наблюдение одного состояния, не гарантия. Preview имеет CPU-копирование/PNG; его частота ограничена 10 Гц. Проверены WebRTC и регистрация отправителя, но не изображение физического LED/приёмника TD и не аппаратный touch. Высота поля рассчитана от низа экрана; монтажная высота и удобство реального пользователя требуют приёмки на стенде. Игра однопользовательская, аудио в видеопоток не передаётся, NDI отключён.

Правила MAX: `max.logo.background`, `max.logo.no-recolor`, `max.type.fast-reading`, роли Max Sans и цвета из локального пакета. Монохромный SVG и шрифты сохранены; положение игрового поля — прикладная адаптация. Нет утверждения владельцем бренда. Механика миссий не менялась. Исследования не создавались, commit/push не выполнялись.

После закрытия preview наблюдалось около 20 FPS program (after.json); это также одиночное наблюдение, не гарантия.
