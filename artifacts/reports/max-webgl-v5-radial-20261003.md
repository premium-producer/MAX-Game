# MAX v5: коррекция оформления иконок

URL: http://localhost:8770/max-game/webgl-v5/?backend=local&layout=wall

Исходный пользовательский кадр: codex-clipboard-9e17ac51-4268-42d3-b11f-8640f4c56293.png. Он показывает подпись внутри плитки, а не под ней; световой вклад отличается от BFM.

## Установлено по коду

- Старое правило html[data-reveal=true][data-service=false] сильнее v5 html[data-visual=webgl-bfm-v5], поэтому позиция подписи top172 побеждала top278 нового оформления. Исправленный v5 selector имеет три атрибута и прежний scope #circles; теперь побеждает старый. Caption и SVG geometry остаются в подготовленном WebGL frame.
- Tile использовал referenceRole материал с белым добавочным вкладом c+=vec3(.15), rim/glow/selection. Новая v5-only ветка плиток/medallion использует CanvasGradient/CanvasTexture/MeshBasicMaterial toneMapped:false без этих оптических слоёв. Рисунок — слои фактической BFM CSS, native roundRect clip и sRGB texture через действующий cache/dispose.
- Старые версии runtime не пересобираются. Прогресс, движок, ввод, расположение устройств/переходы/фон не изменяются. Контроллер вращения остаётся отдельной незавершённой задачей.

## Проверки

PASS JS syntax, duplicate guard, v5 CSS parser и scoped builder. PASS HTTP/runtime SHA7/7; JSON рядом. В предыдущей итерации прошли30 тестов общего адаптера; здесь игровые правила не менялись, повторное прохождение тестов не заменяет проверку вида.

**Визуальная самопроверка: не выполнена. Пользовательская приёмка: открыта.** Браузер не открывался: предыдущий отказ auto-review на новую вкладку не обходился. CSS cascade и отсутствие старого tile shader подтверждены кодом, но устранение видимого эффекта требует нового кадра.

Проверка пользователю: обновить v5 → открыть текущую миссию → посмотреть текст под плитками и радиальное пятно без белого блика. Мастер/TD не запускались и не менялись.
