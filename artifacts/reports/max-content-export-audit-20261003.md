Источник: `artifacts/DESIGN/figma-exports/2026-10-03_13-44-25`, страница `DEV 2`, scope=page, selected=[].

**Итог: передача файлов завершена; логическая карта содержит ошибки и не готова для автоматического импорта в игру.** Исходная выгрузка и плагин в этой итерации не изменялись.

## Целостность — PASS

- export.json и catalog.json: complete; 120 записей, unexported пуст.
- Все 871 файл из подтверждённого журнала существуют; размеры и SHA-256 совпадают.
- 378 PNG: сигнатура, CRC всех chunks и распаковка IDAT успешны. Это проверка контейнера, не художественная оценка.
- 120 SVG разобраны XML-парсером; 360 JSON разобраны. Остальные файлы проверены по размеру/SHA.
- У 84 готовых экранов четырёх основных миссий справки непустые; текст и все blocks совпадают между картой и экспортированными записями. Сравнения с живой Figma не проводилось.
- Старый временный export.json.*.tmp от EPERM сохранён. Он не является текущим журналом или новой ошибкой.

## Ошибки структуры — FAIL

1. **23 записи миссий вместо четырёх основных контейнеров.** В map.cjs глобальный обход всех потомков снова применяет missionRoute внутри уже найденной миссии. Сложный вложенный Auto Layout настоящих UI совпадает с эвристикой. В результате появляются 19 лишних записей миссий; бизнес получает order=6 вместо четвёртого места. У 16 лишних миссий ID непосредственно найден внутри layers основных визуалов; ещё три — обёртки карточек бизнес-канала. Все 17 дополнительных экспортированных записей являются потомками уже экспортированных основных визуалов: это повторный экспорт частей интерфейса, а не новые задания. Ошибка экспортера, не повреждение исходных файлов.
2. **Одна строка не экспортирована:** блогер → Статистика → строка 3, node `296:13602`, status=ambiguous, справка пустая. Сам визуал этой строки отсутствует в выгрузке; определить его содержимое по сохранённым данным нельзя. Статус complete означает только завершение принятой очереди и не закрывает этот пробел.
3. **coverage.json недостоверен для нового формата.** Все 18 старых категорий имеют count=0/not-found-in-export, хотя материалы присутствуют. Причина: адаптер записывает task=unassigned, а общий отчёт использует старую классификацию task. Такой отчёт нельзя использовать для вывода о полноте миссий.

## Предупреждения и пределы проверки

- В 21 записи есть предупреждения Figma: getter componentProperties недоступен из-за ошибок component set. PNG/SVG этих записей сохранены, но полнота метаданных компонентов не гарантируется.
- В 75 записях нет текстовых слоёв визуала — это допустимо для растра/кривых; справки проверены отдельно.
- Полное соответствие финальным клиентским текстам и визуальный вид всех изображений этой технической проверкой не подтверждаются. Имена фреймов не использовались как источник игрового порядка.

Следующая отдельная итерация: ограничить распознавание миссий внешним уровнем, выяснить неоднозначную строку и согласовать coverage с contentMap, затем повторно выгрузить карту. Эта проверка не меняет контент или игру.
