# MAX: WebGL-интерфейс и перемещение объектов — 28.09.2026

Реализованы все видимые игровые экраны в существующем WebGL renderer: текстовые GPU-текстуры, геометрия монолитных SVG-иконок, shader-поверхности, динамика и веерное меню. Невидимый DOM остаётся источником layout/accessibility/input. Реальная оптика сохраняет отдельные профили clear/Frost. Новых WebGL context или RT для foreground нет. Меню миссий и пикер анимированы; mouse/touch drag двигает объект и волокна, сохраняет позицию, короткий тап открывает задачу.
