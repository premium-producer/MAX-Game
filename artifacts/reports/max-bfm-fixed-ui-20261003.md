# MAX BFM — постоянный увеличенный UI, 03.10.2026

Предыдущая правка неверно увеличивала stage только после появления телефона. По уточнению пользователя весь игровой UI должен быть увеличен с открытия страницы. Удалены измерение телефона и вызов fitStage из native phase update. Один фиксированный authored масштаб0,750976 применяется до старта SessionPort и остаётся тем же для menu/scan/reveal/task/finish/PC. Центр stage остаётся центром комфортной зоны. Фон и физическая пиксельная карта сохраняют прежнюю плоскость.

Базовая высота540px взята из измеренного телефона с кнопками предыдущей итерации. Task-контент имеет постоянное CSS-смещение95px, совмещающее базовый телефон с полосой1–1,8м при неизменном центре stage. Это стандартный CSS transform/translate из уже исследованного browser/BFM механизма; новых библиотек/solver/RAF нет. Реальные экраны разной высоты больше не меняют масштаб группы. Точная высота каждого телефона может отличаться от базовой, отдельной нормализации содержания в этой правке нет.

PASS6 CPU-тестов, syntax2 модулей, CSS parser, duplicate guard, scoped BFM build и runtime/HTTP SHA.
