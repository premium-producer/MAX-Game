# MAX Site — подключение общего backend, 02.10.2026

Существующая `/max-game/site-game/` подключена к MissionSessionApplication через SiteSession. Правила, активное задание, ответы, результат, удержание, таймер, рестарт и сброс берутся из общего snapshot/commands. ChannelTransition и локальный review reducer больше не импортируются entrypoint. Прежние сохранения не читаются и не перезаписываются.

По умолчанию выбран явный локальный preview-профиль `backend=local`: Browser PersistencePort сохраняет отдельный `max-site-shared:v1:<contentRevision>`, поддерживает CAS и не заменяет повреждённые данные пустым прогрессом. Это не серверная SQLite-сессия. `backend=server` подключает ServerSessionPort к отдельному API MAX с same-origin X-VK-Token; при недоступности сервера автоматического local fallback нет. API мастера не включался.

DescriptorView получает только device/asset/instruction/actions; исходные кадры, hotspots и коррекция публичного заголовка общие. Горизонтальные экраны используют прежнюю PC-оболочку. Справа только информация; automatic screens не создают локальных кнопок. Отсутствующий или конфликтующий материал показывается явно, его пропуск не становится выполнением. Старый кадр остаётся до decode нового. Rapid descriptors coalesced, максимум два кадра, текущая blend-поза сохраняется; disposed view не применяет поздний decode. Сохраняются существующие оболочка, материалы, движения и 0,7-секундный crossfade, один RAF.

Прогрев: текущие ресурсы и текущий task, первые два кадра следующего task. Видео и весь брендовый каталог заранее не загружаются. Официальные существующие иллюстрации ID и трёх бизнес-инструментов сопоставлены узлам; другие отсутствующие картинки остаются обозначенными. Авторские Legacy-пиктограммы не переносились. Три бизнес-иллюстрации побайтно скопированы из официального site-kit и добавлены в provenance.

PASS: node --check четырёх изменённых модулей; 8/8 CPU (~102 мс): public/private → комментарии → статистика → reload; быстрый повтор и устаревший экран; раннее отпускание; CAS/повреждение storage; восстановление result без второго зачёта; три быстрых descriptor updates; dispose-before-decode. DOM-проверки используют малый fake DOM, не браузер/GPU. Техническая сборка и HTTP/SHA доставка выполняются root отдельно. Визуальная приёмка, размеры и реальная загрузка браузера ожидают пользователя.

Адрес для проверки: `http://localhost:8770/max-game/site-game/?backend=local`. Первая миссия: ладонь → плюс в скриншоте → обе приватности → комментарии → статистика → QR. Дополнительно перезагрузка и продолжение, сброс ↻ в меню, бизнес PC с честными пробелами. WebGL и работающий мастер не переключались; публикации не было.
