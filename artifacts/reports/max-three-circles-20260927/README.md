# MAX: три независимых стеклянных круга · 27.09.2026

Уточнение пользователя: исходный фон сохранить, свет — локальные полосы/градиенты с ореолами; три круга на всю стену, независимые игровые зоны. Прежние 16:9, правый сдвиг и квадратные панели отменены.

## Реализация

- Активный circular-main.js + circle-model.mjs + circular.css. Один исходный createWebGLField на всю стену 4096×1280; три окружности радиуса 520. Никаких трёх renderer/iframe/источников.
- Прежние glow-узлы, анимированные многослойные связи/частицы и bloom сохраняются. Стеклянные края — CSS; игровой маршрут/контакт ограничены своей внутренней областью. Из исходного рендера добавлены разрешённая область plane-point и индивидуальный радиус endpoint, без изменения других режимов.
- Четыре клиентские миссии доступны в каждом круге. Состояние, ID, выбор действия, бизнес-ветка, удержание и результат раздельные. Переключение между кругами возвращает локальный выбор; изменять соседние узлы нельзя. UI содержит короткое задание и круглые номера вместо боковых/нижних прямоугольных панелей. Сброс или смена миссии действует на свой круг.
- Проверка маршрутов — прежний mission-evaluation/screenProjected. 350 мс wake, 120 мс свежесть, 300 мс hold. Глобальная ревизия кадра не сбрасывает локальное удержание соседней зоны. Пауза/скрытие/cancel очищают удержание.
- Фон max-wall-atmosphere теперь добавляет локальные текучие полосы и аналитическое свечение к прежнему underlay; сплошной mix-заливки нет. Проектная палитра MAX, исходный Figma Angular не заявляется. Стена единая у шва.
- Viewer «Подойти к MAX» направлен к центральному кругу, остальные изменения стелы сохранены. Старая вкладка Viewer требует обновления. Pointer API/Spout/WebRTC не менялись.

## Проверено

- 115/115 MAX/service тестов; 110/110 Ribbon; 9/9 walk. Часть тестов относится к сохранённому движку и историческим прототипам, не выдаётся за полный живой walkthrough всех четырёх сценариев.
- JS syntax изменённых файлов. Штатные сборки MAX, Stand Service preserve-native и Viewer. check:local: 560 upstream файлов неизменны, 175 runtime файлов, 39 модулей. Внешняя директория не используется.
- В первом запуске выявлено отсутствие декоративного контура в default catalog: подключён штатный локальный contour catalog, Earth-текстуры по-прежнему не загружаются. Белая подложка iframe устранена согласованием color-scheme:dark с родителем.
- Перезапущен только MAX, остальные generation сохранены. Check.bat: пять running/Spout sending, кадры продвигаются. SHA HTTP app.js, circular.css, max-wall-atmosphere.js и viewer.js совпадают с runtime.
- Одна вкладка реального presentation: первые два круга открыли разные миссии реальными тапами. Первый маршрут A→1→2→3→Б собран и засчитан; второй остался в своей миссии «Общение», третий — в меню. live-circles.png. Console warn/error presentation пустая.

## Ограничения

Короткая проверка, не художественная/аппаратная приёмка. Полное прохождение всех миссий/бизнес-веток на круговой компоновке не выполнялось. Три независимых состояния не означают проверенный аппаратный одновременный multitouch: существующий native pointer транспорт остаётся прежним. Перезапуск источника сбрасывает игровую память. Новое положение подхода Viewer проверено сборкой/CPU, повторного 3D/TD-приёма не было.

Производительность всего стенда открыта: около 5.3 FPS MAX в коротком Check при пяти источниках; это не изолированный benchmark. Без тяжёлых прогонов, видео, Git-публикации и полного master ZIP. [Контракт](../../../apps/max-game/docs/CLIENT_MISSIONS.md).
