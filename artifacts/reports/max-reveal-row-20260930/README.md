# MAX Reveal: последовательное раскрытие и ряд

Требование30.09.2026 заменяет композиции по миссиям для Guided Reveal: иконки по очереди выходят из ладони, после раскрытия всех перелетают по дугам в горизонтальный ряд. Далее телефон проходит этот ряд. Остальные эксперименты и опубликованный релиз не переключаются автоматически.

| Признак | Критерий проверки |
| --- | --- |
| Очередь | Следующий узел остаётся невидимым до собственного интервала; старты каждые260ms при появлении420ms, анимации перекрываются |
| Источник | Ещё не раскрытая иконка находится у ладони, не летит невидимо заранее |
| Дуги | Промежуточная поза отличается от прямой, начало/конец непрерывны |
| Ряд | Все базовые Y одинаковы; порядок соответствует заданиям, подписи не уменьшены |
| Телефон | Первое открытие после посадки всех; следующий этап открывается после результата |
| Прерывание | Drag/hidden приостанавливают расписание; ручная поза не сбрасывается |
| Сохранение | Ответы сохраняются, ручные координаты сохраняются при смене стандартной раскладки |

Визуальная самопроверка: PASS в одной обычной вкладке795×618. Поочерёдное перекрывающееся появление, кольцо и ряд фактически видны. Видеозвонок пройден до результата, второе задание открылось автоматически; крестик возвращает ряд и «Продолжить задание», повторное нажатие возобновляет этап. Console warn/error:0. Проверка через временный review не изменяет прогресс игрока.
