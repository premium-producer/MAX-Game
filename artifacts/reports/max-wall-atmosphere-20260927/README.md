# MAX: переливающаяся стена · 27.09.2026

Добавлен max-wall-atmosphere.js: процедурные складки градиента, узкий световой гребень с широким аналитическим ореолом и локальная волна пикселизации. Используется существующий низкоразмерный linear/HalfFloat underlay SurfaceField, без нового renderer, RAF, текстур или blur-проходов. MAX включает эффект в MaxSharedBackground; остальные потребители SurfaceField по умолчанию выключены. Прежние пиксельные частицы и fluid сохранены. Авторская палитра — шесть цветов project-palette.json; это проектная адаптация по запросу пользователя, не оригинальный Angular-компонент Figma.

Параметры MAX_WALL_LOOK: strength 0.85, speed 0.22, pixelPeriod 18 секунд, pixelAmount 0.48. Пикселизация локальна, мягко появляется в последней трети цикла и исчезает; текст/панели/игра не пикселизируются. Время берётся из service clock, пауза сохраняет фазу. На левом краю MAX эффект точно нулевой, затем плавно нарастает на 20% ширины; под игровым полем приглушён. Настройки общего владельца Ribbon не перезаписываются.

## Проверено

- node --check трёх изменённых JS; штатная build_service.py --preserve-native.
- 110/110 ribbon тестов; 20/21 выбранных service-тестов. Один тест surface-visual.test.mjs ожидает capability shared-flow у max-wall, которой нет в текущем registry после прежней интеграции игры. Ошибка не касается формулы шейдера; registry/server в этой задаче не изменялись. Полностью зелёный service-набор не заявляется. Логи рядом.
- Перезапущен только max-wall-right; before/after подтверждают сохранение остальных generation. HTTP SHA трёх ресурсов совпадают с runtime.
- Check.bat: пять running/Spout sending, кадры продвигаются. В коротком снимке MAX около 2.9 FPS при пяти источниках; это не изолированный замер цены эффекта. Оптимизация общей производительности остаётся открытой.
- Одна вкладка существующего presentation: яркий градиент виден и меняется между наблюдениями, панели читаются, console warn/error пустая. live-wall.png — фактический поток. Полный цикл пикселизации отдельно не записывался/не измерялся.
