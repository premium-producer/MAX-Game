# MAX: проверка оптики и углов панели

27.09.2026. [Исследование и источники](../../../docs/Research/max-glass-reliability-20260927.md). Входящие скриншоты пользователя: `codex-clipboard-9e25688b-9bd8-41bf-8841-8f585608a02b.png` и `codex-clipboard-210eaf25-54fb-4b11-a276-ef7175ad483b.png`.

## Диагноз

В прежнем shader `exp(-abs(distance)/48)` оставлял ненулевую фаску за радиусом угла 56. Внутри SDF там меняется ближайшая грань и скачком поворачивается нормаль. Это установленный дефект модели и объяснение внутренних заломов; нельзя приписать ему каждый пиксель пользовательского снимка. Общий preview уменьшается до 960 px, поэтому его увеличение дополнительно выявляет ступеньки. Проверка отдельно использовала ROI 640×480 (такое же декодированное разрешение) существующего источника.

## Исправлено

Конечный squircle-профиль и аналитическая нормаль, край плавно выходит на плоскость до medial axis. Стандартный refract и независимая слабая линза увеличения 1.08; общий offset ≤56 native px. Ослаблена цветовая тонировка 0.42→0.12, чтобы сохранить структуру фона. Направленный фиолетовый свет, нет frost/dispersion/splay. AA кромки учитывает обе оси пикселя. Всего два texture fetch, прежний RT/контекст. Сохранённые sphere shader/model, фон, игровая логика, UI и положение панелей не менялись.

## Проверено

- `node --check` двух изменённых модулей — успешно.
- 15 профильных тестов: обе геометрии, четыре угла, конечность/непрерывность, центр и симметрия линзы, нейтральный IOR, глобальные координаты и halo на 960/2048/4096/8192. `service-tests.txt`.
- 110 Ribbon тестов — успешно, `ribbon-tests.txt`.
- Выборочный builder доставил два модуля; source/runtime/HTTP SHA совпадают (`http-checks.json`). Сохранённые HTTP-модули фиксируют проверенную сборку.
- Только MAX перезапущен, четыре другие generation прежние (`before.json`, `after.json`, `generations.json`). Все пять источников running / Spout sending, Check успешен.
- Одна существующая вкладка: увеличенный фрагмент угла single, затем общий вид. Угол выглядит ровным, фон проходит через панель, меню резкое относительно разрешения видеопотока. Изменение фона линзой остаётся умеренным; сильное объёмное стекло не объявляется достигнутым. Console warn/error presentation пусты, `browser.json`. Пользовательский single сохранён.

## Ограничения

Декодированный ROI не lossless-снимок GPU/Spout. На промежуточном Check MAX 25.6 FPS; финальный Check 17.2 FPS, одновременно изменился FPS остальных источников. Это не контролируемый A/B и не доказательство ускорения/регрессии; 60 FPS остаётся открытым. В общем service log видны `Output closed` при остановке прежних исполнителей во время restart; новый источник затем running, кадры идут, error=null. Не заявляется отсутствие ошибок во всей истории мастера.

Без тяжёлого GPU-прогона, видео, дополнительного игрового процесса, проверки TD/3D/LED и переключения раскладки. Сторонние библиотеки не установлены; оптика адаптирована по документированным принципам в существующем Three.js. Portable ZIP не обновлён. Физическая полоса UI 1.00–1.80 м и художественная приёмка остаются открытыми. Git stage/commit/push не выполнялись.
