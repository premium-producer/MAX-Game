# MAX: снята блокировка выбора по траектории — 29.09.2026

Причина: safeFlightPath возвращал null, когда надутые защитные области блокировали старт/финиш/весь коридор. chooseObject трактовал это как запрет игрового выбора и показывал «Выбери иконку с другой стороны».

Исправление: placementFlightPath предпочитает обход полных областей, затем только плиток, затем прямой перелёт к месту. chooseObject больше не отказывает из-за анимационного пути. Проверка игровых доступных вариантов, сохранение после посадки и отмена пикера не изменены. Крайний прямой fallback может пересекать объекты во время перелёта; размещение самого меню и итоговых иконок сохраняет защиту.

Проверено: syntax двух JS, [245/245 CPU-тестов](tests.log), build206/76, check-local. Регрессии покрывают недостижимую область подписей с обходом плитки и полностью закрытый коридор без отказа. Одна вкладка: миссия общения с нуля, три последовательных выбора (История, Видеозвонок, Групповой чат), включая обычный click; все три иконки установлены, следующий плюс доступен, console без warning/error. [Результат](placed.png).

Локальный мастер: только MAX перезапущен, остальные поколения сохранены, Check.bat pass, HTTP bundle=runtime: [метаданные](runtime.json). В той же вкладке виден фактический стартовый поток presentation.

Без Selectel/Git-публикации, видео, тяжёлых GPU-тестов. Полный проход миссий, физический стенд/TD и художественная приёмка не проверены.
