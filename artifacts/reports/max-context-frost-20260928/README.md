# MAX: контекстный фокус и размытие UI под стеклом

Дефект: исходная и popup-иконки рисовались одновременно (двойной badge), а Frost затрагивал только фон/волокна. Соседние глифы/подписи оставались резкими поверх матовой карточки.

objectContextPresence общий для foreground/background/fiber masks. Переход200мс через существующий render-loop: выбранный исходный объект0, остальные0.45, popup1. ANSWER не сбрасывает фокус. При закрытии исходный объект возвращается, общий фон/связи не затемняются.

JourneyContextGlass рисует UI под попапом в один ленивый переиспользуемый RGBA8+mip target размера drawing buffer, фильтрует внутри4максимум контекстных масок (две зоны: инструкция+телефон), затем sharp popup. За пределами маски — raw UI. Premultiplied RGB/alpha фильтруются совместно, linear→sRGB один раз; readPixels/нового renderer/RAF нет. Без popup target не выделяется и проход пропускается; resize/reuse/dispose покрыты тестом. Дополнительная памятьRGBA8 с mips ~4.9MB при1280×720; это расчёт, не измерениеGPU.
