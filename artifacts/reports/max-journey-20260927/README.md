- Service: 13/13 профильных проверок оптики/worker. [Лог](service.txt). Ribbon: 110/110. [Лог](ribbon.txt).

- Удалённый ввод через штатный /api/pointer: down/up приняты, CTA сменился меню в реальном видеопотоке.
- В одной браузерной вкладке: standalone CTA → меню → блогер → объект → оба этапа → успех; добавление второго объекта и связи. В service=1/two проверены независимость зон, длинная миссия ID, контекстный пикер, окно задания. DOM-границы текстов/кнопок меню и задания находятся в Y615…1020, переполнение карточек не обнаружено. ## Практические границы

Короткие проверки, без видео, тяжёлой GPU-нагрузки и новой аппаратной калибровки. Приём TD, физические LED/LiDAR и художественное утверждение не подтверждены. Standalone имеет CSS fallback стекла, мастер — shader refraction. Задания — игровые демонстрации без реальных действий в MAX; граф декоративно-смысловой, не валидатор линейного маршрута. Перемещение/удаление уже поставленных объектов не включено в текущую механику.
