# Проверка плагина готовых скриншотов MAX — 28.09.2026

Обновление: размещение перенесено на текущую страницу, комплект выдаётся папкой без нового архива. Сборка, node --check и7 тестов прошли. Дополнительные проверки подтверждают отсутствие создания/переключения страницы, отступ240px от существующих render bounds, повторный импорт справа, сохранение названия/объектов и исходной страницы при переключении во время загрузки шрифта. Живой Figma по-прежнему не проверен.

Комплект: `artifacts/DESIGN/figma-plugins/max-client-screens/`. 84 фактических скриншота клиентской страницы. Плагин игр/сцен не генерирует, текущую версию игры не включает.

Проверено: сборка; node --check готового code.js, сборщика и исходников; парсинг JS внутри ui.html; 5 Node-тестов (pass). Тесты сверяют все встроенные изображения побайтно, 20 основных состояний, девять сочетаний размера/числа колонок, отношения сторон, границы и отсутствие пересечений; исполняют полный импорт 84 кадров на модели Figma API и проверяют отмену/поздние сообщения, повторный запуск, ошибку шрифта и сохранение чужой страницы. Первый запуск Node с изоляцией получил sandbox EPERM; штатный --test-isolation=none прошёл.

Выявлено: исходные файлы с расширением .png фактически JPEG (22 по 1280×720, 62 по 911×591). Импорт сохраняет их байты, распознаёт реальный формат и не обрезает кадры.

Реальное исполнение Plugin API в Figma и визуальное расположение на живом холсте не проверены. Автоматические проверки используют модель API, не подменяют эту проверку. Без изменений приложения, запуска мастера, видео, тяжёлой нагрузки, Selectel и Git-публикации.
