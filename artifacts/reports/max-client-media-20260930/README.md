# Проверка интеграции контента MAX — 30.09.2026

Требование: заменить заглушки подходящими доступными материалами, включая сюжетные сцены ID; отмечать неполные миссии в меню. [Действующий контракт и таблица покрытия](../../../apps/max-game/docs/CONTENT_MEDIA.md).

## Реализация

Подключены111 исходных PNG (32.8MiB), включая шесть дневных кадров с Мишкой, сцены звонков/сообщений/историй, комментарии и статистику, горизонтальные бизнес-экраны и клиентский пример доставки. Оригиналы копируются с SHA, размерами и Figma node ID; не обрезаются/не перерисовываются. Прежние native SVG создания ID сохранены. Видеофайлов этих сценариев не найдено: исходные состояния показываются кадрами, пары ID заменяют прежнюю запросную анимацию.

Общий registry используется всеми редакциями. Галерея не изменяет ответы и прогресс, переход использует прежний clock/retained WebGL foreground. Сначала decode, затем переход с проверкой живого владельца. Крупные действия Guided находятся рядом с телефоном; лишние шапки внутри кадра убраны. Для горизонтальных кадров contain, без растягивания.

Полные: блогер, ID, тестовая льгота. Частичные: общение (группа, стикеры/реакции), бизнес и тестовый бизнес (пост/расписание, принятие заказа, товар/витрина). Клиентский пример изменения доставки отображается, но не выдаётся за принятие заказа. Меню охватывает все бизнес-ветки. Исторические заглушки «АНИМИРОВАНАЯ СЦЕНА ???» заменены конкретным названием отсутствующего материала.
