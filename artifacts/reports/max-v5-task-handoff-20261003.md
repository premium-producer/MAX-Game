# MAX v5 — переход между заданиями, 03.10.2026

## Результат

Только v5: подтверждённое следующее задание запускает unlink → exit → pack → trace → enter → link. Сначала исчезает веер связей от старой иконки к устройству; после нулевой видимости уходит устройство. При скрытом устройстве активируется новый descriptor, сбрасываются временные смещения иконок и начинается их перестроение. Входящая связь следующего задания скрыта до завершения основного движения. Затем она раскрывается; подготовленный экран появляется; после его появления строится новый веер связей. Ответы разрешены по завершении последовательности.

Ширина телефона/PC продолжает плавно меняться внутри одного задания по предыдущему контракту. Между заданиями новый размер назначается у скрытого устройства. Итоговый QR и сохранение финальных поз не изменены.
