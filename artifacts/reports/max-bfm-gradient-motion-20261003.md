# MAX BFM — вращение градиентов, 03.10.2026

Реализовано в четвёртой версии: слой заливки квадратных плиток (ладонь и иконки) вращается средствами Web Animations API. Фаза случайная0…360°, скорость30°/с с независимым разбросом ±15%. Семантический ID сохраняет выбранные случайные значения при пересоздании плитки в текущем открытии страницы. Цвета прежней заливки сохранены.

Панель «Градиент кнопок» внизу справа: скорость5…90°/с, разброс0…35%, пауза. Изменение скорости использует updatePlaybackRate; фаза не задаётся заново. Hidden/reduced motion приостанавливают вращение; возврат продолжает текущую фазу. Рисунок/подпись/зона ввода не вращаются. Собственного RAF для градиентов нет. Прямоугольные кнопки меню сохраняют прежний вид.

PASS: node --check двух изменённых модулей; duplicate guard; локальная сборка80 модулей; [HTTP200/SHA для HTML/JS/CSS](max-bfm-gradient-http-20261003.json). Браузерный обход, GPU-профилирование и видео не проводились. Нативная плавность/композиция ждут пользовательского отзыва; тесты mock-анимации не добавлялись как недоказательные для этой визуальной правки.

[Исследование](../../docs/Research/max-bfm-gradient-motion-20261003.md). Мастер, предыдущие версии, backend и текущий фон не менялись. URL: http://localhost:8770/max-game/bfm-design/?backend=local&layout=wall

Проверка пользователем: удержать ладонь и посмотреть разные фазы раскрытых плиток; изменить скорость/разброс в панели; включить и выключить паузу. Ожидается непрерывное вращение заливки без вращения знаков и сброса фазы при регулировке.
