# MAX — горизонтальный пиксельный флюид, 27.09.2026

Причина: диагональный gate локальной пикселизации и независимое широкое облако shared density. Теперь две горизонтальные дорожки с небольшими изгибами по Y и движущимися пакетами по X определяют ambient density, локальный свет и периодические пиксели. Форма задаётся до cell emergence и bloom. Исходный underlay, объёмные ячейки, игровая сцена и depth-силуэты сохранены; у стыка плавно остаётся исходное общее поле. Дополнительных RT/renderer нет.

Правила MAX: проектная палитра шести цветов из project-palette.json; процедурная адаптация, не оригинальный Figma Angular. Логотипы/шрифты/игровые цвета не менялись.

Проверено: node --check обоих JS; штатная сборка Stand Service; 110 Ribbon + 18 выбранных service тестов (все прошли). HTTP SHA-256 обоих модулей совпали с runtime. MAX перезапущен для загрузки изменения, другие generation сохранены (before/after.json). Финальный Check: все пять источников running/Spout sending, продвижение кадров; MAX около 3.3 FPS при общей нагрузке. В одной существующей вкладке presentation видны узкие горизонтальные пиксельные полосы, три круга и сохранённая подложка. Консоль страницы без warn/error; live-horizontal.png — финальный поток.

В журнале при смене процесса были Output closed / UnknownVizError; последующая регистрация Spout и продвижение потока подтверждены. Без утверждения, что общий журнал полностью чист. 3D и приём TD повторно не проверялись, аппаратной/художественной приёмки и нагрузочных прогонов нет. Полный цикл эффекта отдельно не измерялся. Игровая память сброшена штатным перезапуском источника. Полный master portable ZIP не обновлялся.
