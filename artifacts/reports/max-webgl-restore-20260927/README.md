# Восстановление оформления MAX · 27.09.2026

По уточнению пользователя отменён широкий редизайн 0.2. Восстановлены активные main.js, styles.css/max-theme.css, исходный Three.js renderer, панели слева/справа/внизу, переходы, glow, волновые линки и частицы. Земля/атмосфера/звёзды скрыты, её текстуры не декодируются; окклюзия и сферический hit-test отключены. Пронумерованные действия, четыре клиентских сценария и бизнес-ветки сохранены. Координаты переводятся на плоскость z=0 с фиксированной камерой.

Контент адаптируется сборщиком из client-missions.json в client-webgl.json, отдельная копия текстов вручную не поддерживается. Активная policy принудительно screenProjected: первая живая проверка выявила наследование старого hybrid-default (географический расчёт ground-связей); это исправлено и закреплено регрессией. Remote cancel также отменяет drag из инвентаря.

## Проверки

- 112/112 тестов MAX и service max-game*, включая четыре клиентских маршрута, отсутствие Земли в preload/окклюзии, действующий entry, palette, pointer, runtime SHA. Лог tests.txt. Часть старых тестов проверяет сохранённый движок/отменённый прототип; не выдаётся за живую проверку всех сценариев.
- 110/110 ribbon-тестов, node --check изменённых JS, check:local: 560 upstream-файлов неизменны; 176 runtime-файлов, 55 модулей; внешняя директория X-Спутника не использовалась.
- Сборка штатная. Перезапускался только max-wall-right; четыре остальных generation сохранены (before.json/after.json). Check.bat подтвердил running/Spout sending у пяти источников. HTTP app.js/client-webgl.json/max-theme.css совпадают с build-manifest SHA.
- Одна вкладка живого presentation через localhost, без отдельного игрового процесса. Меню, прежние панели и прозрачная композиция на общем фоне видны. После финального исправления первая миссия пройдена реальными тапами: A → 1 → 2 → 3 → Б, светящиеся линки и popup «Маршрут собран» подтверждены. Снимок live-webgl.png. Console warn/error presentation отсутствуют.

## Ограничения

Это короткая функциональная проверка, не нагрузочная или художественная приёмка. Короткий Check после загрузки показал MAX около 5.7 FPS при пяти источниках. Target 60 FPS не подтверждён; совместная производительность стенда остаётся открытой задачей. Повторный 3D-walk и TD/аппаратный приём в этой задаче не проверялись. Полное прохождение всех веток живым вводом не выполнялось, CPU-каталог проверен. Нет видео, Git-публикации или новой portable ZIP-сборки. Исходные Earth-ассеты пока входят в portable public-набор, хотя плоский renderer их не загружает.
