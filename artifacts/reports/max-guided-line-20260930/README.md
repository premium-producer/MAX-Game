# MAX: смартфон в маршруте — 30.09.2026

Отдельная локальная версия [guided-line](http://localhost:8770/max-game/guided-line/). [Действующий контракт](../../../apps/max-game/docs/GUIDED_LINE.md).

## Техническая проверка — PASS

Сборка: 212 runtime-файлов, 88 скомпилированных модулей. Проверка дубликатов, синтаксис изменённых JS/MJS и штатный check-local прошли. 81 CPU-тест Guided, нового контроллера, связей, движения и переходов прошёл: все 6 миссий, 3 бизнес-ветки, независимые сохранения, свободные координаты телефона, восстановление следующего узла, 5 отдельных портов/ключей и отмена смены содержимого.

Одна браузерная вкладка, обычный viewport 1280×720 и логическая геометрия стены 1760×1024. Использован явно подписанный review-fixture без сохранения прогресса. Подтверждены один телефон в поле, отсутствие его копии в поп-апе, 5 входящих и 5 исходящих связей, ответы блогера и переход к общению, действующие ID-hotspots, перетаскивание телефона при открытой инструкции, закрытие снаружи и продолжение задания. Центр телефона после drag изменился с (640,360) на (715,400), без изменения режима истории; связи сохранились 5/5. Прежний Guided сохранил один телефон по центру (640,360); обычная новая страница без review открывает меню и начальный плюс «Открыть MAX». Console warn/error отсутствуют. SHA runtime/HTTP для HTML, CSS и guided-app.js совпали; CSS также совпал с исходником.

При проверке исправлены три дефекта: сохранённая WebGL-группа не подхватывала новое содержимое телефона при полной перестройке; прозрачный слой инструкции перехватывал ввод телефона; длинная подпись ладони попадала в нижний край. Смена содержимого теперь меняет версию группы, ввод проходит к телефону вне видимых панелей, а до первой возможности используется центральный ряд. Отмена content-перехода восстанавливает прозрачность от текущего значения. Повторный просмотр обычного старта подтвердил полный текст ладони.

## Визуальная самопроверка — PASS в браузере

[Кадр ID](line-id.png): телефон находится внутри композиции пути, пять широких пучков подходят к разным точкам грани и выходят к продолжению. Инструкция отдельно слева, исходный экран ID сохранён. Проверены отображение следующего задания и крупные подписи. Динамика просмотрена при обычном взаимодействии; это не нагрузочный тест и не измерение FPS.

## Утверждение пользователем — ожидается

Новая версия не назначалась источником мастера и не публиковалась. Физическая читаемость, Hokuyo, производительность стены и новый результат Spout→TD не проверялись: для них требуется отдельный просмотр на стенде. Общие фон, флюиды и контракты заднего экрана не изменены. Штатный мастер запущен через STARTUP, прежние назначения сохранены.
