# MAX: устранение растяжения конечного кадра — 29.09.2026

Пользователь подтвердил URL http://localhost:8770/max-game/client/. Предыдущая SVG-интеграция исправила источник, но пропустила ограничение конечного framebuffer. При окне2560×1440 оба canvas имели1600×900; игровой интерфейс увеличивался в1,6раза. Это наблюдалось напрямую через DOM dimensions. Тест проводился в одной вкладке, один контрольный viewport2560×1440, без нагрузочного прогона.

## Исправление

journey-main.js использует существующий MAX_DRAWING_BUFFER_PIXELS=3840×2160 вместо переопределения1600×900. Логическая геометрия и сохранения прежние. При том же окне UI-canvas теперь2560×1440. Декоративный фон сохраняет1600×900; service остаётся4096×1280. Другие фильтры/эффекты/мипмапы не менялись. На очень больших окнах/DPR действует защитный предел8,29Мп.
