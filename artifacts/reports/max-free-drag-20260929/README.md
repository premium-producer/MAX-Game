# MAX: свободный drag при сборке — 29.09.2026

Причина: onCommit до playing разрешал только SWAP, любой другой drop возвращал старую позицию. MOVE в reducer запрещался, а arrangeRoute перезаписывал координаты. MAX дополнительно исключался из drag.

Исправление: MOVE во всех клиентских фазах; freePosition в runs/starts, restore, замене и swap. planningLayout сохраняет ручные позиции. Пустой drop обновляет существующий DOM без обратной анимации/пересоздания плитки. Swap только при попадании центра в центральные60% фактической плитки. Сопротивление у границ убрано; ограничение самим игровым полем сохранено.

Проверки:

- node --check трёх изменённых JS;253/253Node-теста — tests.log.
- Штатная сборка206files/79modules; check-local PASS.
- Одна вкладка localhost: миссия бизнеса, перенос MAX, выбор канала первым (ошибочный порядок), перенос канала в пустое место, добавление финального бизнес-аккаунта. Оба объекта остались в ручных позициях; старых пустых плиток после drop не видно. Console error/warn: пусто.
- После reload и повторного входа позиции сохранены: MAX(0.7951256603,0.1476543789), канал(0.1911024418,0.3570626245). Красная связь не исправляла выбор пользователя.
- Локальный MAX worker перезапущен штатным API; HTTP app.js совпадает с runtime — runtime.json. Check.bat: пять running/Spout sending, MAX26FPS.
