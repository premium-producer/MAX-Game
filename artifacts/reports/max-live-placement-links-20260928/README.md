# MAX — связи во время появления объекта, 28.09.2026

Причина задержки: syncScene учитывал только объекты reducer, а PLACE коммитился после arrived. Выбранная движущаяся плитка отсутствовала в visual-network весь перелёт.

placingObject теперь отдаёт единственный выбранный flight своей зоны. syncScene добавляет его текущий центр в сеть сразу, с постоянным semantic id. Остальные варианты меню не подключаются. При PLACE тот же id переходит установленному объекту; существующий linksByKey сохраняет геометрию и фазу частиц. Семантический прогресс по-прежнему записывается после посадки. Отмена убирает preview; стандартное затухание renderer убирает его рёбра, не оставляя отложенный PLACE.

Дальность Journey —7 размеров плитки:532logical px на стенде,756 standalone. Последние18% дальности дают smoothstep-ослабление. nearestLinks выбирает ближайший ациклический лес среди доступных пар, без принудительных дальних соединений. Позиции обычных объектов для топологии исключают декоративный bob; визуальные концы волокон всегда следуют реальной позе. Новых GPU-проходов/RT/RAF нет; существующий renderer плавно проявляет/убирает рёбра.
