# MAX — уточнения текста и переходов, 07.10.2026, R2

Локальная клиентская и стендовая сборки обновлены. Сервер клиента продолжает работать на http://localhost:8785/webgl-v5/client.html. Стенд и опубликованные страницы не изменялись.

1. Пробел перед «Цифровым ID» сохраняется. Подпись каждой кнопки имеет одного владельца раскладки, вместо отдельных flex-колонок для обычного текста и защищённого термина.
2. Подписи кнопок переносятся обычными строками. Все русские склонения Цифрового ID сохранены.
3. Старое сопровождение остаётся на плашке до конца затухания. Новое вставляется ровно один раз при нулевой прозрачности вместе с соответствующим экраном телефона, затем плавно появляется. Используются существующие часы перехода. Отмена/перезапуск/новый экран отклоняют устаревшую замену; ожидание медиа и пауза не ускоряют появление.
4. В сообщении «А теперь отправим сообщение! Выберем формат…» слово «Выберем» начинает следующую строку.
5. В завершении миссии общения «общения в MAX.» переносится целиком на следующую строку.

Каталог, contentRevision, ID, исходный flow и подтверждённый прогресс не менялись. Переносы являются оформлением текста.
