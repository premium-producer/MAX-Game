## Реализация

- Названия/описания игровых миссий и заданий актуализированы; «Общение на максимум».
- ID: нулевой этап create-id открывает три применения — hotel, benefit, age. Проверка зависимости на уровне reducer, а не только скрытия пунктов меню.
- Business: sector → account → явный branch. У нового пользователя нет неявно выбранного канала. В круговом меню выбирается канал/бот/мини-приложение; остальные задания не обходят prerequisites.
- Выбор сферы, голосового/видео и стикера/реакции записывается в answers, меняет следующий экран, проходит валидацию при restore.
- Старые позиции сохранены; недостоверное зависимое завершение сбрасывается. Автоматический branch старой сессии не принимается за выбор без размещённого инструмента.
- Результат миссии берётся из client-missions.json: удалён второй неиспользуемый словарь RESULTS. WebGL-попапы/анимации сохранены, смена инструмента использует локальный transition.
