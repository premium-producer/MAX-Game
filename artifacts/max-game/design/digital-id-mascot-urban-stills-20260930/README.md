# MAX — Мишка и Цифровой ID, дневная городская серия

Актуальный комплект по уточнениям пользователя30.09.2026. Шесть отдельных PNG, по два на сюжет. Маскот взят из [исходного референса](mascot-reference.png). Первая сцена — подход ко входу с крупной вывеской, вторая — предъявление ID человеку. Это заменяет прежнюю схему с героиней «предъявление → результат».

| Сюжет | Кадр1: подходит | Кадр2: показывает ID |
|---|---|---|
| Отель / hotel | [ОТЕЛЬ](hotel-01-arrival.png) | [У стойки отеля](hotel-02-present-id.png) |
| Льгота / benefit | [МУЗЕЙ](museum-01-arrival.png) | [Сотруднику музея](museum-02-present-id.png) |
| Возраст / age | [МАГАЗИН](age-01-arrival.png) | [На кассе](age-02-present-id.png) |

Дневной urban: светлый бетон/камень, стекло, нейтральный свет, небольшие фиолетовые акценты MAX. Ночной неоновый вариант отвергнут пользователем. Нейтральные материалы и естественная внешность сотрудников — последнее прямое уточнение; не переносить шестицветную палитру UI на цвет человеческой кожи и реальных материалов.

Мишка идёт к дверям, а не от них. Во вторых кадрах обычные взрослые сотрудники: мужчина у стойки отеля, женщина среднего возраста в музее, женщина на кассе; естественная кожа, спокойные жесты, повседневная одежда. Маскот без одежды, с исходными отличительными признаками: коричневая шерсть, кремовые морда/живот, короткие лапы, большие сине-фиолетовые глаза, округлые уши и центральный хохолок.

Это генеративные стилшоты по модели-листу, не рендер исходной3D-модели. Точное геометрическое совпадение и числовые размеры не доказаны. QR условный, портрет маскота; не официальный интерфейс MAX. Подписи/действия задания остаются отдельным текстом. Создание ID сохраняет клиентские SVG.

[Промпты](prompts.json), [оригиналы генераций](origins.json), [размеры и SHA](manifest.json), [самопроверка](REVIEW.md). PNG скопированы без изменения и искусственного увеличения. Оригиналы и предыдущие варианты сохранены. Runtime не подключён, мастер/серверы не менялись, публикации нет.
