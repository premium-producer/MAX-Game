## Новое указание пользователя

- Тап по пустому месту поля открывает локальный пикер иконок возле этой точки, как альтернативу постоянному боковому inventory X-Спутника.
- Выбор смысловой иконки размещает объект в выбранной точке свободного 2D-поля. Номера больше не заменяют пиктограммы.
- У установленного объекта может быть задание. Маркер уведомления обозначает доступное задание; тап по объекту открывает инструкцию и условный интерфейс приложения.
- После выполнения действия объект получает состояние выполнения. Общий успех требует выполнения задач миссии; одна расстановка/связность не должна выдавать такой успех.
- Связи сохраняют WebGL-волокна и изгибы; их вид не задаёт обязательную последовательность по горизонтали. Точные правила необходимости связей и зависимостей задач уточнить при переносе сценария в код, не считать изображённый граф алгоритмом валидатора.
- Весь обязательный текст и hit-target остаются внутри физической полосы1.00–1.80м на прямом участке; независимость two/single зон сохраняется. Пикер у края должен смещаться внутрь полосы, не уходить за неё; закрытие окна возвращает на то же поле.

## Источники и статус

Пользовательские референсы сохранены в ../../incoming/object-context-menu-reference.png, object-task-reference.png и object-notification-reference.png. Сценарий: ../../incoming/Пользователь_VK_MAX13.md и ../../public/config/client-missions.json. Бренд: ../../../DESIGN/BRANDS/MAX. Сгенерированные иконки — образцы семантики; для runtime нужны согласованные векторные ассеты и реальные брендовые шрифты/токены.

Изображения показывают увеличенную рабочую область, а не полный физический экран. Точный HEX, оптика, Max Sans и геометрия1–1.8м генерацией не гарантируются. Использовать изображения как визуальное предложение, не готовую LED-текстуру. Небольшие отличия формы пиктограмм/плашек между кадрами нормализовать в компонентной реализации. Все12PNG проверены по наличию, формату и размеру; просмотрены при генерации на смысловые иконки, наличие task overlay и completed badges. Пользовательская художественная приёмка не заявлена.

Изменены только макеты и проектный контекст. Runtime игры всё ещё использует прежний inventory/числовые узлы и критерий маршрута; новая механика в нём не реализована. Мастер не перезапускался.
