# MAX — стилшоты применения Цифрового ID

Этот вариант с героиней заменён последним уточнением пользователя: [актуальная дневная серия с маскотом](../digital-id-mascot-urban-stills-20260930/README.md), «подходит → показывает ID». Предыдущие файлы сохранены для истории.

Сгенерировано 30.09.2026 встроенным imagegen: три сценарные анимации заменяются парами статичных кадров по запросу пользователя. Единая героиня, одежда и фотостиль.

| Сцена / задание | Кадр 1 | Кадр 2 |
|---|---|---|
| Отель / `hotel` | [Предъявление ID](hotel-01-present-id.png) | [Получение ключа](hotel-02-check-in-complete.png) |
| Студенческая льгота / `benefit` | [Подтверждение статуса](museum-01-confirm-student-status.png) | [Льготный билет](museum-02-discount-ticket.png) |
| Возраст / `age` | [Предъявление ID на кассе](age-01-present-id-at-checkout.png) | [Проверка завершена](age-02-verification-complete.png) |

Кадр1 — предъявление, кадр2 — подтверждение/результат. Это иллюстрации физических сцен; QR условные. Подписи/действия остаются в игровом интерфейсе. Исходные экраны Figma создания ID и добавления фото сохраняются.

PNG941×1672 или948×1659, без масштабирования/перерисовки. При интеграции сохранять пропорции. [Промпты и референсы](prompts.json), [размеры и SHA-256](manifest.json). Оригиналы генераций сохранены.

Все шесть кадров просмотрены: сюжет, герои, руки/предметы и согласованность пар. Художественное утверждение пользователем отдельно. Подключение к runtime ещё не выполнено; мастер, сборка и серверы не изменены.
