# Наполнение MAX site-game — карта первого этапа

**Дополнение 02.10.2026:** актуальные [общие правки клиента](../../../apps/max-game/docs/MISSIONS.md#общие-правки-клиента--дополнение-02102026) заменяют часть маршрутов этой карты: групповой чат исключён; бизнес — сфера → платформа/верификация → канал и новости → бот → мини-приложение/витрина, все инструменты последовательно, без создания бизнес-аккаунта. Таблицы ниже пока сохраняют прежнее сопоставление ассетов; выбор одной ветки и расположение сферы после платформы более не являются требованиями. Исполняемый каталог ещё не обновлён под это дополнение. Прочие экранные правки и открытые вопросы собраны в том же своде.

02.10.2026. Рабочая карта для переноса контента в новую игру; **ещё не подключена к runtime**. Основа — [комментарии клиента](../../DESIGN/max-game/max-review.json), исходные [медиа](../public/assets/client-media/sources.json), [сценарии клиента](../src/journey-client.mjs), [создание ID](../src/journey-id.mjs). Более поздние уточнения пользователя имеют приоритет над комментариями и прежним планом.

## Зафиксированные решения

- «Реальный интерфейс» в комментариях 1949283636/1949284692 означает исправление экрана **на телефоне в лапах Мишки**, внутри сюжетной фотографии. Это отложено в общий бэклог. Не добавлять новые интерактивные шаги ID к сюжетам, не заменять фотографии скриншотами.
- Отель/музей/магазин сохраняют две фотографии и два действия: «Далее» → действие через ID → результат.
- Голосовое, затем видеосообщение — обязательная последовательность внутри одного узла «Сообщения», без выбора одного из двух форматов.
- Бизнес: платформа/верификация → сфера → инструмент → выбранная ветка. Бизнес-аккаунт не отдельный обязательный узел. В тестовом бизнесе ID исключён.
- Отсутствующие оригиналы показываются как явный пробел. «Пропустить недоступный шаг» внутри устройства не даёт зачёт. Итог различает выполнение и просмотр с пропусками.
- В правой плашке только информация, без повторяющихся заголовков и действий. Нажатия — на элементах показанного интерфейса; запасной вариант — одна кнопка под изображением внутри устройства. Варианты ответа могут иметь несколько кнопок. Стрелок/счётчиков кадров нет.
- Подтверждённый визуал новой версии сохраняется, включая последние изменения прозрачности и blur узлов 12 px. Старые игровые шейдеры/плашки не переносятся вместе с контентом.

В таблицах числовой ассет N — `../public/assets/client-media/frame-N.png`; SVG ID N — `../public/assets/digital-id/create-N.svg`. «Есть» означает файл существует, а не что этап уже работает в site-game. «Сверить» означает, что нужен просмотр конкретного кадра перед переносом; он не может быть автоматически засчитан по имени файла. Переходы по умолчанию идут к следующей строке задания, если не указан выбор или результат.
