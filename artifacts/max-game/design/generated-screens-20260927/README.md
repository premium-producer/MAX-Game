Это художественные растровые концепты 1536×1024, не экспорт работающего UI и не точная LED-развёртка. Визуально проверены названия, количество и порядок узлов, замкнутость цепочек и статусы результата. Генератор не выдержал заданную вертикальную полосу пиксельно: часть заголовков выше целевых49% высоты. Поэтому нельзя назначать PNG напрямую на реальный экран и объявлять правило1–1.8м выполненным. При реализации размещать живые элементы по действующему INTERACTION_BAND615…1020 в circle-model.mjs, использовать настоящий Max Sans и брендовые токены; интенсивность обводок дополнительно сверять с guideline. Точная колориметрия/оптика и аппаратная приёмка не заявляются.
