# MAX — Открой возможности

CTA, четыре клиентские миссии, свободное размещение смысловых иконок, учебные задания объектов и общий финал. В мастере — одна или две независимые зоны правого экрана; интерфейс в полосе1–1.8м.

Мастер: apps/STARTUP/Start.bat, Check.bat, Stop.bat; http://localhost:8770. Standalone через работающий мастер: http://localhost:8770/max-game/ . Публичная игра: https://futuronika.pro/vk/max-game/ .

Сборка из корня: node artifacts/max-game/scripts/build.mjs.
