Как создать канал

Для тех, кто хочет вести свой канал на широкую аудиторию

  1. Убедитесь, что у вас подключён Цифровой ID
  2. Откройте список чатов и нажмите «+»
  3. Выберите «Создать канал»
  4. Добавьте название, описание и фото канала, нажмите «Создать канал»
  5. Выберите тип канала «Публичный»
  6. Введите желаемый никнейм — убедитесь, что он свободен
