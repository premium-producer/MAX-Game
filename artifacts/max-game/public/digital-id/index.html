Цифровой ID
вместо бумажных документов

Подключите Цифровой ID в мессенджере MAX, чтобы подтверждать возраст, льготный статус, а также всегда иметь доступ к основным документам: от паспорта до водительских прав

Как создать Цифровой ID

Чтобы создать Цифровой ID:

  1. Зайдите в раздел Цифровой ID в настройках и нажмите «Создать QR»
  2. Далее нажмите «Добавить документы»
  3. Включите вход по лицу или отпечатку пальца для безопасности данных
  4. Перейдите в Госуслуги для подтверждения

Как использовать Цифровой ID?

Чтобы воспользоваться Цифровым ID:

  1. Откройте настройки в MAX
  2. Выберите «Цифровой ID»
  3. Предъявите QR-код на кассе или покажите его сотруднику

QR-код действует только на вашем устройстве и обновляется каждые 30 секунд, чтобы им не мог воспользоваться никто, кроме вас
