# Исходные материалы X-Спутника

Локальный снимок для разработки MAX: `app/` содержит все исходные WEB-модули, редакторы, public, тесты, сборщики, package/lock и запуск исходного приложения; `skills/` — 13 исходных web-skills с ресурсами. [Manifest](manifest.json) фиксирует пути, размеры и SHA-256 всех 560 перенесённых файлов, включая документы и референсы в Research.

Это материал для сравнения и переноса функций. Рабочий MAX находится на уровень выше; его запуск/сборку определяют [актуальные инструкции](../../../apps/max-game/docs/DEVELOPMENT.md). Старые launcher и sync-assets автоматически не запускаются. Старые брендовые ассеты остаются только в этом снимке и не попадают в MAX runtime.

Документы, история и пользовательские референсы: [локальные источники](../../../docs/Research/x-sputnik-max-game-20260926/sources/README.md). Активный [skill разработки MAX](../../skills/max-game-development/SKILL.md) учитывает изменения бренда, версий API и текущие правила проверки. Исторические AGENTS не действуют в нашем проекте.

Исходный каталог X-Спутника для дальнейшей работы не нужен. Поле sourceRootHistoricalOnly — происхождение, а не вход сборки. Исключения: чужая инфраструктура/VPS/доступы, TD, node_modules, сгенерированные сборки, резервы и временные данные. Полный WEB public сохранён, поэтому исходные визуальные материалы доступны локально.
