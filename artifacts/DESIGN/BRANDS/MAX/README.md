## С чего начинает агент

1. Прочитать [brand.json](brand.json): версия, область применения, ограничения.
2. Взять нужные правила из [rules.json](rules.json). 41 правило: 39 сверены с источником, 2 содержат противоречия. У каждого есть `frameId`, `nodeId`, исходный текст; `source-verified` означает проверку по источнику, а не одобрение владельцем бренда.
3. Найти ассет в [asset-index.json](asset-index.json), использовать готовый файл. Не рисовать логотип заново и не набирать его текстом.
4. Подключить [tokens/brand.css](tokens/brand.css) или прочитать [tokens/brand.tokens.json](tokens/brand.tokens.json). Не менять сгенерированные значения вручную.
5. Для спорного требования открыть конкретную страницу через [source-index.json](source-index.json), затем её SVG/PNG/JSON в исходном экспорте. Индекс содержит все 586 текстов; загружать весь 51-МиБ атлас для каждой задачи не требуется.

Процедура применения и проверки: [max-brand](../../../skills/max-brand/SKILL.md). Подготовка следующего бренда: [brandbook-ingest](../../../skills/brandbook-ingest/SKILL.md).

Шрифты взяты из уже предоставленной проекту папки `BRANDS/Fonts/Max Sans/WOFF2`. Лицензия не исследовалась. Логотипы извлечены из оригинальных SVG с сохранением зависимостей, масок и эффектов; происхождение и SHA-256 записаны в индексе.


Сохранять соседство `tokens/` и `assets/`, поскольку CSS использует относительные пути. В runtime копировать нужные файлы штатной сборкой приложения; не делать зависимости от `D:/...` или папки сырого экспорта.

## Ограничения

- В выборке есть главы 1–5. Указанные в оглавлении главы о маскоте и 3D отсутствуют.
- «Синий гигант»: HEX `#471AFF`, RGB `26 75 255` и заливка около `#1A4BFF` расходятся. Синий и дополнительные градиенты, зависящие от него, не включены в CSS.
- Единица охранного поля монохрома в тексте и схеме противоречива. Не вычислять её буквально по спорному множителю. Охранное поле макета и межбрендовые отступы — разные правила.
- Angular и Glass Effect пока не перенесены в рабочие веб-компоненты. Main-полоска в proof — образец линейного градиента, не замена этим эффектам.
- Анимации, After Effects и некоторые мастер-компоненты представлены ссылками; их содержимого в экспорте нет.
- Правила CTA относятся к коммуникационным макетам. Они не задают универсальные размеры кнопок приложения. Шрифты SF Pro/Roboto из примеров не объявляются фирменными.
- `proof.html` проверяет ресурсы, а не является утверждённым рекламным макетом. Полная визуальная идентичность оригиналу Figma не проверялась.

## Обновление

Редактируемые входы: `curation.json` и `rules.json`. `curation.json` фиксирует конкретный SHA-256 атласа, вручную сопоставленные SVG-группы и узлы, выбранные ассеты. После нового экспорта сначала повторить исследование изменившихся правил и происхождения; не подменять хеш ради обхода проверки.

Из корня проекта, Python 3.10+ без дополнительных пакетов:

```powershell
python -B artifacts/DESIGN/brand-tools/inspect_export.py "artifacts/DESIGN/figma-exports/MAX - 2026-09-26_17-35-42" --report artifacts/reports/max-brand-pilot-20260926/export-audit.json --index artifacts/DESIGN/BRANDS/MAX/source-index.json
python -B artifacts/DESIGN/brand-tools/prepare_brand.py artifacts/DESIGN/BRANDS/MAX
python -B artifacts/DESIGN/brand-tools/test_brand_tools.py
```

Инспектор универсален для Frame Archive v2. Подготовщик — ограниченный пилот для явно заданных SVG-групп, копирования файлов, HEX-цветов и линейного градиента с единичной матрицей. Для бренда с иной структурой нужны новые преобразования, а не фиктивное заполнение полей MAX.
