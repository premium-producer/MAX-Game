# Готовая карточка официального сайта MAX

Выделена из [go.max.ru/brandbook](https://go.max.ru/brandbook),01.10.2026. Это существующий блок сайта, а не придуманный аналог и не отдельный опубликованный UI-kit.

- `card-source.html` — точный фрагмент первой карточки раздела логотипа.
- `card-source.css` — исходные верхнеуровневые правила карточки, responsive wrappers и полные keyframes.
- `brandbook-map.png` — оригинальное изображение.
- `source.json` — хеши, зависимости и ограничения интеграции.

Стили содержат крупные скругления, тонкую полупрозрачную кромку, мягкое орбитальное свечение8s, hover/focus и адаптивные варианты. Данный эффект работает через CSS без Svelte runtime. Исходные scope-классы сохранены. Подключение требует локального пути картинки, переменных темы/шрифта и размеров контейнера. Responsive wrappers могут содержать соседние правила сайта: перед включением в общее приложение сузить область действия.

Для игры нужна явная адаптация: hover заменить согласованными touch/contact-состояниями, убрать прямое переключение opacity, учесть reduced motion и проектную палитру. Анимацию `left/top` оригинального сайта не переносить автоматически в игровой motion pipeline. Для WebGL-узлов переносится внешний вид в существующий рендер и общий clock. Меню и справочные DOM-плашки могут использовать адаптированный HTML/CSS. Это исходный блок для переиспользования; в runtime игры он пока не подключён.
