# MAX — пакет пяти официальных сайтов

Отдельная визуальная основа для новой изолированной игры. Источники: [брендбук](https://go.max.ru/brandbook), [бизнес](https://business.max.ru/), [Цифровой ID](https://go.max.ru/digitalId), [авторы](https://go.max.ru/authors), [карьера](https://team.vk.company/career-max/). Снимки сохранены 01.10.2026.

**Посмотреть материалы:** [каталог](index.html). Он показывает исходники; его техническая вёрстка не является дизайном будущей игры. Видео запускаются вручную. **Чего не хватает:** [аудит относительно текущей игры](../../../../reports/max-site-kit-audit-20261001/README.md).

| В составе | Количество / содержание |
|---|---|
| Уникальные ассеты | 165, 45,9 MB; одинаковые байты хранятся один раз |
| Логотипы | 7 вариантов, каждый SVG / PNG / PDF — 21 файл |
| Шрифты | 11 WOFF2 и 10 TTF; разные версии сайтов раздельно |
| Растровая графика | 42 PNG и 32 WebP, включая логотипы, постеры и иллюстрации |
| Векторная графика | 56 SVG, включая логотипы, QR, элементы навигации и декор |
| Видео | 3 создания каналов, 2 Цифрового ID, 2 карьерных заставки |
| CSS | 29 исходных таблиц стилей с локальными зависимостями |
| Исходные блоки | 9 рецептов: карточки, кнопки, градиент, телефон, вкладки |

Категории и форматы в таблице пересекаются: например, SVG логотипа входит в оба счётчика. Ресурсы приложения/декоративные SVG не считать автоматически готовыми игровыми иконками.

Входные файлы:

- `brand.json` — область применения, состав, известные пробелы.
- `asset-index.json` — ID, путь, формат, SHA-256, размер, доступные размеры изображения, источники и варианты имён.
- `source-index.json` — исходные URL, пути архивов и хеши оригинальных страниц.
- `tokens/site.css`, `tokens/tokens.json` — шесть цветов из подписанных образцов брендбука и пять оригинальных WOFF2 сайта брендбука. Подключение шрифта из этого файла не смешивает варианты бизнеса/карьеры.
- `components/index.json`, `components/*/source.html` — цельные исходные блоки и список CSS-зависимостей. Классы исходников сохранены; это рецепты, требующие адаптации, а не проверенная библиотека игровых компонентов.
- `motion-index.json`, `references/*/styles/` — исходные keyframes, переходы, состояния hover и таблицы стилей с перепривязанными ресурсами.

Старые `glass-profiles.json`, WebGL-ленты, Frost, LumiCells, эффекты сканирования, прежние пиктограммы, Figma-экраны заданий и созданные ранее сцены с Мишкой не входят в пакет. Отсутствующие материалы отмечены в аудите. Изображение-постер создания ID, полученное из первого кадра оригинального видео из-за HTTP404 исходного постера, явно помечено как производное; SVG QR извлечён из публичного JS страницы. Графика не перекрашена и не перерисована.

Для новой игры сначала выбрать конкретные asset ID и компоненты; не загружать весь пакет, все 7 роликов и все CSS одновременно. Лендинговые CSS содержат глобальные селекторы и собственные брейкпоинты. Их нужно ограничить новой областью UI; размеры LED-текста и touch-зон задаются отдельно. Карьерный скролл дополнительно зависит от GSAP/ScrollTrigger; библиотеки и обработчики старой игры не включены.

Воспроизведение пакета:

```powershell
py -3 artifacts/DESIGN/brand-tools/build_max_site_kit.py
```

Проверка: хеши, ZIP CRC, ссылки CSS/HTML, сигнатуры шрифтов и наличие ресурсов. Художественная оценка и соответствие на стенде ожидают пользователя. Новая игра в этой итерации не собрана; текущий игровой runtime и мастер не изменены.
