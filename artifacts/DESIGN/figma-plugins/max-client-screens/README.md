# MAX — скриншоты по миссиям

Готовый локальный Figma Design плагин. Все 84 снятых изображения клиентской игры уже встроены. Интернет, сервер, запущенная игра и выбор файлов не нужны.

1. Используйте эту готовую папку плагина. Архив не требуется.
2. В настольной Figma: **Plugins → Development → Import plugin from manifest…**. Выберите `manifest.json`.
3. Запустите **MAX — скриншоты по миссиям**.
4. Выберите миссию, набор, размер и число экранов в ряду. Нажмите **Разложить в Figma**.

По умолчанию импортируются все 84 кадра. Набор **5 основных состояний** создаёт 20 кадров: начало, первый MAX, полная сборка, первый попап задания и завершение каждой из четырёх миссий. Можно отдельно выбрать задания с результатами, меню выбора иконок, справки или завершения.

На текущей странице размещаются шесть секций: старт, блогер, Цифровой ID, общение, бизнес, финал. Набор начинается справа от существующих объектов с отступом 240 px; на пустой странице — у центра видимой области. В каждой миссии — вложенные секции состояний, затем отдельная последовательность экранов каждого задания. Под изображениями — подписи; во фрейме сохранены исходное имя, URL и размер. Экраны идут слева направо, миссии — сверху вниз. Исходные пропорции и полный кадр сохраняются. При выборе общей ширины растягивается только размер на холсте, файл не перекодируется.

**Стоп** сохраняет уже импортированные изображения. Повторный запуск добавляет новый набор справа от предыдущего. Существующие объекты и название страницы сохраняются. Страница назначения фиксируется при нажатии кнопки импорта; ручное переключение вкладки страницы не перенаправляет изображения.

Это цельные растровые скриншоты, а не редактируемые слои интерфейса. В наборе бизнес пройден через канал, общение — голосовое сообщение и стикер. Неснятые альтернативы не добавлены. Снимки имеют два исходных размера: 1280×720 и 911×591. Несмотря на историческое расширение `.png`, браузер выдал JPEG; плагин распознаёт фактический формат и переносит исходные байты без повторного сжатия.

Пройдены 7 автоматических проверок: фильтры, раскладка, пропорции/пересечения, 84 встроенных файла, импорт на текущую страницу на модели Figma API, сохранение существующих объектов, смена страницы во время импорта, отмена и ошибка шрифта. Импорт в реальном редакторе Figma пока не проверен.
