# MAX Journey — актуальный UI в Figma

Локальный автономный плагин собирает текущий **Guided Reveal**: все **6 миссий**, включая две тестовые. Основной набор — **139 экранов**; полный — **216**, включая ошибки ответов и дополнительные кадры галерей.

## Установка и запуск

1. Используйте эту папку плагина: `internal` должен находиться рядом с `manifest.json`. Архив не требуется.
2. В Figma Design откройте файл с правом редактирования: **Plugins → Development → Import plugin from manifest…** → `manifest.json`.
3. Запустите **MAX Journey — все экраны**. Для обновления разрешения чтения комментариев повторно импортируйте manifest и запустите плагин заново.
4. Выберите «Все шесть миссий и меню» и основной набор, нажмите «Собрать экраны». Для первого запуска можно выбрать одну миссию и один экран.

Для создания экранов не нужны сервер, запущенная игра или интернет. Готовые `internal/code.js` и `internal/ui.html` содержат renderer, шрифты и медиа. Существующие объекты не изменяются: новый набор располагается справа на текущей странице, группами по миссиям. «Стоп» сохраняет уже созданные экраны.

## Один JSON с экранами и комментариями

1. Откройте файл клиента и выделите нужные экраны или группы миссий. Перегенерировать экраны не нужно.
2. В блоке **«Комментарии клиента → один JSON»** вставьте ссылку именно на открытый файл и личный токен Figma с правом `file_comments:read` и доступом к этому файлу. [Авторизация Figma](https://developers.figma.com/docs/rest-api/authentication/).
3. Опцию текущей страницы включайте только если свободные комментарии точно относятся к ней: API не сообщает страницу для абсолютных координат.
4. Нажмите кнопку экспорта и сохраните **`max-review.json`**. Пришлите этот файл для разбора правок.

В одном файле находятся `screenMap`, `commentMap`, `threads`, привязки к экранам, кандидаты, причины неоднозначности и `unassignedCommentIds`. Сохраняются все комментарии файла, ответы, авторы, даты и статус решения, включая комментарии вне выделенных экранов. Свободные точки, перекрытия и области могут оставаться неоднозначными — плагин не выдумывает привязку.

Токен используется только для чтения Figma API, очищается после запроса и не попадает в JSON или макет. Вместо токена можно загрузить ранее полученный JSON ответа API с массивом `comments`. Экспорт не запускает игровой renderer и не меняет объекты. Получение комментариев из реального файла и скачивание в Figma ожидают пользовательской проверки; 12 коротких CPU-проверок выполнены.

## Состав

Для каждой миссии:

- начало с карточкой ладони;
- все иконки вокруг ладони после последовательного раскрытия;
- все иконки в линии;
- отдельные состояния каждого задания и каждого его этапа, варианты ответов/формата, результат и итог.

Все три бизнес-ветки — канал, бот, мини-приложение — включены. Общий аккаунт и выбор инструмента не дублируются. Сюжеты ID содержат по две фотографии; создание ID использует исходные SVG360×800. Горизонтальные материалы бизнеса помещаются в ПК. Таймер3:00/рестарт, справа информационная справка без действий и кнопки внутри устройства соответствуют игре. Тестовые миссии и существующие контентные заглушки сохраняют маркировку.

| Миссия | Основной набор | Полный |
|---|---:|---:|
| Стать блогером | 15 | 32 |
| Все возможности с Цифровым ID | 23 | 26 |
| Общение на максимум | 29 | 61 |
| Продвижение бизнеса | 27 | 38 |
| Получение льготы · тест | 17 | 20 |
| Продвижение бизнеса · тест | 27 | 38 |
| Общее меню | 1 | 1 |

Фильтр «Только ладонь, круг и линия» даёт **18 экранов**. Можно отдельно выбрать одну из трёх раскладок или только задания/результаты. Основной формат1600×1000; длинные линии расширяются до2048px, чтобы показать все узлы без уменьшения масштаба. Это кадры самостоятельной игры, не развёртка LED-стены. Во время начальных перемещений подписей нет — они появляются после подключения связи.

## Слои и ограничения

Иконки/исходные экраны ID — SVG; текст по умолчанию — отдельные PNG-строки настоящего Max Sans. Фото — исходные изображения. Стекло, фон, связи и элементы под Frost запекаются настоящими шейдерами игры. По умолчанию есть скрытый полный PNG-эталон для сравнения со слоями.

Опция редактируемого текста работает при наличии нужного Max Sans в Figma; без него остаются точные PNG-строки. Метрики текста Figma могут отличаться от Canvas. Динамика представлена статическими ключевыми состояниями, а не интерактивным прототипом или анимацией Figma. Шейдеры и некоторые поверхности остаются растром.

Проверены каталог, сборка, обмен с моделью Plugin API и выборочные кадры настоящего renderer в одной браузерной вкладке. **Импорт в реальный редактор Figma и полный прогон216 кадров пока не проверены.** Начните с одного экрана и сравните слои со скрытым эталоном.
