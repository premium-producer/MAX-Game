# MAX — карта контента всех миссий · v2

Локальный плагин: **6 миссий, 253 карточки, 107 встроенных ресурсов**. Сохранены все 216 состояний прежнего комплекта, включая 27 размещений результатов. Ревизия `restored-client-review-20261002-v2`.

## Запуск

1. Figma → Plugins → Development → Import plugin from manifest… → `manifest.json` в этой папке. Если плагин уже импортирован, закройте и запустите его заново.
2. В окне «MAX · Контент миссий · v2» выберите миссии и нажмите «Собрать / обновить v2».
3. На текущей странице появится «MAX · Все миссии · восстановленная карта v2», справа от существующих объектов. Новая страница не создаётся. Старая карта v1 сохраняется.

Нужна вся папка: `code.js` и `ui.html` рядом с manifest. Архив, сервер, токен, MCP и интернет не нужны. Повторная сборка v2 обновляет её собственный контейнер, сохраняет положение и ручные правки текста. JSON экспортируется из контейнера текущей страницы.

## Исправление финального экрана · 02.10.2026

Финалы отображают «Миссия выполнена», официальный QR MAX и «К миссиям»; итог остаётся в справке справа. При повторной сборке ошибочный последний скриншот скрывается, сохраняя его ручные правки в слоях. QR не дублируется. Перезапустите плагин и нажмите «Собрать / обновить v2» для исправления существующей карты.

## Цветовые отметки

- **Зелёная справка** — текст или заголовок изменён по клиентскому комментарию. Глобальное удаление заголовков справок тоже считается изменением. Удалённый текст не заменяется редакторским пояснением: пояснение находится отдельно.
- **Зелёный фрейм** — добавленный или запрошенный контент, включая существовавшие изображения, вынесенные в самостоятельный шаг.
- **Жёлтый фрейм** — контент, который попросили убрать, оставлен для сравнения.
- **Красная область экрана** — нужный материал отсутствует или старый материал не соответствует запросу. Красный экран может находиться внутри жёлтого/зелёного фрейма: внешний цвет описывает решение, внутренний — наличие материала.

В каталоге: 41 удаляемая карточка, 48 добавленных, 225 изменённых справок, 38 карточек с пробелами. Категории пересекаются.

## Восстановление и структура

Исходные тексты и изображения взяты из сохранённого `../max-journey/internal/ui.html`, сверены с полным аудитом и дополнены адресными комментариями из `../../max-game/max-review.json`. Текущий игровой каталог не служит источником исходного текста.

В видеозвонке восстановлены четыре основных состояния и прежний кадр 85835. Дополнительные исходные кадры, включая 85865, сохранены ниже основной последовательности. Возвращены отдельные результаты, разные справки отеля/музея/возраста и тексты тестовых миссий. Отменённые стадии остаются жёлтыми.

Шесть миссий — горизонтальный Auto Layout. Внутри миссии — колонки иконок; задания и их кадры идут строго вертикально. Дополнительные состояния находятся ниже основных в той же колонке. Экран слева, справка справа, по центру высоты. Текст HUG по высоте, текст иконки FILL по ширине. Блок задания: промежуток 350 px, отступы 20/40, белая обводка 5 px / 40%. Миссия: отступы 200/200, обводка 6 px / 60%.

Начальные состояния ладони, кольца и линии включены как **карточки состава контента**, а не повторная отрисовка полного WebGL-интерфейса. Отсутствующие бизнес-экраны, иконки и неподтверждённые финалы явно отмечены. Интерфейс в лапах Мишки остаётся отложенной правкой.

## Источники и экспорт

`restored-content.mjs` собирает независимый редакторский каталог. Проверяются SHA исходной сохранённой сборки и встроенных ресурсов. `additions-baseline.json` хранит предыдущую подборку для метаданных ассетов и поздних дополнений; она не заменяет исходные тексты.

`content-index.json` содержит карту 216 исторических состояний и реестр 80 комментариев. 26 комментариев вне выделенных экранов не применяются автоматически. JSON правок версии 2 сохраняет исходные тексты, происхождение, цветовые решения, связи с комментариями и пользовательские изменения. Экспорт не меняет игру.

Предыдущая версия сохранена обычной папкой `artifacts/workspace/backups/max-content-builder-before-restoration-v2-20261002/`. Игра, backend и мастер этой сборкой не меняются.
