## Итерация

Наблюдение → гипотеза → один изменяемый слой → ожидаемая видимая разница → исходный кадр → новый кадр → решение. Если есть регрессия, исправить её или вернуть конкретную экспериментальную правку, сохраняя чужие изменения.

## Итог

- Техника: работает / не работает / частично.
- Визуальная самопроверка: PASS / FAIL / BLOCKED.
- Художественное решение пользователя: не запрошено / ожидается / принято / отвергнуто.
- FPS: измерение с условиями либо не измерено.
